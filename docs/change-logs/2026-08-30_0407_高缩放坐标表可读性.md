# 高缩放坐标表可读性

时间：2026-08-30 04:07 +08:00

## 问题与影响

在 150%–180% 界面缩放下，左侧“格点”表的长浮点坐标会被 Qt 自动省略为 `0...`。这会让用户无法直接检查当前元胞坐标，也容易误以为拖拽或吸附改变了错误的值。跃迁表的幅度、端点和偏移字段同样可能在窄侧栏中被截断。

## 根因

表格列必须在高缩放下保持可用宽度，不能简单无限加宽；此前单元格只保存可见文本，没有为被省略的原值提供一致的查看入口。格点表的画布拖动更新、手动输入、新增格点和模型加载还分别创建了 `QTableWidgetItem`，因此提示行为并不统一。

## 实施修改

1. 在 `ControlPanel` 中增加统一的表格项构造器：
   - 浮点值超过 10 个字符时，单元格显示 8 位有效数字，保持紧凑、可读、可编辑；
   - 原始 Python 字符串写入独立的 Qt 数据角色；
   - 悬停提示统一显示“完整值：…”，保留模型实际使用的完整精度。
2. 格点表的手动编辑、画布拖动更新和新增格点全部走统一构造器；手动修改后立即刷新提示，避免提示残留旧坐标。
3. 跃迁表关系提示保留原有“胞内/胞间、dx/dy”语义，同时追加当前单元格的完整值，不改变 JSON 字段和内部 0 基端点语义。
4. 新增回归测试，覆盖长坐标的紧凑显示、完整提示、编辑后提示刷新，以及胞间跃迁幅度提示。

## 后续注意

完整值仍可通过进入单元格编辑状态查看和修改；对于极端长表达式，侧栏仍以纵向滚动为主，避免为了少数长文本破坏整体布局。后续可在表格右键菜单中补充“复制完整值”，但不应牺牲当前紧凑布局。
