# 预设单位跃迁默认值统一

- 时间：2026-08-28 22:35 +08:00
- 范围：内置预设“最近邻 + 次近邻”模式的默认参数、链模型解析色散回归、预设视觉验收

## 发现

项目此前将最近邻参数 `t` 默认设为 `1.0`，但只在包含 `t2` 的预设中把次近邻参数默认设为 `0.2`。这使内置模型初始状态出现两套不同的跃迁尺度，和项目目标“默认模型的所有跃迁都是 1”不一致，也容易让用户误把默认差异当成模型几何或边界效应。

## 修改

- `templates._generic` 中只要模型包含 `t2`，现在默认 `t2=1.0`；`t2` 仍是独立可编辑参数，用户可以主动改为 `0.2` 或任意合法值；
- 保留现有符号表达式（最近邻 `-t`、次近邻 `-t2`），只调整预设初始参数，不改变模型文件字段或计算接口；
- 一维链的默认二阶谐波回归同步更新为
  `E(k_x)=-2t\cos k_x-2t_2\cos(2k_x)`，在 `t=t2=1` 时 `E(0)=-4`、`E(π)=0`；
- 新增跨模板检查，确认一维链、方格、三角、蜂窝、Kagome 的每一条默认跃迁数值幅度均为 1；
- 新增跃迁入口上一轮的单格点/半无限修复保持不变，新增项仍默认实跃迁且可独立设置胞间偏移。

## 影响与风险

- 这是有意的默认数值变更：加载内置“最近邻+次近邻”模板后，能带和矩阵的数值会与旧版不同，但更符合统一单位跃迁约定；
- 已保存的 `.hvisual` 文件、用户自定义参数和只选择“最近邻”的预设不被改写；
- 既有研究若依赖旧版 `t2=0.2`，应在参数面板显式输入 `t2=0.2`，模型数据会准确保留该选择。
