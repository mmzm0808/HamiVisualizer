# 工作区入口与 Bloch 别名审计

- 日期：2026-08-28 15:20 +08:00
- 类型：工作区交互回归 + 表达式显示兼容性修复
- 影响范围：`view/main_window.py`、`view/matrix_view.py`、`tests/test_workspace.py`、`tests/test_ui_hardening.py`

## 修复与补强

### 最近模型

- 增加回归覆盖：从“打开最近模型”打开文件会新建一个标签页；再次打开同一文件只切换到现有标签，不重复创建会话。
- 保留路径规范化、大小写不敏感去重、失效文件移除和工作区持久化逻辑。
- 菜单项使用文件名显示，并通过工具提示保留完整路径，避免长路径挤压菜单。

### Bloch 符号别名

- 矩阵智能显示此前只把自由符号 `kx` 识别为 Bloch 变量，而格式化器已经支持 `k_x`。
- 现在两个入口统一接受 `kx` 与 `k_x`，自定义表达式不会因命名风格不同而退回纯数值显示。
- 下标仍由统一富文本转换输出，保证 `x` 位于 `k` 的下标而不是与指数同级。

### 发布文档一致性

- README 原先保留了早期“半无限仅支持 ±1 跨胞偏移”的描述；该限制已在长程谐波重构中解除。
- 已改为明确说明支持任意整数 `off_x`，与 `HamiltonianBuilder`/`RibbonHamiltonian` 当前实现一致。
- README 工作区说明同步加入“恢复位置”入口，避免把该功能隐藏在撤回历史中。
