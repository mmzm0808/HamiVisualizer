# 非矩形有限盘边界态判定与简并能级代表选择

- 开始时间：2026-08-31 08:11:57 +08:00（北京时间）
- 完成时间：2026-08-31 08:24:55 +08:00（北京时间）
- 影响范围：OBC 波函数的边界投影、边界/体态诊断和目标能量选择；不改变 Hamiltonian、能谱、本征值、模型文件格式或半无限 Bloch 计算。

## 一、问题与物理原因

旧版 `edge_mask_for_positions()` 将边界定义为 x/y 外包矩形四侧的一层，并把厚度设为样品最大跨度的 15%。这有两个物理问题：

1. 对正三角、圆盘和六边形，斜边或圆弧上大量真实边界格点既不靠近 `xmin/xmax`，也不靠近 `ymin/ymax`，因此会被误判成体内格点；
2. 15% 厚度随样品线性尺寸增长，同样晶格常数下样品越大，被归入“边缘”的内部层数越多，边界权重失去可比性。

另一个相连问题位于能量选择：`wavefunctions()` 已在精确简并子空间内对角化边界投影，得到从体内到边界局域的可检查代表；但 `select_energy()` 使用 `argmin` 总取同能级的第一个索引。由于投影本征值升序，第一个恰好通常是边界权重最低的代表，用户即使输入正确能量也可能只看到体态。

## 二、实施方案

### 2.1 旋转不变的单层边界

- 用分块欧氏距离计算每个格点的最近非重合邻居，取中位数作为晶格局部间距；每块最多 256 行，避免创建完整 `N×N×2` 坐标差张量；
- 对二维点集使用单调链算法构造凸包，计算每个格点到所有凸包线段的最短距离；距离不超过 `0.8 × 中位最近邻间距` 的格点属于边界层；
- 用 SVD 判断退化为一维的样品，沿物理主轴投影，仅在两个端点各保留固定一层；
- 重合点、单点和数值近共线点提供保守回退，不产生 NaN 或空边界。

该定义与坐标轴方向无关，厚度由晶格间距而非样品尺寸控制。当前内置有限盘均为凸形，因此凸包边界与正三角、圆盘、六边形和矩形的物理外边界一致。

### 2.2 简并能级中的边界代表

- 首先按原规则寻找距离目标能量最近的本征值；
- 只在机器精度判定的同一数值简并组内比较各态边界概率，不混合或跳过不同能级；
- 选取边界概率最高的已有代表态；手动下拉框选态仍完全尊重用户索引；
- 诊断栏追加“同能级 N 态中优先边界代表”，让自动选择行为可解释。

## 三、测试与实证

- 人工圆盘点集：斜向凸包点 `(2,2)` 必须属于边界，中心 `(0,0)` 必须属于体内；旋转 0.371 rad 后掩膜逐项不变；
- 21 格点一维链：只有第 1 与第 21 个物理端点属于边界；
- 人工 5×5 精确二重简并：目标 `E=0` 自动从中心态切换到同能级角点态，并显示简并选择说明；
- 全部 `10 个模板 × rectangle/triangle/disk/hexagon = 40` 组合：边界非空，整体旋转 0.287 rad 后掩膜逐项不变；
- Kagome 6×6 正三角盘：输入 `E=√2−1`，自动从同能级第 31 态切换到第 32 态，边界权重 `81.5%`、基线 `52.4%`、富集 `1.56×`，UI 判定“边界局域态”；
- 既有 SSH 边态、φ 分数输入、普通能量选择和波函数标记尺寸测试继续通过；
- 完整回归：`359 passed in 108.77s`（2026-08-31 08:24:55 +08:00）；`compileall` 与 `git diff --check` 通过。

## 五、风险与边界

- 本轮边界几何针对当前内置凸形有限盘。未来如果引入带孔、凹角或多连通区域，应把凸包升级为基于跳跃图配位数或 alpha-shape 的边界；
- 简并态优先只发生在机器精度同能级内，不会把能量相近但物理不同的态混在一起；
- 波函数概率和本征能量没有被修改，只改变边界诊断与自动展示的代表索引。
