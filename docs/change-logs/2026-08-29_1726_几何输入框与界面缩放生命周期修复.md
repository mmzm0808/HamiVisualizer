# 几何输入框与界面缩放生命周期修复

- 时间：2026-08-29 17:26 +08:00
- 范围：元胞长度/矢量编辑框、UI 缩放后的延迟适配，以及对应的多缩放实拍。

## 发现的问题

本轮对 80%、100%、150%、180% 的编辑态逐帧检查时发现：

1. `a₁/a₂` 长度和分量输入框使用原生 `QDoubleSpinBox` 按钮条，长数值在 180% 界面缩放下会被右侧上下箭头挤压，视觉上像是最后一个字符被遮住；
2. UI 缩放使用无父对象的 `QTimer.singleShot` 延迟适配，窗口关闭或测试销毁较快时，回调可能访问已删除的 `ZoomGraphicsView`，在 stderr 留下 RuntimeError。虽然不影响主流程，但不符合稳定软件的生命周期要求。

## 改动

- 几何输入框隐藏原生上下按钮条，保留鼠标滚轮、键盘上下键和直接输入能力；12 位长度精度不变，字段宽度只承担文本显示，不再让按钮覆盖尾数；
- UI 缩放后的 `fit_all` 改为窗口拥有的单次 `QTimer`，重复缩放只保留最后一次适配；窗口销毁时定时器随父对象一起销毁，并对极端平台销毁顺序增加 RuntimeError 防护；
- 不改变模型 JSON、元胞矢量、吸附、撤回、计算或任何公开接口。
