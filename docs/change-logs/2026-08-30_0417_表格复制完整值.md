# 表格复制完整值交互

时间：2026-08-30 04:17 +08:00

## 需求背景

上一轮将高缩放下的长坐标改为“紧凑显示 + 悬停查看完整值”。实际检查模型时，用户还需要把精确坐标、跃迁幅度或胞间偏移带到笔记、脚本和外部计算中；仅靠悬停提示不够高效，也不便于复制到 MATLAB / Python。

## 设计与实现

1. 格点表开启单元格右键菜单，提供“复制完整值”。菜单只在有效单元格上启用，空白区域不弹出无意义菜单。
2. 跃迁表将同一操作放在原有胞内/胞间关系菜单顶部，不增加额外弹窗，也不改变关系编辑路径。
3. 复制内容优先读取统一保存的原始值角色：
   - 被省略的浮点坐标复制完整模型文本，而不是屏幕上 8 位紧凑显示值；
   - 跃迁表复制可见的完整端点、幅度、`dx/dy` 或相位文本；
   - 复制动作直接写入 Qt 剪贴板，保持与现有矩阵元复制操作一致。
4. 右键时将当前单元格设为焦点，避免用户先点击一次再打开菜单；原有行选择和胞内/胞间快捷关系不受影响。

## 代码范围

- `hamivisualizer/view/control_panel.py`：新增统一复制方法、格点表上下文菜单，并把复制项并入跃迁关系菜单；
- `hamivisualizer/tests/test_ui_hardening.py`：验证上下文菜单策略、格点完整坐标复制、跃迁幅度复制及原关系菜单完整性；
- 未改动模型文档格式、Hamiltonian 构造、端点 1 基显示或矩阵数据。
