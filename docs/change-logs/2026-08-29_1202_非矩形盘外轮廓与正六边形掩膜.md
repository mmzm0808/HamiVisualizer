# 非矩形盘外轮廓与正六边形掩膜

- 时间：2026-08-29 11:40–12:02（+08:00）
- 范围：`hamivisualizer/model/boundary.py`、`hamivisualizer/controller.py`、`hamivisualizer/view/rendermodel.py`、`hamivisualizer/view/lattice_view.py`、相关模型/场景测试。
- 背景：上一轮已把圆盘、六边形和正三角形的元胞筛选迁移到真实 `a1/a2` 物理度量，但视图仍只绘制离散元胞轮廓；此外六边形筛选式并不是严格正六边形。用户在密集 Kagome/蜂窝模型中难以确认盘形，且不同元胞尺寸可能出现形状比例误导。

## 发现的问题

1. 旧六边形判定使用 `max(|y|, |x| + 0.5|y|)`，会把 `(0,1)` 等不属于正六边形的点保留下来，导致上下方向过宽、边长不一致。
2. 非矩形盘没有显式物理外轮廓，用户只能从元胞虚线拼接推断盘形；在 `cell_outline` 关闭或元胞较稀疏时，三角盘尤其容易被误解成普通矩形网格。
3. 外轮廓只按元胞原点计算时，Kagome 等元胞内部的站点可能落在轮廓外侧，视觉上像是节点被裁掉或盘形与晶格不一致。

## 实施修改

### 1. 正六边形物理掩膜

- 向量元胞路径改用正六边形的两个凸半平面条件：
  - `|y| ≤ √3/2 + margin`
  - `√3|x| + |y| ≤ √3 + 2·margin`
- 无向量的旧兼容路径同步使用同一正六边形度量，并把 `shape_aspect` 应用于归一化 y 坐标。
- 掩膜仍只决定有效元胞集合；矩阵与晶格拓扑继续共享这一集合，不改变跃迁语义或 JSON 结构。

### 2. 真实物理外轮廓

- `Boundary.shape_outline()` 新增统一轮廓接口：
  - 正三角形：复用真实 `a1/a2` 正交物理框架中的等边三角形顶点；
  - 圆盘：按真实物理半径生成 96 段平滑多边形；
  - 六边形：按真实物理半径生成 6 个等距顶点的正六边形。
- `LatticeSceneData` 增加末尾字段 `boundary_outline`，保持旧版位置构造兼容。
- 场景矩形纳入轮廓点，避免轮廓超出视口；轮廓以独立的蓝色无填充线绘制，元胞轮廓开关关闭时仍能识别盘形。
- 轮廓按元胞内最大站点半径适度外扩，确保 Kagome/蜂窝等非方形元胞的可见节点不会被理想几何线误切。

### 3. 回归保护

- 新增正六边形轮廓测试：6 条边长度相等、6 个顶点到中心半径相等。
- 新增场景 DTO 测试：矩形无额外轮廓，三角形至少 3 点，圆盘至少 24 点，六边形恰为 6 点。
- 既有 Kagome 三角形 `6→4→2` 有效元胞层、圆盘/六边形实空间度量测试继续保留。

## 兼容性与风险

- 没有破坏性 API 或模型 JSON 版本变更；新增 DTO 字段位于末尾，旧插件可继续按旧位置构造。
- 形状轮廓是显示层信息，不参与哈密顿量计算；正六边形掩膜的修正会让少数旧自定义模型的有效元胞数量改变，这是物理几何纠正带来的预期行为。
- 旧模型若没有 `cell`/`a1/a2`，仍走兼容掩膜路径；新建和内置预设均使用真实元胞向量路径。
