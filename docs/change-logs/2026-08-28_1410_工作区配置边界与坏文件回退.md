# 工作区配置边界与坏文件回退

## 问题

模型文件已经有结构与大小校验，但本地 `preferences.json`、`workspace.json` 对非对象 JSON、异常字段类型和超大文件的处理仍不一致。损坏的工作区配置可能在启动阶段抛出未处理异常，或把非法分屏尺寸、标签页索引带入 Qt 界面。

## 修改

- 偏好设置限制为 64 KiB，工作区限制为 1 MiB；超限直接回退默认值；
- 非对象 JSON、错误版本和异常字段类型统一回退，不再依赖 `dict.get()` 隐式行为；
- 工作区标签页最多读取 32 个，会校验名称、路径、布尔值、结果页索引和字符串长度；
- 当前标签页索引、比较结果名称和分屏尺寸统一归一化到安全范围；
- 增加坏 JSON 与超大工作区回归测试。

## 兼容性

合法的旧版工作区字段仍可正常读取；缺失字段继续使用原有默认值。没有改变模型文件格式，也没有改变用户模型保存位置 `~/.hvisual`。

## 验证

- 工作区与偏好设置测试覆盖坏 JSON、超大文件、正常往返和多标签恢复；
- 测试临时目录固定在项目内 `.codex-artifacts/test-runs/`；
- 全量测试：`130 passed in 27.22s`（项目内 basetemp）；
- 离屏浅色 100%、深色 100%、深色 150% 截图已生成并人工检查：`.codex-artifacts/screenshots/workspace-boundary-audit-20260828/`。
