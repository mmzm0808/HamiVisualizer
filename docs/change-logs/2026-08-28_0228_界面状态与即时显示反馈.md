# 界面状态与即时显示反馈

- 修改时间：2026-08-28 02:22:00 至 02:28:00 +08:00
- 类型：界面缺陷修复、计算与显示解耦、持久化完善
- 影响范围：控制面板、全局主题、控制器、模型文件、回归测试、视觉验收工具

## 问题

1. 自定义 `QCheckBox::indicator` 只给选中状态填充蓝色，没有绘制
   勾号；用户只能看到实心方块，容易误判为点击无效。
2. 折叠标题将 Unicode `▾/▸` 直接放进文字。部分中文字体不含
   该字形，最终显示为方框。
3. “智能识别标签”和“元胞编号方向”是纯显示选项，原实现却将
   它们纳入哈密顿量签名，导致不必要的矩阵和谱重算；手动计算模式下
   还会给人“勾选了但没反应”的感觉。
4. 元胞编号方向没有写入 `.hvisual` 文件，保存、多标签切换和撤回后
   可能丢失用户选择。

## 修改

### 1. 可视状态

- 删除覆盖 Qt/Fusion 原生指示器的 QSS，恢复高对比勾号；
- `CollapsibleGroupBox` 不再使用文字三角，改由 `QPainter` 绘制
  向下/向右矢头；
- 矢头颜色来自当前 palette，明暗主题自动适配；尺寸基于字体度量，
  界面缩放时同步增大；
- 标题左边距扩大，为绘制箭头保留空间。

### 2. 显示与物理计算解耦

- `ControlPanel` 新增 `displayChanged(str)` 信号；
- 智能标签仅重绘矩阵，元胞编号仅重绘晶格；
- 控制器缓存已解析的 hopping 对象，纯显示刷新不重复解析表格；
- 从哈密顿量签名中移除 `smart` 和 `labels_bottom_up`；
- 即时刷新后状态栏明确显示“未重新计算哈密顿量”；
- 保留用户已缩放/平移的矩阵和晶格视口。

### 3. 保存、多标签与撤回一致性

- 模型文档新增可选布尔字段 `labels_bottom_up`；
- 旧文档缺少该字段时默认为 `true`，不提升格式版本，保持向后兼容；
- 打开模型时恢复编号方向；当前文档、标签页历史和自动保存都包含它。

### 4. 可重复视觉验收

- 新增 `tools/render_ui_regression.py`；
- 统一调用程序的中文字体初始化和 Fusion 风格；
- 一次生成浅色 100%、深色 100%、深色 150% 三张固定尺寸截图。
