# 偏好设置布尔字段严格校验

## 问题

偏好设置加载后会直接把 `autosave`、`check_updates` 交给 dataclass。Python 中非空字符串即为真值，因此配置文件中的 `"false"` 会错误开启自动保存，也会为未来更新检查留下同样的行为风险。

## 修改

- `Preferences.normalized()` 仅接受原生 `bool`；其他类型回退到安全默认值（自动保存/检查更新均为开启）；
- 增加字符串布尔值回归测试；
- 保持合法配置与现有偏好设置界面行为不变。

## 验证

- 全量测试覆盖正常偏好往返、坏 JSON 和字符串布尔值；
- 全量测试：`133 passed in 21.55s`；
