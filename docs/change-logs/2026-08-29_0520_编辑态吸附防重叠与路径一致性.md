# 编辑态吸附防重叠与文档路径一致性

时间：2026-08-29 05:20–09:30 +08:00  
范围：晶格编辑吸附、半无限/有限预设交互回归、使用文档

## 复核到的问题

编辑格点时，吸附候选同时包含当前所有格点、原始构型和网格点。拖动一个格点靠近邻居时，最近候选可能正好是邻居的位置，结果会把两个格点堆叠到同一坐标；下一次重建后，用户会看到节点或连线像是“消失”了。这个问题只在真实鼠标拖动路径中成立，预览调用仍需要完整二维候选。

另外 README 的两个段落对自动保存位置描述不一致：一个写到 `~/.hvisual/models/`，另一个笼统写成 `~/.hvisual`，容易让用户误以为模型文件直接落在配置根目录。

## 实施内容

1. `LatticeView.snap_position` 增加交互拖动专用的占位保护：
   - 当前正在拖动的格点仍可吸附回自身和拖动起点；
   - 其他实时格点不再作为拖动目标，避免吸附重叠；
   - 原始构型参考点若已被另一实时格点占用，会被跳过；
   - 网格回退点若与邻居冲突，会把指针位置沿邻居法线轻推到安全间距，连快速拖动到邻居中心也不会产生重复坐标或“跳到邻居上”的突变；
   - 无 `drag_origin` 的程序化/预览调用保留完整几何候选和原有二维吸附行为。
2. README 统一说明：模型自动保存至 `~/.hvisual/models/`，工作区布局与偏好位于 `~/.hvisual/`。
3. 新增拖动防重叠回归测试，保留石墨烯特殊坐标和二维吸附测试，确保斜原胞与旧 DTO 行为不回归。
