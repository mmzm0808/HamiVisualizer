# 半无限跃迁快捷端点与紧凑列修复

- 日期时间：2026-08-29 02:22 +08:00
- 范围：半无限（x-Bloch）跃迁快捷添加、端点继承和高缩放紧凑布局
- 状态：已实现、已截图、全量回归通过

## 复核发现

上一轮把 `dx`/`dy` 提升为常驻列后，150% 高缩放截图仍暴露出第二个布局问题：相位列与高级列同时占据紧凑表宽度，导致表格出现横向滚动/右侧字段裁切。另一个交互细节是，关系菜单新增项无论用户当前检查哪条键都固定使用 `0→1` 端点，多格点模型中容易造成“操作被忽略”的感觉。

## 修改内容

### 1. 快捷添加继承当前端点

`ControlPanel._default_hop_sites()` 现在按以下顺序选择端点：

1. 若跃迁表当前选中行且起点/终点合法，沿用该行的 `from/to`；
2. 一格点模型使用 `0→0`；
3. 没有有效选择时回退到安全默认 `0→1`。

因此“按关系添加”只改变胞内/胞间关系，不会悄悄更换用户正在检查的格点对。自定义偏移对话框也自动获得同样的端点默认值；模型 JSON 和外部接口保持兼容。

### 2. 紧凑表避免高缩放裁切

- 紧凑模式保留：名称、起点、终点、`dx`、`dy`、幅度；
- 相位、相位模式、符号统一放入高级列，勾选后仍可完整编辑；
- 150% 高缩放时不再为相位元数据保留不可读的窄列，纵向滚动可继续浏览大量跃迁；
- `dx`/`dy` 仍始终可编辑，并带有“胞内/胞间 + 有符号偏移”逐行工具提示。

这不是隐藏物理信息：胞内/胞间拓扑关系属于核心字段，始终可见；较少使用的相位元数据才采用渐进披露。

## 端到端物理检查

- `(0,0)` 行仍进入 `H0`；
- `(+1,0)` / `(-1,0)` 行仍规范化后进入 `H1`，`H(kx)` 自动补共轭；
- `dy`/斜向偏移仍按有限 ribbon 行连接和截断；
- `|dx|>1` 长程项仍使用 `extra` 对应 Bloch 谐波；
- 显示层仍使用独立的中心/虚影逻辑，未把矩阵索引混作绘图编号。

## 使用方式

在“跃迁项”展开后，先选中要复用端点的已有行，再点击“按关系添加 → 右侧胞间/左侧胞间/上方胞间/下方胞间”；若需任意端点或长程 `(dx,dy)`，使用“自定义胞间偏移…”。若需编辑相位字段，勾选“显示高级列”。
