# 模型导入大小边界审计

## 问题

模型 JSON 已限制格点、跃迁、参数和表达式复杂度，但读取入口此前会直接调用 `json.load()`，在结构校验前没有限制文件字节数。对不可信的大文件，这会把不必要的内存和解析时间交给 GUI 线程。

## 修改

- 在 `model/persistence.py` 增加 `MAX_MODEL_BYTES = 4 MiB`；
- `load_model()` 先检查文件大小，超过上限立即抛出中文 `ValueError`，不会进入 JSON 解析；
- 合法模型的 JSON 格式、保存接口和结构校验规则不变；
- 增加回归测试，确认超大文件在解析前被拒绝。

## 验证标准

- 超过 4 MiB 的模型不会被加载或修改当前模型；
- 小于上限的合法模型继续正常读写；
- 原子保存逻辑保持不变，临时文件仍在目标目录并在失败时清理。

## 实际验证

- 全量测试：`128 passed in 23.96s`；pytest 基准目录为项目内 `.codex-artifacts/test-runs/security-audit/`。
- 离屏截图：浅色 100%、深色 100%、深色 150% 均成功生成并人工检查；截图目录为 `.codex-artifacts/screenshots/security-audit-20260828/`。
