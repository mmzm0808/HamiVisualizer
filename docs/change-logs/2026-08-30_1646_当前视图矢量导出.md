# 当前视图 SVG/PDF 矢量导出

- 时间：2026-08-30 16:46:16 +08:00
- 范围：文件菜单、主窗口导出状态、当前标签页导出、自动化回归与 100% 菜单证据。

## 背景

此前文件菜单只有 PNG 导出。PNG 适合快速分享，但放入论文或报告后放大容易看到像素化，
矩阵文字和晶格线条也无法继续编辑。本轮补充 SVG 与 PDF 两个矢量出口，同时保留原 PNG
入口和快捷键，不改变模型文件格式、计算流程或已有对外接口。

## 实现

1. 文件菜单新增“导出当前视图 SVG…”和“导出当前视图 PDF…”，并为菜单项提供用途提示；
2. 导出对象统一取当前标签页，保留当前标签页中的矩阵四边标尺、晶格/能带/波函数内容、
   主题和可见叠加层，不另起一套容易漂移的绘图逻辑；
3. SVG 使用 Qt `QSvgGenerator` 接收 QWidget 的 QPainter 绘制命令，设置视图尺寸、96 DPI、
   标题和描述，适合在矢量编辑器中继续排版；
4. PDF 使用 Qt `QPdfWriter`，按当前窗口像素尺寸换算为 96 DPI 的点数，自动选择横向/纵向
   单页布局并取消额外页边距，避免论文图被默认 A4 页面裁切；
5. PNG、SVG、PDF 共用结果状态门控：首次计算前、计算失败或结果过期时全部禁用；计算完成
   后统一恢复，避免导出旧结果；用户未输入扩展名时自动补全 `.png`、`.svg` 或 `.pdf`；
6. 导出失败只弹出可恢复错误，不修改当前模型、不关闭标签页，也不会把失败路径写入最近模型。
