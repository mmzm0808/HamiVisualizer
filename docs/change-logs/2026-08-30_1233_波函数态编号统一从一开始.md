## 问题

- 选择器条目改为 `#1、#2、…`；内部 `_state` 仍保持 0 基，保证数组访问和现有 API 完全兼容；
- 波函数信息栏中的“本征态 #N”以及“目标 E → #N”同步显示为 1 基编号；
- 未修改能量最近态选择、简并处理、边界局域度量和波函数绘制逻辑；
- 新增回归断言，覆盖选择器第一项与信息栏编号的一致性。
