# Kagome 三格点原胞、矩阵数学排版与侧栏标题栏

## 目标

将 Kagome 的双开边界正三角形纳米盘改为符合其原始 Bravais 几何的三格点斜原胞，同时明确保留半无限 ribbon 的六格点正交超胞。同步修复矩阵中 `e^{ik_x}` 的嵌套上下标基线，并将左侧控制面板的“插在线上”的小标题换成可点击、可辨识的标题栏。

## 实现

### Kagome 三格点正三角盘

- `templates.py` 新增任意斜 Bravais 矢量下的周期键生成器与 Kagome 三格点原始元胞：
  - `a₁ = (2, 0)`；
  - `a₂ = (1, √3)`；
  - 胞内位点为 A `(0, 0)`、B `(1, 0)`、C `(1/2, √3/2)`；
  - 最近邻和次近邻键均按这两个平移矢量补全。
- 仅当模板新建路径是 **Kagome + 双开边界 + 正三角形盘** 时使用该三格点原胞；半无限、矩形/圆/六边形 Kagome 继续采用原有六格点正交超胞，因此 x-Bloch 的 `H₀/H₁` 分块语义、胞间跃迁入口和既有模型文件不变。
- `Boundary.triangle_outline` 对等长且夹角 60° 的原始矢量使用 `cx + cy ≤ N − 1` 的三角掩膜；`6×6` 样本的有效元胞层现在为 `6, 5, 4, 3, 2, 1`，共 21 胞、63 格点。
- 场景元胞轮廓使用渐进披露：少量胞保留完整虚线轮廓；超过 12 胞时只高亮一个真实原始元胞，再以蓝色有限样品外轮廓表达整体形状，避免大量斜菱形虚线盖住 Kagome 的红色最近邻骨架。

### 数学文本

- Qt 的富文本对 `<sup>...<sub>...</sub></sup>` 没有 TeX 式嵌套脚本排版，会将 `x` 先降到上标基线下、再相对正文二次下降。因此 `e^{ik_x}` 显得像 `x` 掉到了指数外。
- 首轮兼容修复保留了 `to_html()` 的旧 HTML 输出；随后进一步将矩阵绘制统一切换到 `view/math_text.py` 的无第三方依赖脚本布局。它以 QFontMetrics 计算父原子基线，分别布局 `^` 与 `_`，支持指数、下标、嵌套分组、希腊符号和常见运算宏。
- 小矩阵图元和大矩阵视口叠加层共用同一个 `MathLayout`，因此 `e^{ik_x}` 中 x 只相对 k 下沉一次，整个 `ikₓ` 只上移一次；字号继续按矩阵单元的实际屏幕像素缩放。
- 数学字体仍按 Cambria Math → STIX Two Math → DejaVu Serif → Times New Roman 回退，不把完整 LaTeX 运行时引入发行版；模型计算与复制出的标准 LaTeX 源码不受影响。

### 控制面板

- `CollapsibleGroupBox` 不再使用 Qt 画在边框外缘的 `QGroupBox::title`。它现在在卡片内部绘制完整标题栏、展开箭头、悬停描边与按下高亮；标题不会被滚动区域从边框中间裁开。
- 标题栏是明确点击目标，点击即可展开/折叠；内容区和标题区完全分离。
- 跃迁表表头压缩为 `名称 / 从 / 到 / Δx / Δy / 幅度`，并让所有侧栏表头居中、在 UI 缩放时预留额外高度，避免高 DPI 下文字与顶边重叠或被截断。

## 兼容性与边界

- 现有已保存模型不会被自动改写；只有通过模板新建“Kagome / 双开 / 正三角形盘”时默认得到三格点原始元胞。
- 用户将旧六格点 Kagome 文档手动切换成三角盘时，系统不会擅自重建/丢失其自定义格点和跃迁；它仍按该文档的既有超胞计算。
- 本轮没有引入新的第三方 LaTeX 运行时。这样避免为了一个矩阵标签让发行版增加沉重的渲染依赖；矩阵已针对实际出现的 TeX 子集修正了 Qt 的嵌套脚本缺陷。
