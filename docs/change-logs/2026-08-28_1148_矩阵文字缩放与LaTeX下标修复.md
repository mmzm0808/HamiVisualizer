# 矩阵文字缩放与 LaTeX 下标修复

## 时间

2026-08-28 11:48（UTC+08:00）

## 问题

矩阵元文字在近期的视口优化中被固定成近似像素字号，导致单元格随视角放大而文字不再同比放大；同时半无限模型中的 `kx` 被作为普通字符绘制，`x` 没有落在 `k` 的下标位置。

## 实施

1. `MatrixView._ensure_text_items` 改为按单元格场景尺寸计算文字项缩放，文字项不再使用 `ItemIgnoresTransformations`。因此文字与矩阵单元格共享同一视图变换，滚轮、快捷键和窗口缩放保持一致。
2. 继续保留文字长度与单元格内边距约束，避免长表达式覆盖相邻矩阵元。
3. Bloch 表达式格式化统一经过 `format_bloch_elem`，半无限智能矩阵保留 `e^{±ik_x}` 的结构。
4. `to_html` 增加 Bloch 指数专用转换，将 `k_x` 转为 Qt 富文本的真实下标结构；幂指数仍以上标呈现。该路径不依赖系统安装 LaTeX，离屏和 Windows 环境均可复现。

## 验证

- 半无限矩阵在浅色 100%、深色 100%、深色 150% 下截图检查：文字随视角同比放大，`x` 位于 `k` 下方。
- 相关测试覆盖矩阵文字阈值、智能 Bloch 标签、富文本上下标和视口缩放。
- 当前阶段组合测试：`58 passed`；最终全量回归：`122 passed in 22.93s`。
