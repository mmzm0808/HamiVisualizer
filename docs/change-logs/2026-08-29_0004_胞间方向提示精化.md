# 胞间方向提示精化

## 发现

上一轮新增“胞内/胞间”统计后，半无限蜂窝模型仍把 x 方向胞间和 y 方向胞间合并显示。两者物理含义不同：只有 x 方向偏移会进入 `H1 e^{ik_x}` 的 Bloch 谐波，y 方向偏移属于有限方向连接。合并统计容易造成误解。

## 修改

- 关系摘要现在同时显示胞内总数、胞间总数、x 方向胞间数和 y 方向胞间数；
- 半无限模式明确标注 x 方向胞间生成 Bloch 相位 `e^(±ikₓ)`，并将 y 方向胞间标为有限方向连接；
- 保持 `HoppingTerm.cell_offset`、`H0/H1/extra` 建阵逻辑和 JSON/API 完全不变；
- 关系摘要的新增、编辑、删除生命周期继续共用同一刷新路径。

## 验证

- 语义菜单、关系摘要和右侧胞间 Bloch 谐波专项：`3 passed`；
- 全量回归：`196 passed in 47.65s`；
- 深色 150% 蜂窝半无限实景截图确认提示在表格上方完整显示，无裁切或横向漂移；
- 全预设巡检证据仍有效，未改变其它默认晶格的连线和盘形。
