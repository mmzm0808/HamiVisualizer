# 尺寸资源预估提示

## 目的

稠密 NumPy 后端在计算前才会进行安全预检。用户仍然可以编辑和保存大模型，但如果没有提前反馈，容易误以为界面卡住或无响应。

## 改动

- 左侧“边界”组在 NX、NY 下方加入实时稠密工作集估算；半无限按折叠后的 `NY × 格点数` 计算，双开按保守的 `NX × NY × 格点数` 上界计算；
- 小尺寸显示 MiB，大尺寸自动切换 GiB/TiB；超过 256 MiB 安全预算时明确提示“仍可保存，计算前会提示”，不修改输入上限；
- 尺寸输入框、滑块、边界切换、加载预设和添加格点都会即时刷新提示；该提示只读，不触发重建，不阻塞编辑；
- 离屏回归工具新增 `--resource-hint-demo`，用于在不真正分配大矩阵的情况下检查提示文案和多缩放布局。

## 验证

- UI 回归新增“实时提示且不限制编辑”测试，确认 30×30 OBC 仍可设置并在恢复 2×2 后回到安全提示；
- 资源提示浅色/深色 80%、100%、150%、180% 共 8 张截图已人工查看，边界组、滑块、输入框和提示文本没有裁切或错位：[资源预估多缩放审计组](../../.codex-artifacts/screenshots/leader-decouple-all-20260830/)；
- 全量测试：`246 passed`；编译通过。现有模型 JSON/API 和计算语义不变。
