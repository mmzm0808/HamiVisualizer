# 悬停系数身份提示

- **记录时间**：2026-09-01 13:06:48 +08:00（Asia/Shanghai）
- **范围**：晶格编辑态的跃迁悬停提示、连续鼠标移动、内/胞间关系辨识
- **性质**：交互可读性增强；不改变 Hamiltonian、矩阵数值、边界条件或模型文件格式

## 问题与目标

上一轮已经把重叠引线的 hover 解析集中到视口像素命中，并让点击后的系数编辑框跟随选中跃迁。
但悬停卡片仍然只显示一个孤立数字。在蜂窝、Kagome 和 SSH 等模型中，多个线段可能在同一
节点交汇，用户无法仅凭数字判断当前预览到底属于哪一条跃迁。

目标是让“悬停哪条线 → 看到哪条跃迁的系数”成为闭环，同时保留轻量、非交互式的预览，不让
提示卡抢走线条点击或触发画布平移。

## 实施内容

1. `LatticeView._show_hover_hop_label()` 现在生成两行信息：
   - 第一行：`#序号 · 起点→终点 · 内`，或 `#序号 · 起点→终点 · 外 ±dx,±dy`；
   - 第二行：当前绝对系数值，沿用原有有限数值格式；
   - 非默认参数族（例如 `t1`、`t2`）会追加参数名，避免同一几何线上的独立项混淆。
2. 提示卡 tooltip 同步包含完整身份和系数；卡片沿用固定像素尺寸与主题边框，背景不接受鼠标，
   因此只提供说明，不会遮挡或改变跃迁点击路径。
3. 保留上一轮的集中像素命中、单线高亮和轻微滞后规则：悬停卡片更新不触发场景重建，
   连续移动不会让未悬停线闪烁；离开画布时仍自动清除临时卡片。

## 兼容性与边界

- 悬停只发生在晶格编辑态且鼠标未按下时；普通浏览、格点拖动、添加跃迁和矩阵交互不受影响。
- 复杂幅度仍只在左侧跃迁表中精确编辑，悬停卡不会把不可编辑表达式伪装成可写标量。
- 提示卡文字可能覆盖其所在键附近的少量背景，但不会成为命中目标；点击同一条物理线仍会在右侧
  打开对应编辑框并显示相同的跃迁身份。
