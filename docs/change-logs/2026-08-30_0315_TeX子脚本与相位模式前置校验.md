# TeX 子脚本基线与跃迁相位模式前置校验

时间：2026-08-30 03:15 +08:00

## 用户目标

继续打磨 HamiVisualizer，重点消除两个会直接影响使用体验的问题：

1. 矩阵中的 `e^{ik_x}` 在不同绘制路径下应保持数学排版一致，`x` 必须是 `k` 的下标且整体留在抬高的指数区域，不应向主基线坠落；
2. 跃迁表的高级列不应让用户填入当前计算引擎尚未实现的 `directional` 方向依赖相位，再在点击计算后才失败。

## 修改内容

### 1. TeX 子脚本的光学基线调整

文件：`hamivisualizer/view/math_text.py`

- 将嵌套下标的 `SUB_DROP` 从 `0.26` 调整为 `0.16`；
- 仍保留下标相对 `k` 的下降关系，但减少其向主基线的坠落，兼容 Cambria Math、STIX Two Math、DejaVu Serif 等回退字体；
- 不改变模型表达式、复制出的 LaTeX 片段或矩阵缩放阈值，仅修正呈现层的脚本位置。

收益：小矩阵图元和大矩阵栅格叠加层都复用同一 `MathLayout`，所以 `e^{ik_x}` 的视觉基线更稳定，缩放时不会出现指数与下标分离。

### 2. 方向依赖相位的前置错误提示

文件：`hamivisualizer/view/control_panel.py`

- 跃迁表解析遇到 `phase_mode=directional` 时立即给出可操作错误：当前版本尚未支持该模式，请改用 `none` 或 `phase`；
- 对其他未知模式仍保留原有无效值校验；
- 表格的 tooltip 与实际可编辑能力保持一致，避免用户误以为该占位模式已经可以参与计算。

文件：`hamivisualizer/model/persistence.py`

- 保留旧模型文件对 `directional` 的读取兼容，使用户可以打开文件并修复，而不是在文件解析阶段丢失上下文；
- 一旦进入面板重建，前置校验会给出明确提示，核心计算仍不会把未实现模式静默当作固定相位。
