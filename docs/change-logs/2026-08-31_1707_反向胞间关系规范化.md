# 反向胞间关系规范化

## 记录信息

- 审计开始：2026-08-31 16:52:17 +08:00
- 实现与首轮证据：2026-08-31 17:07:29 +08:00
- 范围：画布跃迁编辑器的几何关系归并、半无限胞间偏移和反向厄米行
- 目标：同一条物理胞间键的正向/反向表格描述只显示一个输入框，且正负偏移方向都能稳定归并。

## 问题与根因

画布原有的关系规范化仅在偏移为负时交换端点：

```text
(from, to, dx, dy)  →  (to, from, −dx, −dy)  （仅部分负偏移触发）
```

因此，正向胞间行例如 `1 → 0, (dx,dy)=(0,+1)` 与反向行 `0 → 1, (0,-1)` 可能被视为不同关系，产生两个编辑器。该问题只影响画布编辑层；矩阵构造仍依据完整定向跃迁行正确计算，但用户会看到多余输入框或误以为存在两条键。

## 实施修改

### 几何键采用确定性无向规范化

`LatticeView._editor_geometry_key()` 同时构造：

- 正向键 `(from, to, dx, dy)`；
- 反向键 `(to, from, -dx, -dy)`。

取两个元组的字典序最小值作为唯一几何键，不再依赖偏移符号。这样覆盖：

- 胞内键；
- `dx` 正负的跨胞键；
- `dy` 正负的有限方向键；
- 同时含 `dx/dy` 的斜向胞间键。

该键仍与参数族键分开：同几何线上的 `t`/`t2` 等独立参数不会被错误合并，同参数族的反向行则会安静归并。

## 兼容性与影响

- 不修改 Hamiltonian、Bloch 谐波、边界条件、矩阵数值或模型 JSON 格式；
- 不改变用户可编辑的表格行，只改变画布代表编辑器的归并；
- 已有正偏移自定义模型无需迁移，重建画布后会自动得到稳定的单输入框；
- 表格仍保留全部定向行，适合检查相位方向、偏移和精确表达式。
