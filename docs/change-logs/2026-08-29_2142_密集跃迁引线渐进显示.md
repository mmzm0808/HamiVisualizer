# 密集跃迁引线渐进显示

## 背景

编辑态把所有跃迁系数集中到右侧导轨后，输入框不再遮挡晶格，但每个输入框都用“斜向虚线 + 横向虚线”回指原跃迁。在 Kagome、蜂窝、NP 等含有较多 NN/NNN 项的模型中，虚线会形成交叉网，晶格骨架和节点都难以辨认。

## 本次修改

- 保留右侧导轨中的全部系数输入框，不改变编辑入口和模型数据语义；
- 仅在密集的“系数：全部显示”模式启用渐进显示：初始隐藏全部导轨引线，避免交叉线网；
- 悬停物理跃迁线、悬停右侧输入框或聚焦输入框时，只显示该跃迁对应的斜向 + 横向两段虚线；移开后自动隐藏；
- 聚焦状态独立于悬停状态：鼠标离开输入框但仍在编辑时，引线继续保留；失去焦点且不再悬停后才收起，避免操作过程中导引突然消失；
- 通过 `QGraphicsProxyWidget` 的行号元数据保持输入框与模型跃迁行的稳定对应；输入框提示补充跃迁序号、起止格点、胞内/胞间偏移和分数输入说明；
- 引线隐藏/显示只切换已有图元的可见性，不重建场景、不改变参数、不抢焦点，也不会触发视图平移；缩放和导轨重新排布后仍会重新应用可见性策略；
- 物理 NN/NNN 连线保持原有语义和层级，渐进策略只作用于编辑辅助引线，不会隐藏真实哈密顿量连接。
- 切换“系数：全部显示”后，底部状态栏明确提示“悬停或聚焦查看对应引线”，降低隐藏引线后的学习成本；
- 使用文档同步说明“全部输入框 + 按需引线”的交互约定，避免用户把隐藏辅助线误解为跃迁数据缺失；
- 修复固定像素输入框在场景坐标中重叠造成的悬停误判：视图开启持续鼠标跟踪，并按实际视口像素矩形解析当前输入框；这样即使 Qt 的代理场景边界互相覆盖，用户悬停到哪一行就只会显示哪一行的引线；
- 新增真实视口鼠标事件回归，覆盖“指针移入右侧导轨字段 → 精确显示对应引线”的完整交互路径；

## 交互结果

默认画布保持“结构优先”，右侧数值仍然全部可直接编辑；需要核对关系时，把鼠标移到对应的键或输入框即可得到唯一、清晰的导引。这样避免了永久引线带来的遮挡，同时保留逐项审查所需的信息。
