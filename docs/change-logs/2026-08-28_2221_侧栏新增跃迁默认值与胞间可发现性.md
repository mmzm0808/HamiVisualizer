# 侧栏新增跃迁默认值与胞间可发现性

- 时间：2026-08-28 22:21 +08:00
- 范围：左侧“跃迁项”表格的 `+ 跃迁` 入口、半无限模式的胞间偏移编辑

## 问题

此前左侧按钮固定插入 `0 → 1`、`phase=phi` 的示例行：

1. 空白自定义、一维链、方格等单格点模型没有索引为 1 的格点，新增后会立刻进入非法模型状态；
2. 没有定义 `phi` 的模型会因为这个示例相位引入额外未知参数；
3. 半无限模式最关键的 `off_x/off_y` 列默认隐藏，用户通过表格添加跃迁后看不到胞内/胞间的区别，容易误以为无法添加胞间键。

## 修改

- 新增默认跃迁逻辑：多格点模型插入合法的胞内 `0 → 1` 实跃迁；单格点模型插入 `0 → 0, (off_x,off_y)=(1,0)` 的右侧胞间实跃迁；
- 新行使用 `phase_mode=none`、`phase=0`，不再隐式制造未定义的 `phi`；
- 新增行后自动选中并滚动到该行，便于立即检查；
- 半无限模式新增行后自动展开“高级列（元胞偏移 / 相位模式 / 符号）”，并在按钮提示中明确 `dx=+1/-1` 对应右/左相邻元胞；
- 模型 JSON、`HoppingTerm` 语义和 Hamiltonian 计算接口保持不变；这是输入入口的默认值与可发现性改进，不是破坏性格式变更。

## 验证

- 新增 UI 回归覆盖：一维链半无限单格点默认得到合法右侧胞间项；蜂窝半无限多格点默认得到合法胞内项；高级偏移列会自动展开；
- 目标专项：`1 passed in 2.45s`（覆盖三种模型场景与实际重建）；
- 全量测试：`187 passed in 50.04s`，仅保留 Windows 中文路径下原有 `.pytest_cache` 权限警告；
- `compileall` 与差异检查通过；
- 界面证据：[侧栏新增跃迁后高级偏移列](../../.codex-artifacts/screenshots/intercell-dialog-audit-20260828/side-panel-add-hop-dark-150.png)；语义入口证据：[半无限胞间跃迁对话框](../../.codex-artifacts/screenshots/intercell-dialog-audit-20260828/semi-intercell-dialog-dark-150.png)。

## 影响与风险

- 以前依赖“+ 跃迁”自动带入 `phi` 的工作流会看到更简洁的实跃迁默认值；如需相位，用户可在高级列或语义化对话框中显式选择；
- 单格点 OBC 在 `NX=1` 时右侧胞间项会被边界裁掉，这是物理上正确的边界结果，不会造成非法索引；
- 现有模型文件与预设不被改写，加载/保存格式向后兼容。
