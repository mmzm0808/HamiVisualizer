# 自定义胞间跃迁入口

- 日期：2026-08-29 00:53 +08:00
- 范围：半无限（x-Bloch）与双开模型的侧栏跃迁编辑器
- 目标：让用户不必先理解隐藏的高级列，也能直接创建任意整数元胞偏移的跃迁；同时保留表格作为批量检查和精确修正入口。

## 问题与原因

已有“按关系添加”菜单可以快速创建同胞、左右相邻胞和上下相邻胞的常用关系，但对 `dx=2` 等长程 Bloch 谐波仍要求用户展开高级列并手动填写 `dx/dy`。这条路径对第一次编辑半无限模型的用户不够直观，也容易把“胞间关系”和“实空间坐标”混淆。

## 修改内容

### 1. 新增自定义入口

在“按关系添加”菜单中加入“自定义胞间偏移…”。入口打开与可视化编辑共用的 `HoppingDialog`，因此支持：

- 任意整数 `dx/dy`，包括 `dx=2/3` 等高次 Bloch 谐波；
- 幅度表达式（例如 `-t2`、`0.3`）；
- 相位表达式（例如 `phi`）；
- 语义化的同胞、左右、上下关系和自定义偏移切换。

对话框确认后，新增行会自动选中、滚动到可见位置，并在半无限模型中自动展开 `dx/dy` 高级列。取消对话框不会修改模型。

### 2. 维持核心语义不变

- 仍由 `HoppingTerm.cell_offset=(dx,dy)` 作为唯一的胞间关系来源；
- 半无限 `dx` 进入 `H1` 或高次 `extra` Bloch 谐波，`dy` 只参与有限方向的元胞连接与边界截断；
- 显示编号、连线编号和矩阵索引逻辑不改变；
- 现有“+ 跃迁”快捷按钮和原始表格接口保持兼容。
