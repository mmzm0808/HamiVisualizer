# 缩放审计的截图证据统一为 100%

- 时间：2026-08-30 17:15:15 +08:00
- 范围：`tools/audit_editor_scales.py`、100% 截图输出契约、全预设编辑器几何回归、README 与测试。

## 发现

主离屏渲染工具已经拒绝 150%/180% 的新证据，但全预设编辑器审计脚本仍会在 80%、100%、
150%、180% 四个倍率下逐一保存窗口截图。这会让项目证据目录重新混入非标准倍率，造成浅色
截图和深色截图无法直接比较，也违背“任何时候只能使用 100% 验收截图”的工作约定。

## 处理

1. 保留 80/100/150/180% 的几何检查，因为它们仍能发现大字体、控件、输入框和编辑代理在
   不同无障碍倍率下的裁切、重叠与越界；
2. 新增 `_evidence_path()` 作为唯一截图出口，只有 `scale == 1.0` 才返回路径，其他倍率
   只执行断言，不创建或覆盖 PNG；
3. 输出统计从含糊的 `saved=N` 改为 `checked=88 saved=22 evidence_scale=100%`，明确区分
   “检查次数”和“落盘证据数”；
4. 22 张 100% 证据覆盖 11 个场景（10 个默认模型 + Kagome 三角盘）× 2 个主题；
5. README 明确写出：其他倍率只做几何回归，验收图片只保存 100%，避免后来维护者误用脚本；
6. 新增回归断言，保证 100% 返回 `*-100.png`，150% 返回 `None`，防止输出策略回退。
