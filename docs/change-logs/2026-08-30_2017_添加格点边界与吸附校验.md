# 添加格点边界与吸附校验

- 时间：2026-08-30 20:17:21 +08:00（北京时间）
- 范围：`hamivisualizer/view/lattice_view.py`、`hamivisualizer/view/control_panel.py`、编辑交互回归测试。
- 目标：让“添加格点”与拖动编辑遵守同一套吸附、元胞边界和重复坐标规则，避免非法输入在下一次重算时才暴露为格点或连线消失。

## 问题与根因

1. “添加格点”路径无条件按 `snap_step` 四舍五入；用户关闭“吸附”后仍不能输入自由坐标，工具栏状态与实际行为不一致。
2. 空白画布点击没有做原始元胞范围检查。对于斜元胞或被平移到中心的编辑元胞，点击元胞外会把非法局部坐标直接写入站点表，直到下一次 Hamiltonian 构建才失败，用户看到的现象就是刚添加的点/边莫名消失。
3. 站点添加信号直接连接面板槽，插件或合成事件可以绕过画布检查，把 `NaN`、无穷大或重复坐标写入表格。

## 实施修改

### 画布添加路径

- 关闭“吸附”时保留实际指针坐标；开启时才使用与背景网格同源的 `snap_step` 取整。
- 在斜/正交元胞中用 Bravais 基矢的分数坐标 `(u, v)` 检查 `0 ≤ u,v < 1`，元胞外点击被拒绝，不再静默夹到边界或污染模型。
- 新位置与已有编辑格点的距离不超过编辑清除阈值时拒绝写入，并给出“请换一个网格节点”的状态提示。
- 失败时保持“添加格点”工具为激活状态，用户可以立即换位置重试；成功时状态栏标明“吸附位置”或“自由位置”。

### 面板防线

- `ControlPanel.append_site` 增加有限数值检查和重复坐标检查，保护直接槽调用、插件调用及合成事件。
- 这道防线不改变表格的一基显示约定、内部零基索引或既有模型文件格式。

### 回归测试与证据

- 新增“关闭吸附保留自由坐标 / 开启吸附落到网格 / 元胞外与重复位置拒绝”测试。
- 新增面板直接调用 `NaN` 与重复坐标的防御性测试。
- 更新原有空白画布添加测试，使其在真实的高亮编辑元胞内点击，并在工具栏重排后重新解析视口坐标，避免把过期像素位置误当成用户点击。
- 新增离屏验收脚本，仅输出 100% 浅色/深色截图，模拟添加格点工具激活及元胞外点击后的可恢复提示：

## 兼容性与影响

- 没有破坏性 API 变更；信号签名、站点表格式、Hamiltonian 计算和保存格式保持不变。
- 以前依赖“把元胞外点击也写进表格”的非正式行为不再保留；界面会明确提示应在蓝色原始元胞范围内操作。
- 网格仍是纯视图层，网格点数量上限和吸附步长行为不变。
