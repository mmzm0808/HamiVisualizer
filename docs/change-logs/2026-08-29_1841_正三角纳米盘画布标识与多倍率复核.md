# 正三角纳米盘画布标识与多倍率复核

## 时间

2026-08-29 18:41 +08:00

## 动机

用户反馈前一轮截图中混用了矩形 Kagome 和三角纳米盘，肉眼难以确认当前样品的物理边界。虽然模型层已经产生严格等边轮廓，但画布没有文字上下文，容易把“普通 Kagome”“三角晶格”和“Kagome 三角纳米盘”误认为同一模型。

## 实施

在 `LatticeView.set_data` 的场景边界外沿增加非交互式形状标识：

- 仅当 DTO 提供三点正三角形外轮廓时显示；矩形、圆盘、六边形和半无限 ribbon 不增加无关文字；
- 标识内容为“正三角纳米盘 · 平直等边边界”，不依赖模板名称，因此对所有三角形有限样品都准确；
- 标识固定放在场景边距而不是某个格点、元胞或连线旁，避免遮挡物理结构；
- 作为普通场景项绘制，导出 PNG、组合视图和独立晶格页保持一致；
- 不接受移动、点击或编辑，层级仅用于信息展示，不会改变原有交互命中逻辑；
- 文本采用 Cambria Math 回退链，并按场景物理宽度限制显示宽度，随视图缩放保持可读而不变成巨大覆盖层。

## 回归

新增测试 `test_triangle_scene_has_a_clear_physical_shape_badge`，确认：

1. Kagome 三角盘恰有一个标识；
2. 标识包含“正三角纳米盘”和“平直等边边界”；
3. 标识位于展示层且不可移动；
4. 原有三角盘几何测试仍确认三边共线、等长，且所有格点位于边界内。

## 实拍验收

使用真实 PySide6 离屏窗口重新生成 Kagome 双开、6×6、3 格点斜原胞、最近邻三角盘：

- 覆盖浅色/深色与 80%/100%/150%/180% 共 8 张截图；
- 80% 和 180% 重点检查标识不越界、不压住顶点、不遮盖连线；
- 画面同时保留连续 Kagome 最近邻骨架、底边水平以及左右两条直线边界。

证据：[正三角纳米盘标识多倍率审计](../../.codex-artifacts/screenshots/leader-decouple-all-20260830/)。

## 验证结果

- 三角专项：`3 passed`；
- `compileall` 通过；
- 截图 8 张均为 `1440×920`，人工查看 80% 浅色和 180% 深色，未发现裁切、遮挡或控件越界；
- 无模型格式、矩阵建构、边界语义或对外 API 变更。
