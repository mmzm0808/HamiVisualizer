# 半无限跃迁关系常驻可见

- 日期时间：2026-08-29 02:14 +08:00
- 范围：控制面板跃迁表的胞内/胞间关系编辑与半无限端到端路径
- 状态：已实现、已截图、全量回归通过

## 用户场景与问题

半无限（x-Bloch）模式的底层数据结构已经支持 `cell_offset=(dx,dy)`，但紧凑跃迁表此前把 `dx`、`dy` 隐藏在“高级列”中。用户点击新增跃迁后，起点、终点和幅度可见，实际决定胞内/胞间关系的两列却不可见；这会让一个真正进入 Bloch `H1` 的跨胞项看起来与普通胞内项完全相同，也增加了“我无法添加胞间跃迁”的误解风险。

## 实施修改

### 1. 将关系字段提升为常驻核心列

- 紧凑模式始终显示 `dx`、`dy`；`0,0` 直观表示胞内，任一非零值直观表示胞间。
- “显示高级列”改为只控制 `相位模式`、`符号` 两个确实较少使用的元数据列，不再隐藏物理拓扑关系。
- 紧凑列宽按短整数字段重新排布，保留幅度和相位可编辑空间，避免为看关系而反复横向滚动。
- JSON schema、表格解析列序和外部接口均保持不变，没有破坏性变更。

### 2. 增强逐行可解释性

- 每行 `dx`/`dy` 单元格附加工具提示：胞内会显示“同一元胞”，胞间会显示目标元胞的有符号 `(dx,dy)` 偏移。
- 表格编辑、添加格点导致跃迁重排、预设/模型加载后都会刷新提示，避免提示与实际行内容脱节。
- 原有总计摘要继续保留：半无限模式同时展示 x 方向 Bloch 谐波、y 方向有限连接及斜向偏移统计。

### 3. 计算语义复核

逐项复核确认：

- `(0,0)` 仍进入 `H0`；
- `(+1,0)` / `(-1,0)` 规范化后进入 `H1`，`H(kx)` 自动补 Hermitian 共轭；
- `dy` 仍按有限 ribbon 行处理，越过边界的项明确计入截断统计；
- 长程 `|dx|>1` 仍进入 `extra` 并使用对应 Bloch 谐波；
- 晶格显示使用独立的中心/虚影拓扑，不把周期矩阵索引当成绘图编号。

## 兼容性与后续

此修复不改变模型文件格式，也不限制 NX/NY 或半无限研究规模。下一步若继续打磨，可在关系菜单中增加按当前选中格点作为起点/终点的快捷操作；目前“自定义胞间偏移…”已经提供完整端点选择，表格仍是批量检查兜底入口。
