# 可见编号统一从一开始

时间：2026-08-29 20:27 +08:00

## 背景

用户明确反馈格点编号通常从 1 开始。此前 OBC 晶格画布直接显示内部索引 `0, 1, …`，矩阵标尺和选中/复制提示也可能出现 0-based 坐标，和用户阅读习惯不一致。

## 改动

- OBC 晶格格点标签改为 `1, 2, …`；半无限模式的 `胞:格点` 标签和左右周期虚影继续复用同一组 1-based 标签；
- 矩阵四边冻结标尺改为 1-based。半无限标签显示为 `胞:格点`，双开标签显示为 `x胞,y胞:格点`，并保持元胞坐标与格点序号的结构可读性；
- 矩阵点击状态、复制内容和 LaTeX 坐标改为 `H[1,1]` 形式；绘图/计算 DTO 内部仍使用 0-based 数组索引，不改变哈密顿量数值、跃迁解析或持久化格式；
- 对第三方/历史结果增加保守兼容：能识别内置的 `0:0` / `0,0:0` 标签并转换，无法识别的自定义文字原样保留；
- 新增 UI 与控制器回归，覆盖 OBC、半无限、矩阵选择和复制路径。

## 兼容性与风险

这是纯显示语义调整，破坏性只体现在截图、状态栏和复制文本的编号从 0-based 变成 1-based；底层 Python/NumPy 矩阵索引仍为 0-based，插件若直接读取 `HResult.labels` 仍可获得历史原始标签。
