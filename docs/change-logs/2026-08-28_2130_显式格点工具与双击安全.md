# 显式格点工具与双击安全

- 完成时间：2026-08-28 21:30 +08:00
- 状态：完成
- 影响范围：晶格画布编辑、编辑工具栏、创建模型提示、Qt 交互回归。

## 目标

将“选择格点、移动格点、新增格点、添加跃迁”四种行为拆成清晰且互斥的交互状态，防止密集晶格中一次无意双击或一次检查性点击改变模型拓扑。

## 改动

1. 新增工具栏“添加格点”。启用后在画布空白处单击一次添加一个吸附到当前网格的格点；成功后自动退出工具。
2. “添加格点”与“添加跃迁”互斥，Esc 与再次点击工具均可安全取消。普通选择、移动和检查输入框不会自动启动任一工具。
3. 双击画布不再具有任何修改语义；它会给出简短状态提示，要求用户使用“添加格点”。这消除了旧的空白命中判定在密集线段、元胞框和代理输入框附近产生的随机感。
4. 工具提示、进入编辑模式的状态说明同步更新，侧栏 `+ 格点` 表格入口仍作为精确兜底。

## 兼容性

- 不改变模型文件、哈密顿量计算或既有表格添加格点功能。
- 旧的“双击空白直接新增格点”是唯一有意移除的快捷手势；它被更安全、可发现、可取消的显式按钮取代。
