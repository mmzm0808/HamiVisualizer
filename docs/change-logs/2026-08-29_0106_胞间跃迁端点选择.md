# 胞间跃迁端点选择

- 日期：2026-08-29 01:06 +08:00
- 范围：侧栏“按关系添加 → 自定义胞间偏移…”对话框
- 背景：此前自定义入口虽然支持任意 `dx/dy`，但起点和终点仍隐式使用默认的 `0→1`。用户想在多格点元胞中创建指定的胞间键时，需要再回到跃迁表手动改端点，流程不完整。

## 修改

### 端点选择

`HoppingDialog` 新增可选的端点选择模式。侧栏自定义入口会根据当前格点数量生成“起点”和“终点”下拉框，显示为用户熟悉的 1-based 格点标签，提交时转换回内部 0-based 索引。视觉编辑器仍传入已选端点，不显示下拉框，因此不会改变原有的“两次点击选键”语义。

### 与胞间关系统一

对话框中的端点选择、语义关系选择、任意整数偏移、幅度和相位会作为同一条跃迁记录一次提交：

- `dx=dy=0` 表示胞内项；
- 任一偏移非零表示胞间项；
- 半无限模式中的 `dx` 进入 `H1`/高次 Bloch 谐波，`dy` 仍按有限方向处理；
- 取消或关闭对话框不会写入表格。

README 已补充这条完整操作路径，表格仍保留为批量检查和兜底接口。

## 验证

- 新增 UI 回归测试：4 格点对话框选择格点 3→5，并选择右侧胞间关系，最终行准确写入 `[from=2, to=3, dx=1, dy=0]`；
- 原有半无限语义关系、表达式校验、自定义 `dx=2` 菜单测试继续通过；
- 生成并检查深色 150% 对话框截图：起点、终点、关系、幅度、相位和偏移输入框均有完整边框，无底部裁切或控件挤压。
