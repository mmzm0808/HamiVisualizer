# 编辑输入框可视边界修复

## 时间

2026-08-28 13:45（UTC+08:00）

## 变更

编辑模式的跃迁强度输入框使用固定像素尺寸，原先只按场景矩形约束；在 150% 界面缩放或切换到不同分屏后，最底部输入框可能被绘图区边界裁掉。现在由可见的 `QGraphicsView` 传入视口边界，以屏幕像素计算安全边距，再映射回场景坐标。控件仍贴近原跃迁中点，但始终保留完整可编辑区域。

## 验证

- 蜂窝、半无限、NY=4、最近邻模型在浅色 100%、深色 100%、深色 150% 离屏渲染；
- 视觉检查确认三条跃迁输入框、格点手柄、元胞轮廓和连线均可见；
- 全量测试基线：`122 passed in 26.68s`。
