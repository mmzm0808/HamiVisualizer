# 胞间跃迁对话框关系预览

- 日期时间：2026-08-29 02:57 +08:00
- 范围：半无限跃迁添加对话框的胞内/胞间语义反馈、长程偏移说明和边界提示
- 状态：已实现、已截图、全量回归通过

## 背景

此前对话框已经可以选择胞内、左右胞间、上下胞间和自定义 `dx/dy`，但用户只能从下拉框和数字框推断该项将怎样进入哈密顿量。对于半无限模式，尤其是 `dx=2` 或同时含 `dy` 的斜向项，这种反馈不够明确，容易把可计算的胞间项误认为输入失败。

## 实施修改

- 新增动态“关系预览”说明区域；
- 半无限 `dx=dy=0` 明确显示“写入 H₀（不产生 Bloch 相位）”；
- 半无限 `dx≠0` 显示对应 Bloch 谐波：`dx=±1` 为 `H₁`，`|dx|>1` 为 `Hn`，并保留 `dy` 的有限方向语义；
- 半无限 `dx=0,dy≠0` 明确提示这是有限方向连接，靠近边界时会截断；
- 双开模式提示超出样品边界的胞间项会按边界规则截断；
- 自定义偏移框变化时即时刷新预览，不改变模型 JSON 或计算接口。
