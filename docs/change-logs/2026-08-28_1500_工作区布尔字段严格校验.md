# 工作区布尔字段严格校验

## 问题

工作区加载时 `split_enabled` 使用 `bool(value)` 转换，JSON 中的字符串 `"false"` 会被 Python 当作真值，导致启动后错误打开分屏。

## 修改

- 仅接受 JSON 原生布尔值；其他类型（包括字符串、数字和 null）按关闭分屏处理；
- 增加字符串布尔值回归测试；
- 不改变正常工作区的保存格式和用户界面行为。

## 验证

- 全量测试覆盖正常多标签/分屏恢复和异常配置回退；
- 全量测试：`132 passed in 26.26s`（项目内 basetemp）；
- 浅色/深色/150% 离屏截图已生成并人工检查：`.codex-artifacts/screenshots/split-bool-audit-20260828/`；
- 测试、截图和临时数据仍只写入项目内 `.codex-artifacts/`。
