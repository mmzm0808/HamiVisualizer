# 编辑器审计帮助页与副作用修复

- 时间：2026-08-30 18:22:46 +08:00
- 范围：`tools/audit_editor_scales.py` 命令行入口、帮助页行为和测试隔离。

## 背景

项目的编辑器缩放审计脚本是维护界面质量的重要工具，但此前没有命令行解析入口。用户或自动化
系统传入常见的 `--help` 参数时，脚本会直接启动 10 个默认模型 + Kagome 三角盘的全套 Qt 审计，
创建截图并运行数分钟；这既不符合命令行工具习惯，也可能在误操作时污染证据目录。

## 修改

1. 在审计脚本入口加入标准 `argparse` 帮助页，明确说明 80/100/150/180% 的检查范围和仅保存
   100% 证据的约束；
2. 解析发生在创建输出目录、启动 QApplication 和遍历模型之前，因此 `--help` 只打印说明并
   立即退出，不产生截图、不修改模型或用户偏好；
3. 新增真实子进程回归，检查帮助页退出码、usage 和 100% 契约文字，并设置超时，防止未来再次
   把帮助调用误变成长任务。

## 验证

- 直接运行 `python tools/audit_editor_scales.py --help` 成功，仅输出帮助文本；
- 定向测试：编辑器审计帮助页 + 证据渲染帮助页共 `2 passed`；
- 本改动只涉及终端工具入口，没有 GUI 视觉变更，因此不新增截图；现有 GUI 证据仍全部遵循
  100% 界面缩放规范；
- 无模型计算、持久化、对外 GUI API 或证据输出路径变更。
