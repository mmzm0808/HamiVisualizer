# 跃迁端点用户编号统一

时间：2026-08-30 03:38 +08:00

## 问题

格点画布、矩阵行列标尺已经使用从 1 开始的用户可见编号，但左侧跃迁表的“从 / 到”仍显示内部 0 基编号。例如同一条连接在画布上标为格点 1 → 2，表格却显示 0 → 1。用户编辑时需要在两套编号之间来回换算，容易把胞内/胞间连接改错。

## 修改

文件：`hamivisualizer/view/control_panel.py`

- 跃迁表的“从 / 到”列统一显示 1…N，与格点表、画布标签和矩阵标尺一致；
- `get_hop_rows()` 读取表格时将显示编号转换回内部 0 基编号，哈密顿量构建、能带/波函数计算和 JSON 保存格式完全不变；
- 预设加载、模型打开、画布添加跃迁、关系菜单添加跃迁均只在 UI 边界转换一次，避免重复加一；
- 删除格点后的跃迁端点重排改为先在内部 0 基坐标处理，再写回 1 基显示值；
- 对手动输入的端点增加 `1..N` 范围校验，错误会明确指出用户可见编号范围，而不是等到矩阵计算阶段才失败；
- 保留空行映射修复：跃迁表空行和格点表空行不会改变真实行号或端点语义。

这是一项纯 UI 编号改进，不是破坏性数据迁移。旧模型仍按原有 0 基 JSON 读取，打开后表格显示为 1 基；再次保存得到的 JSON 结构与原格式一致。
