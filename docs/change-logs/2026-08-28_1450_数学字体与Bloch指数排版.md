# 数学字体与 Bloch 指数排版

- **日期**：2026-08-28 14:50（+08:00）
- **范围**：矩阵元文字、Bloch 相位指数、离屏渲染一致性

## 用户可见问题

此前矩阵元虽然把 `k_x` 转成了 HTML `<sub>`，但文本仍继承普通 UI 无衬线字体。放大后 `e`、指数和下标的字面高度、粗细与间距不协调，视觉上不像数学公式；大矩阵的视口叠加层还可能直接显示 TeX 字符串。

## 修改内容

### 1. 数学字体链

新增 `to_math_html()`，在兼容旧 `to_html()` 输出的同时，为矩阵公式增加字体链：

`Cambria Math → STIX Two Math → DejaVu Serif → serif`

Windows 上启动时仅注册系统已有字体，不向项目或用户目录复制字体文件；缺失 Cambria Math 时 Qt 自动回退，不影响启动。

### 2. 指数与下标

- `e^{ik_{x}}` 和 `e^{ik_x}` 均转换为 `e<sup>ik<sub>x</sub></sup>`；
- `x` 保持在 `k` 的下标位置，不再与 `i/k` 处于同一基线；
- 展示用负号统一为数学排版的 `−`，改善宽度与垂直对齐；
- `QGraphicsTextItem` 统一使用 Cambria Math 的字体度量，缩放时上下标随公式整体同比变化。

### 3. 兼容性

原有 `to_html()` 保留原始 ASCII `-` 与返回片段，避免破坏外部集成和既有测试；桌面矩阵渲染改用 `to_math_html()`。
