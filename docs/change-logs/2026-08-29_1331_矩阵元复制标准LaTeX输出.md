# 矩阵元复制标准 LaTeX 输出

- 时间：2026-08-29 13:31（+08:00）
- 范围：`hamivisualizer/view/matrix_view.py`、`hamivisualizer/view/main_window.py`、离屏回归工具和矩阵 UI 测试。
- 前置背景：上一轮新增了矩阵元复制，但复制内容主要面向屏幕阅读，直接粘贴进 LaTeX 时仍可能携带 Unicode `φ`、`ω`、中点乘号和 Unicode 减号。
- 目标：保留所见即所得的显示行，同时提供一行可直接继续编辑/粘贴的保守 LaTeX 源码，不改变矩阵计算和画布排版。

## 问题定位

矩阵显示层使用 Qt 富文本来保证缩放和大矩阵性能，显示层的 Unicode 数学符号是有意选择；但复制动作如果只把显示层字符串原样写入剪贴板，论文工作流还要手工替换符号。此前没有集中方法保证符号模式、智能 Bloch 模式和纯数值模式都能返回一致的源码片段。

## 实施修改

1. `MatrixView.cell_latex(i, j)` 以当前 `MatrixSceneData` 为唯一输入：
   - 符号模式优先使用 `sym_pretty` 的指数/下标结构；
   - 智能模式保留 `format_bloch_elem` 的紧凑物理表达；
   - 数值模式使用与画布相同的数值格式；
   - 统一将 `φ→\\phi`、`ω→\\omega`、`·→\\,`、`−→-`，不做宽泛转义，避免破坏已有的 `e^{...}` 与 `k_{x}` 花括号。
2. “复制选中矩阵元”现在写入两行：
   - 第一行：逻辑行列标签 + 当前显示式，便于人眼检查；
   - 第二行：`LaTeX: H[行,列] = ...`，便于粘贴到论文源码或笔记。
3. 旧矩阵、空选择和重算后的过期选择仍沿用上一轮生命周期保护；LaTeX 生成失败不会留下半截剪贴板内容。
4. 离屏工具的 `--matrix-copy-demo` 在真实复制动作后再抓取浅色/深色矩阵和深色 150% 菜单，确保新增行为和菜单入口同时有证据。

## 兼容性与取舍

- 未引入 matplotlib、浏览器引擎或额外字体文件；Qt 画布仍使用现有的数学字体回退链，复制能力不增加启动依赖。
- 复制行中的 `H[0,1]` 是可读的标识，不强行把模型逻辑标签（例如 `0:0`）伪装成 TeX 下标；用户可按需要包入自己的公式环境。
- 此改动只增加剪贴板输出，不修改模型 JSON、公共计算 API、矩阵分类或撤回历史。
