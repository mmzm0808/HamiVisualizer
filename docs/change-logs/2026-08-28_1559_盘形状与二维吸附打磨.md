# 盘形状、二维吸附与编辑器可用性打磨

- 时间：2026-08-28 15:59 +08:00
- 范围：OBC 有限盘几何、格点吸附、编辑态入口、模型持久化与离屏验收

## 需求对应

本轮针对石墨烯/蜂窝编辑时的三个实际痛点处理：

1. 吸附会把来自不同格点的 x、y 坐标拼接，拖动后可能落在不存在的几何位置；
2. 修改后缺少直观的恢复/关闭吸附入口，元胞间距入口隐藏在折叠区域；
3. NP 纳米盘和 Kagome 不能选择有限区域形状，导致只能使用矩形盘。

## 已实施改动

### 1. 二维几何吸附

- snap_position 改为完整二维候选匹配：优先吸附到真实格点坐标或拖动起点，再回退到用户设定的网格；
- 不再独立选择最近 x 与最近 y，因此不会产生“x 属于 A 点、y 属于 B 点”的幽灵位置；
- 新增编辑工具栏“吸附”开关，关闭后拖动完全自由；按住 Alt 仍可临时绕过吸附；
- “恢复位置”保留为编辑会话级几何恢复入口；左侧 |a₁| 间距、|a₂| 间距进入编辑模式自动展开，修改斜原胞长度时保持方向；
- 吸附开关与步长写入 ~/.hvisual/preferences.json，旧偏好文件缺失该字段时默认开启。

### 2. 可编辑有限盘形状

- Boundary.shape 新增 rectangle、triangle、disk、hexagon 四种掩膜；
- OBC 建阵使用同一组有效元胞坐标：矩阵维度、越界跃迁、格点位置和元胞轮廓保持一致；
- 主面板和新建模型对话框均提供“盘形状”选择；半无限边界按物理语义禁用并忽略该选项；
- 默认矩形模型保持 version 1 旧 JSON 结构；只有非矩形 OBC 才写入 boundary.shape，旧模型可无损读取；
- Kagome 可直接创建三角盘，NP 可创建三角/圆/六边形纳米盘。

### 3. 编辑器视觉

- 跃迁系数输入框在窗口和 UI 缩放后按实际像素尺寸重新排布；
- 输入框保持完整不透明边框，优先避让格点且不互相堆叠；
- 进入编辑模式自动展开格点/跃迁精确表格，为视觉编辑提供可靠兜底。

## 兼容性与风险

- 默认矩形边界、模型文件版本、values() API 和既有跃迁符号语义均保持不变；
- 非矩形盘是离散元胞掩膜，不是连续曲线；小尺寸盘会按最近元胞保证非空；
- 盘形状会改变 OBC 矩阵维度，这是预期的物理语义变化；半无限能带不受盘形状影响；
- 形状掩膜目前以规则网格为基础，后续可增加用户自定义多边形顶点或导入掩膜。

## 验证

- 全量回归：162 passed in 33.25s；仅有 Windows 路径编码造成的 pytest cache 警告；
- 二维吸附测试确认不再生成不存在的坐标，关闭开关后保留自由位置；
- OBC 三角形测试确认 Kagome 4×4 从 16 个元胞变为 10 个有效元胞，并同步得到 60 个格点与 10 个元胞轮廓；
