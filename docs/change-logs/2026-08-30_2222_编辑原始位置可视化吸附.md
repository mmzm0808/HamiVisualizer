# 编辑原始位置可视化吸附

- 时间：2026-08-30 22:22:33 +08:00（北京时间）
- 范围：晶格编辑背景网格、斜元胞精确吸附、拖动后恢复原始构型
- 目标：让蜂窝、Kagome、三角等斜晶格在拖动之后仍能直接看见原始位置，避免“内部确实能磁吸，但用户只能猜应当拖回哪里”的隐性功能。

## 问题与根因

编辑器已经保存进入编辑模式时的几何基准，并在拖动靠近原位置时优先吸附到精确基底坐标；工具栏也提供“恢复编辑前构型”。但原始坐标只存在于内部候选列表中，没有稳定的视觉提示。石墨烯 B 子格坐标常含 `sqrt(3)/2`，不一定落在用户选择的 0.25 笛卡尔网格上，因此拖动离开后，原位置既没有规则网格点，也没有专门标记，用户无法轻易手动复位。

## 实施内容

1. 背景吸附层现在同时处理当前格点和编辑会话开始时保存的基准格点。
2. 当前格点的非规则精确吸附位置使用细实线环；已离开的原始位置使用细虚线环，二者与普通笛卡尔网格点保持视觉层级区分。
3. 若原始位置本身已经落在普通网格点上，不重复绘制圆环，避免叠加成大白圈或第二个格点。
4. 当前位置和基准位置在 `1e-8` 精度下去重；所有环仍经过场景范围和 Bravais 原始元胞分数坐标过滤，不会在元胞外生成“看得见但吸不上”的假目标。
5. 标记使用 `Qt.NoButton`，位于格点和键的下层，不参与鼠标命中，不会抢走拖动、选择、添加跃迁或系数输入框的交互。
6. 更新基准参考坐标后只重绘网格装饰层，不重新计算哈密顿量、不重建系数代理控件，因此恢复/撤销后的视觉反馈即时且轻量。
