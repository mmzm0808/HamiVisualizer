# 绝对强度表达式安全写回

- 开始时间：2026-08-31 20:41:54 +08:00
- 完成时间：2026-08-31 20:52:47 +08:00
- 范围：画布跃迁强度编辑、表达式分类、失败回滚和同参数族归一化。

## 问题与根因

画布输入的是“绝对强度”，而跃迁表保存的是带符号、参数和相位的表达式。旧写回逻辑会把同名行直接猜成一个参数族，并把当前数值近似成整数比；因此 `t*u`、`t+1`、`sqrt(t)`、`I*t` 等表达式可能被静默改写，复杂项的物理因子会丢失。画布输入在控制器拒绝后也没有可靠恢复已提交的显示文本，容易出现输入框与表格/矩阵不同步。

## 实现

1. 在受限 SymPy 表达式层新增结构化分类：
   - `literal`：有限实常数；
   - `linear`：有限实数系数乘单一参数 `c·p`，支持 `-t`、`4*t`、`t/3`、`sqrt(3)*t`；
   - `unsupported`：多参数、非齐次、非线性、复振幅、未知或非有限表达式。
2. 关系身份同时包含几何、相位族、分类和唯一参数，保证同一条几何线上的 `t`/`t2`/`u` 不会混成一个输入框；等价正反向行仍只保留一个代表并同步写回。
3. 对同一参数族跨几何关系保留原有比例编辑语义：蜂窝 `1.2/0.3/0.3` 仍归一化为 `-4*t/-t/-t`。整数比仅在精确有理系数、分母和比例规模受控时启用，并在写回前做回算检查。
4. 非有理或不可安全公度的族采用局部缩放：只改选中的物理关系，其他关系的表达式和参数原值逐字保留；无法对零幅度或非有限值缩放时拒绝并提示用户转到表格/参数栏精确编辑。非整数比例不再被 `int()` 截断。
5. 画布输入采用 pending → accept/reject 两阶段事务；拒绝时恢复上一次已提交的文本、宽度、样式和强度快照。控制器以事务返回值判断成功，不受旧错误标签残留影响。

## 兼容性与影响

- 未改变模型文件格式、Hamiltonian/Bloch 计算接口、参数含义或已有合法表达式语法。
- 复杂表达式仍可在跃迁表中保存和精确编辑，只是不再允许通过“绝对强度”快捷入口猜测改写。
- 既有反向行同步、跨胞跃迁、撤回/重做和保存加载语义保持不变。

## 遗留风险

快捷入口仍刻意不替用户重写无法证明等价的复杂表达式；这会让少数非齐次模型需要回到表格编辑，但可避免静默改变物理模型。后续若要支持更丰富的符号变换，应增加显式预览、逐元回算和撤销确认，而不是放宽当前分类器。
