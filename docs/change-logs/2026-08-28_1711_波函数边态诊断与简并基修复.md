# 波函数边态诊断与简并基修复

- 日期时间：2026-08-28 17:11 +08:00
- 范围：双开边界 OBC 的本征态选择、波函数显示与边界态判读
- 状态：已实现、已截图、全量回归通过（`166 passed in 29.49s`）

## 背景

波函数页原本会把输入的目标能量映射为最近本征态，但页面只显示选中的本征能量和一项未经基线校正的边界权重。用户无法判断：

1. 输入的目标能量与真正选中的离散本征能量相差多远；
2. 边界权重高是因为态局域在边缘，还是因为有限晶格本身“外圈格点多”；
3. 严格简并的本征空间中，数值对角化器任意给出的线性组合是否掩盖了边界局域代表态。

这会让“为什么没有边界态”变成无法验证的视觉猜测。

## 核心计算改进

### 几何一致的边界掩膜

在 `model.hamiltonian` 新增 `edge_mask_for_positions(positions)`：按真实 `(x, y)` 坐标的最外圈生成边界掩膜，而不是按矩阵编号判断。这对斜原胞、三角盘、圆盘和六角盘均成立。求解器与视图共用该函数，避免“计算的边界”和“图上写的边界”不一致。

### 严格简并子空间的可解释基

`wavefunctions(H, positions=...)` 在且仅在**严格数值简并**的能量子空间内，对边界投影算符对角化：

\[
P_\mathrm{edge}=U_\mathrm{deg}^\dagger\,\Pi_\mathrm{edge}\,U_\mathrm{deg}.
\]

得到的正交基按边界权重分解，因此可以稳定展示最边界局域和最体内的代表态。该旋转只在严格简并范围内进行，近简并但能量不同的态绝不混合，所以仍是原哈密顿量的本征态。同步和后台异步波函数计算均传入真实格点坐标，行为一致。

### 能量选择反馈与边态判读

波函数页信息栏现在明确显示：

- 目标能量 `E_target`；
- 实际选择的态编号和离散本征能量；
- `ΔE = |E_selected - E_target|`；
- 边界权重；
- 均匀分布时的外圈基线；
- 边界富集倍率与“边界局域态 / 体内富集态 / 未见明显边界局域”的结论。

分类使用 `边界权重 / 外圈格点占比`。因此即使一个盘形状中外圈占大量格点，均匀体态也不会被误称作边态。

### 高缩放可读性修复

离屏 150% 审阅发现诊断文字在一行中与态选择器抢宽度，右端会被裁掉。现在将“本征态选择器”和“物理诊断”拆成上下两行；诊断标签可换行且保留完整 tooltip，窄窗口和 150% 下均不会吞掉边态判定。

## 新增回归

1. `test_wavefunctions_choose_edge_localized_basis_inside_exact_degeneracy`：构造一个含“内点 + 边点”严格二重简并的有限哈密顿量，验证旋转后的两态边界权重为 0 和 1，而能量不变；

## 物理边界

该工具现在能可靠展示模型中实际存在的边缘局域态，但不会凭空制造边态：若当前哈密顿量、参数、盘形状和目标能量不支持边态，界面会如实显示“体态 / 未见明显边界局域”，并通过 `ΔE` 告知所请求能量距离最近离散态有多远。
