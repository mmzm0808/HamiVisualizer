# 证据脚本帮助页修复

- 时间：2026-08-30 17:46:09 +08:00
- 范围：`tools/render_ui_regression.py` 命令行帮助、100% 证据倍率约束和回归测试。

## 背景

在继续做命令行入口审查时发现，运行 `python tools/render_ui_regression.py --help` 会直接抛出
`ValueError: unsupported format character`。原因是 `argparse` 会把帮助文本按 `%` 模板处理，而
“100%”中的字面百分号没有转义。这个问题不影响 GUI 计算，但会阻断用户查看证据脚本参数，属于
发布工具的可用性缺陷。

## 修改

1. 将帮助文本中的字面 `100%` 写为 `100%%`，让 argparse 在最终输出中还原为 `100%`；
2. 保留证据脚本仅允许 1.0（100%）界面缩放的既有契约，不改变应用本身 80%–180% 的无障碍缩放；
3. 新增真实子进程回归，直接执行脚本 `--help`，同时断言退出码为 0 且输出包含 `1.0（100%）`，
   确保未来新增帮助文本时不会再次引入同类崩溃。

## 验证

- 直接运行 `python tools/render_ui_regression.py --help` 成功输出完整 usage 和参数列表；
- 定向 UI 工具回归：`2 passed`（100% 倍率拒绝 + 帮助页可渲染）；
- 本改动为终端帮助页修复，没有新增 GUI 截图；项目 GUI 验收截图仍严格沿用既有 100% 口径，
  未生成任何新的非 100% 图片；
- 无模型格式、计算逻辑、持久化和对外 GUI API 变更。
