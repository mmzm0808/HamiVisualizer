# 自定义胞间偏移范围统一

- 日期时间：2026-08-29 02:34 +08:00
- 范围：半无限（x-Bloch）自定义胞间跃迁的 `dx/dy` 输入边界、长程谐波链路与高缩放对话框
- 状态：已实现、已截图、全量回归通过

## 发现的问题

模型持久化层接受 `cell_offset` 的每个分量 `−1000…1000`，半无限引擎也能将 `|dx|>1` 项放入 `extra` 并生成对应的 Bloch 谐波；但 `HoppingDialog` 的两个自定义偏移框却只允许 `−100…100`。界面文案声称“任意整数”，实际入口能力与文件格式不一致，长程项只能退回高级表格手工输入。

## 实施修改

- 新增 `CELL_OFFSET_INPUT_MAX = 1000`，对话框 `dx`、`dy` 使用与持久化校验一致的 `−1000…1000` 范围；
- 为两个输入框增加明确的范围工具提示；
- 保持快捷关系选项、端点选择、幅度/相位表达式及模型 JSON schema 不变；
- 没有放宽到无界整数，仍以模型层的安全上限防止异常输入；
- 长程项的物理语义不变：`dx=250` 会进入第 250 次 Bloch 谐波，而不是被截断成最近邻。
