# 截图证据整理

时间：2026-08-29 19:29

## 背景

项目在持续实拍验收过程中积累了少量重复截图、临时探针图和修复前诊断图。用户要求不要让旧截图长期堆积，同时历史日志中的有效证据必须保持可追溯。

## 清理策略

- 扫描 `docs/` 与 `docs/change-logs/` 中的全部 Markdown 本地链接；
- 文件链接保护对应文件，目录链接保护目录内全部截图；
- 仅把“未被任何文档链接引用”的 PNG 视为可清理对象；
- 删除前逐个确认目标是项目专属 `.codex-artifacts/screenshots/` 目录内的 PNG，不使用工作区根目录、通配递归或系统临时目录作为目标；
- 删除完成后移除空的证据目录，保留 `.gitkeep` 约定目录和全部有效证据。

## 结果

- 删除未被引用的中间截图 57 张，释放约 8.6 MiB；
- 删除由清理产生的空目录 8 个；
- 有效截图从 763 张整理为 706 张；
- 任何 Markdown 引用的截图或目录均未删除；
- 清理后的证据仍全部位于项目目录 `.codex-artifacts/screenshots/`，没有写入系统用户目录或工作区其它项目。

## 验证

- 清理前保护集合覆盖所有 Markdown 链接目标；
- 清理后重新扫描，保留的截图目录结构正常；
- 后续 Markdown 本地链接检查保持缺失 0；
- 代码、模型文件、测试数据和用户模型未受影响。

## 维护约定

以后每项功能只保留最终验收截图，并在对应修改日志和 `docs/持续打磨简报.md` 中登记链接；未引用的中间截图不进入长期证据集。
