# 编辑会话状态与纳米盘形状复核

## 发现

连续编辑同一个密集模型时，如果上一轮打开了“系数：全部显示”，退出编辑再重新进入会把全部输入框状态带回来。这个状态残留会让 Kagome、NP 等模型一打开就被输入框覆盖，和渐进式编辑的交互约定不一致。

## 修改

- 每次进入新的晶格编辑会话，显式重置“系数：全部显示”为关闭；
- 工具栏文字同步恢复为“系数：点击编辑”；
- 场景中的全部跃迁编辑代理同时清除，重新以最近邻骨架和按键渐进显示为起点；
- 不改变用户已经保存的模型、跃迁系数、元胞矢量或显示偏好；仅重置本次编辑会话的临时呈现状态。

## 形状与锚点复核

用 Kagome `NX=4, NY=4` 在 150% 深色界面下实景检查矩形、三角形、圆盘、六边形四种盘形。四种形状的有限矩阵、中心编辑锚点、最近邻连线和元胞轮廓均保持一致语义；中心编辑手柄不会漂浮到盘外。截图均保存在项目专属截图目录。

## 验证

- 新增跨编辑会话回归：确认“全部显示 → 退出 → 重新进入”恢复紧凑状态；
- 四种盘形状实景截图：Kagome 150% 深色各 1 张；
- 全量回归：`214 passed in 63.23s`，仅有既存的 Windows `.pytest_cache` 权限警告；
- 测试临时模型和 JSON 已清理，文档链接检查保持 0 缺失。
