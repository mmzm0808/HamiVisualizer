# 晶格编辑控件生命周期与项目整理

## 时间

2026-08-28 12:15（UTC+08:00）

## 问题

编辑模式中，单击格点、跃迁线或跃迁输入框后，偶发一个输入框或相关编辑元素消失。该现象不是模型数据删除，而是 PySide6 的 `QGraphicsProxyWidget` 没有被场景对象持有稳定引用，在鼠标事件后的垃圾回收阶段从场景中释放。

## 实施

1. `LatticeView` 增加 `_edit_proxies`、`_edit_guides` 和 `_edit_proxy_anchors`，在场景重绘前统一清理，在绘制后明确持有全部编辑控件，保证其生命周期与场景一致。
2. 跃迁辅助线设置为不可点击的视觉元素；输入框使用独立数据标识，站点手柄保持更高层级，点击节点不会误命中固定像素输入框。
3. 普通点击造成的亚像素位移不再被当成拖动；只有超过阈值才更新格点坐标。输入框失焦但数值没有变化时不触发重建。
4. 输入框位置在视图缩放通知中进行边界约束，避免控件完全落到绘图区外。
5. 将诊断截图统一归档到 `.codex-artifacts/diagnostics/`，诊断脚本归档到 `tools/diagnostics/`，主题截图脚本归档到 `tools/render_theme_shots.py`；项目根目录只保留源代码、正式文档和标准构建文件。

## 验证

- 新增“单击格点、跃迁辅助线、输入框均不破坏场景”的回归测试。
- 编辑模式回归：`24 passed`；最终全量回归：`122 passed in 22.93s`。
- 蜂窝半无限编辑场景完成浅色 100%、深色 100%、深色 150% 三重截图检查，确认格点、连线、元胞向量和 1.2/0.3 强度输入框均存在。
