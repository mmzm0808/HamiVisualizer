# Kagome 三角盘元胞边界降噪审计

- 时间：2026-08-30 07:30 +08:00
- 范围：Kagome 正三角形有限盘、3 格点斜原始元胞、100%/180% 界面缩放、浅色/深色主题、最近邻连线
- 结论：通过。格点和跃迁形成平直等边三角边界；画布不再把所有斜元胞四边形虚线铺到样品外，只保留一个原始元胞示意框和一条真实有限盘轮廓。矩阵掩膜、格点数、连线拓扑和编辑数据未改变。

## 发现的问题

Kagome 三角纳米盘采用 3 格点斜原始元胞后，有限掩膜本身已经正确选择 `cx + cy <= N - 1` 的三角层级，但画布仍逐个绘制所有元胞平行四边形。斜元胞的几何包络天然比其内部格点更宽，因此右侧和上方会出现伸出物理样品的虚线，用户会误认为是多余边界或错误连线。

## 修复策略

- 非矩形有限盘（正三角形、圆盘、六边形）仍完整保留 `cell_polygons` DTO，供编辑、检查和导出使用；
- 绘制时只显示第一个原始元胞作为“元胞参考”高亮；
- 物理样品只显示 `boundary_outline`，其轮廓由实际渲染格点包络计算，三角形三边共线且三边等长；
- 半无限条带和矩形双开样品继续显示完整元胞网格，不影响原有编号、周期虚影和编辑入口；
- 该改动只作用于视图层，不改变 `Boundary.active_cells()`、HamiltonianBuilder 或跃迁矩阵。
