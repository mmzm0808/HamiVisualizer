# 同几何线独立参数编辑隔离

## 记录信息

- 审计开始：2026-08-31 13:25:00 +08:00
- 实现完成：2026-08-31 16:34:20 +08:00
- 范围：画布跃迁系数编辑器、半无限/有限模型的重复关系归并、离屏证据入口与用户文档
- 目标：保留反向厄米共轭项的简洁编辑体验，同时避免把同一几何线上的独立物理参数错误合并。

## 问题与根因

画布原先只依据 `(from, to, off_x, off_y)` 的规范化几何关系生成代表编辑器。这样可以把正向、反向和重复表格行收束为一个输入框，但也会把不同参数族误判为同一项。例如：

- `t` 与 `t2` 作用在同一条几何线时，两个独立幅度只剩一个框；
- SSH 的 `t1` 与 `t2` 或插件模型中不同命名/不同表达式的贡献可能被隐藏；
- Haldane 等带方向相位的项如果几何重合，用户无法从画布知道哪个参数会被修改。

这不是矩阵计算重复计数，而是编辑层的语义丢失：表格仍保留完整行，画布却让用户误以为只有一个可调物理量。

## 实施修改

### 1. 分离几何关系和参数族

`LatticeView` 新增两个明确的内部判定入口：

- `_editor_geometry_key()`：只规范化端点和元胞偏移，负责识别一条无向物理线；
- `_editor_parameter_key()`：组合参数名、相位模式和相位表达式，负责识别独立的可编辑贡献；幅度表达式中的数值倍数不参与归类，以兼容 `-t` → `-4*t` 的比例归一化。

`_editor_relation_key()` 现在是两者的组合。因此：

- 同名、同表达式、同相位族的正向/反向/重复行仍只生成一个输入框，并在 tooltip 中列出合并的表格行号；
- `t`/`t2`、`t1`/`t2` 或表达式/相位族不同的重合项分别保留输入框，不再静默丢失控制入口；
- `phase_sign` 不参与参数族键，因为它描述方向，反向厄米行仍应共享同一幅度输入。

### 2. 增加关系标签辨识

当一条几何线承载多个独立参数且模型足够紧凑、会显示关系徽标时，徽标追加参数名，例如 `胞内 · t`、`胞内 · t2`。两个右侧输入框仍位于稳定导轨中，并分别由斜向加水平虚线连接到同一条物理线，用户可以通过参数名区分编辑对象。

### 3. 扩展离屏证据入口

`tools/render_ui_regression.py` 增加 `--independent-parameter-demo`，使用隔离的两格点模型构造同一几何线上的 `t` 与 `t2`。该入口只写入指定 `.codex-artifacts` 目录，不修改内置预设和用户模型，用于持续验证明暗主题下的可读性。

## 影响与兼容性

- 未修改 Hamiltonian、Bloch 谐波、边界条件、模型 JSON 字段或公开计算接口；
- 只改变画布编辑器的代表行筛选和紧凑关系标签；
- 旧模型中同几何线的不同参数现在会显式出现多个可编辑项，这是对原有物理语义的恢复，不是破坏性模型格式变更；
- 表格仍是完整精确兜底，任何行都可继续检查和编辑。

## 后续观察

密集模型默认采用渐进显示，独立参数项仍通过表格、物理线悬停和“系数：全部显示”入口可达。若用户希望在密集模型中默认显示所有独立参数，可在后续偏好设置中增加“按参数族展开导轨”的显示策略，而不改变本轮的物理判定。
