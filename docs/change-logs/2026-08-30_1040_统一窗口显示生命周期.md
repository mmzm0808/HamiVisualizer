# 统一窗口显示生命周期

## 发现的问题

`MainWindow` 中存在两个同名 `showEvent`。Python 类定义会以后一个方法覆盖前一个方法，导致早先写好的首次视图适配逻辑实际上不可达；工作区恢复、比较视图延迟刷新和普通窗口首次适配由两个互相覆盖的入口分别承担，后续维护很容易再次引入空白或未适配视图。

## 调整

- 删除被覆盖的重复 `showEvent`；
- 在唯一的显示入口中统一执行首次可见窗口的 `fit_all(force=False)`；
- 保留工作区分屏比较视图的 `QTimer.singleShot(0, _refresh_comparison)`，确保视口获得真实尺寸后再刷新比较缓存；
- 不改变模型计算、矩阵数据、标签顺序或保存格式。

## 验证

- 工作区恢复专项测试：`2 passed`，确认 NP/SC 标签、活动模型、分屏状态、比较模型和晶格场景矩形均恢复；
- 实际创建两个窗口并恢复工作区，第二个窗口的比较晶格数据非空，`sceneRect` 有效；
- 离屏证据：[恢复后的深色工作区](../../.codex-artifacts/screenshots/workspace-lifecycle-audit-20260830/workspace-restored-dark-100.png)；右侧比较晶格可见，中心合并视图和左侧控制栏均可用；
- 全量回归：`308 passed in 82.82s`；
- 编译检查：`python -m compileall -q hamivisualizer` 通过。

## 影响与回滚

这是窗口生命周期代码的去重和职责合并，不涉及破坏性接口。若需回滚，只需恢复被删除的重复方法即可，但会重新引入 Python 后定义覆盖前定义的隐患。
