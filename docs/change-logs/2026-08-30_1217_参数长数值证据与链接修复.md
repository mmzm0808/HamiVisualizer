# 参数长数值证据与链接修复

- 日期：2026-08-30 12:17:12 +08:00
- 范围：参数表长数值验收、简报相对链接、项目离屏验收工具

## 发现的问题

1. 参数长数值旧日志从 `docs/change-logs` 指向 `.codex-artifacts` 时少了一层 `..`，链接实际落到不存在的 `docs/.codex-artifacts`；
2. 旧日志仍引用 180% 临时截图，既已被清理，也不符合当前“新增截图统一 100%”的验收口径；
3. 简报位于 `docs/` 根目录，却使用了 `../assets`，导致 README 活动截图链接指向项目根目录下不存在的路径。

## 实施修改

- 新增 `tools/render_parameter_value_100.py`，固定 `1920×1200` 和 100% 界面缩放，定位参数名为 `t` 的单元格并输入 `0.333333333333`，分别生成浅色/深色完整窗口截图；
- 实际运行工具并将输出写入项目专属 `.codex-artifacts/screenshots/parameter-value-audit-20260830/`；
- 修正旧日志链接为 `../../.codex-artifacts/...`，移除已清理的 180% 证据，只保留 100% 浅色/深色截图；
- 修正简报根目录活动截图链接为 `assets/screenshots/...`；
- 不改变运行时源码、模型计算、持久化格式或用户配置。
