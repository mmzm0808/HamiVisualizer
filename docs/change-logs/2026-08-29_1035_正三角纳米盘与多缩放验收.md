# 正三角纳米盘与多缩放验收

时间：2026-08-29 09:30–11:10 +08:00  
范围：有限纳米盘掩膜、Kagome 三角盘物理几何、全预设形状回归、不同 UI 缩放截图验收

## 问题与判定标准

旧版的 `triangle` 掩膜用 `cx + cy` 的索引和直接裁切，因此在 Kagome 的 `2 × 2√3` 原胞上显示为直角三角形。它没有使用实空间元胞基矢，换一个斜元胞后也无法保证三条边的物理长度一致。

本轮以以下标准修复并验收：

1. 正三角形必须在**真实实空间**中构造，而不是在索引方格中构造；
2. Kagome `NX=NY=6` 的有效元胞层数应为 `6 → 4 → 2`，不再沿一条索引对角线裁切；
3. 有限矩阵、晶格显示、编辑锚点和边界截断必须使用同一份有效元胞集合；
4. 不能仅用 150% 截图代表所有 DPI：要检查 80%、100%、120%、150%、180%，并覆盖浅色/深色主题；
5. 不额外绘制会穿过真实格点的“理想轮廓线”。离散纳米盘以实际保留的格点/元胞为准，避免视觉边界与哈密顿量有效自由度不一致。

## 实施内容

### 1. 真实基矢下的等边三角形掩膜

- `Boundary` 新增只读派生几何 `shape_vectors`；它由当前 `a1/a2` 或 `Lx/Ly` 生成，不写入用户模型 JSON；
- `Boundary.triangle_outline()` 在 `a1` 方向建立局部正交坐标，取可放入有限样品包围范围的最大等边三角形；
- `active_cells()` 用每个元胞原点的真实坐标做三边同侧判定。对 Kagome `a1=(2,0)`、`a2=(0,2√3)`、`6×6`，顶点为 `(0,0)`、`(10,0)`、`(5,5√3)`，三条边均为 `10`；
- 控制器会在每次重建时从面板的当前元胞尺寸/矢量重新推导基矢，因此用户修改原胞间距后，三角盘掩膜也随真实几何同步刷新；
- 保留没有 `shape_vectors` 的旧 Boundary 调用的兼容回退，旧 JSON 与第三方直接模型构造不会失效。

### 2. 视觉与缩放验收工具

- `tools/render_ui_regression.py` 新增 `--ui-scale`：可对指定 80%–180% 的界面比例同时输出浅色、深色截图；未传参数时保持既有 `100% + 150%` 文件命名和行为；
- 重新渲染 Kagome 正三角形盘的 80%、100%、120%、150%、180% 两主题截图；
- 重新渲染 8 个默认模板在 OBC 正三角形盘下的浅色/深色截图，确认这不是 Kagome 专属补丁；
- 额外复核半无限蜂窝编辑态和矩阵放大态的 80%、120%、180% 截图：编辑按钮、跃迁输入框底边、状态栏、矩阵四边标尺均完整可见。

## 兼容性与风险

- 这是内部 Boundary 派生几何增强；模型 JSON 结构、`shape` 字段、跃迁 `cell_offset`、矩阵索引接口均未改动；
- 一维链等本质一维模型在“正三角形盘”选择下仍呈线状，这是其维数决定的正常显示，不伪造二维三角外观；
- 非矩形盘在离散元胞层面呈台阶边缘，属于有限尺寸晶格的真实离散边界；矩阵和可视化共享同一掩膜，故不会出现“图是一个盘、计算是另一套边界”的情况；
- 无破坏性变更。
