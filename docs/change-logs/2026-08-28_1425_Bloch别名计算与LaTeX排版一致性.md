# Bloch 别名计算与 LaTeX 排版一致性

## 问题

矩阵视图和格式化器已支持 `kx`、`k_x` 两种波矢写法，但参数收集只排除 `kx`，符号数值化也只把 `kx` 替换为当前滑块值。使用可读写法 `k_x` 时，可能出现多余参数控件或数值计算找不到参数。

## 修改

- 参数收集同时排除 `kx` 与 `k_x`，两者都视为内置波矢；
- 符号矩阵数值化同时识别两个别名并注入当前 `kx` 值；
- 保留现有 LaTeX/HTML 排版输出，`k_x` 继续渲染为 `k` 的下标 `x`；
- 增加别名参数收集回归测试。

## 验证

- `collect_symbols(["k_x + t", "kx - phi"])` 只返回用户参数 `t/phi`；
- 全量测试：`131 passed in 22.53s`（项目内 basetemp）；
- 矩阵专用离屏截图覆盖浅色、深色、150% UI，并人工确认 `k_x` 的 `x` 位于 `k` 下标；截图目录为 `.codex-artifacts/screenshots/bloch-alias-audit-20260828/`；
- 没有改变模型文件格式或公开接口。
