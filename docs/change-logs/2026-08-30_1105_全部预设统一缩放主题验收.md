# 全部预设统一缩放与主题验收矩阵

## 背景

此前简报只挑选了“浅色 100%”和“深色 180%”两张代表图，比较时容易把主题差异和界面缩放差异混在一起。本次补齐同一窗口、同一模型标签集合、同一结果页的完整 2×2 证据，并覆盖全部默认预设及独立的 Kagome 三角纳米盘动作。

## 统一条件

- 窗口截图尺寸：1920×1200；
- 场景：同一多模型工作区，11 个模型标签同时打开，当前结果页为“矩阵+晶格”；
- 主题：浅色、深色；
- 界面缩放：100%、180%；
- 每个预设的四张图只改变主题和缩放，模型参数、标签集合与窗口尺寸保持一致；
- 截图使用应用启动时的稳定 UI 字体与数学字体配置，避免离屏验收因字体回退产生误判。
