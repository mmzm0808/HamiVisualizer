# 当前矩阵 LaTeX 复制

- 时间：2026-08-30 17:34:23 +08:00
- 范围：矩阵视图、编辑菜单、剪贴板、结果状态门控、测试与 100% 菜单证据。

## 背景

矩阵视图已经能够以数学字体显示符号和 Bloch 相位，但用户在论文、报告或外部计算中仍需要
手动抄录整张矩阵。逐个复制单元格既慢又容易漏掉共轭项，也不能保证使用与当前视图相同的符号
表达式。本轮增加完整矩阵的 LaTeX 复制入口，不改变矩阵计算和画布上的无外层括号排版。

## 实现

1. `MatrixView.matrix_latex()` 遍历当前矩阵并复用既有 `cell_latex()`，保持符号、数值、参数名、
   `e^{i\phi}` 和 `e^{\pm i k_x}` 的一致表达；输出标准 `bmatrix` 环境，适合直接粘贴到 LaTeX。
2. 编辑菜单新增“复制当前矩阵 LaTeX”，快捷键为 `Ctrl+Shift+L`；复制成功后状态栏显示当前矩阵
   维度，用户不需要离开当前标签页。
3. 结果门控与 PNG/SVG/PDF 导出一致：尚未计算、结果过期或计算失败时动作禁用；矩阵为空或超过
   4096 个元素时给出可恢复错误，不分配过大的剪贴板文本。
4. 只读复制操作不修改模型、撤回历史、最近模型记录或用户偏好；画布上的 MATLAB 风格无外层
   括号保持不变，导出文本的 `bmatrix` 括号属于文档语义。

## 兼容性与风险

- 无破坏性 API、模型 JSON 格式或持久化变更；原有选中单元格复制快捷键保持不变。
- LaTeX 复制采用完整矩阵的 `bmatrix`，若目标文档需要无括号排版，可在外部改为 `array` 环境；
  画布仍按 MATLAB 风格不显示外层括号。
