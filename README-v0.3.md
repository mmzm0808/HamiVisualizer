# HamiVisualizer 0.4

HamiVisualizer 是一个面向晶格模型科研与教学场景的 Python/Qt 桌面工具。用户可以用格点、
Hermitian 跃迁和参数表达式描述单轨道标量模型，并交互查看哈密顿量矩阵、晶格、纳米带能带与
有限体系本征态。

项目源自 `HamiltonVisualizer.m`，但 Python 版采用数据驱动模型，不再把 NP/SC 写死在建阵函数中。

## 0.4 工作区体验

- 顶层模型标签支持同时打开、复制、重命名、关闭和拖动排序多个模型；每个模型独立保存参数、
  边界、结果页、晶格编辑模式以及视图缩放/平移状态。
- “视图 → 分屏比较”提供两个独立结果视窗，可比较不同模型，也可对照同一模型的不同结果；
  模型数据同步而视图缩放互不干扰。
- “文件 → 新建模型”提供 NP、SC、空白、方格、一维链、SSH、Haldane、蜂窝、三角和 Kagome 模板，可选择
  仅格点、最近邻或最近邻+次近邻；文件菜单另有“新建 Kagome 三角纳米盘”快捷入口，
  直接创建双开 6×6、3 格点斜原胞和三条平直等边边界的三角盘。普通 Kagome 模板仍可用于
  矩形样品与半无限 ribbon。
- 晶格页提供浏览/编辑模式：拖动格点默认吸附网格，按 Alt 自由移动；删除使用 Delete，
  “添加格点”和“添加跃迁”都是显式工具，避免普通点击误改模型。半无限模式下，开启“添加
  跃迁”后还可以直接点击左右虚影格点，程序会把它们转换为相对元胞偏移 `dx/dy`；左侧表格
  与“其他关系…”菜单仍是精确检查和长程胞间项的兜底入口。编辑工具栏提供“恢复编辑前构型”，
  只恢复进入编辑模式前的格点与元胞矢量；参数和仍然有效的跃迁保留，完整回退请使用 `Ctrl+Z`。
- 编辑态的“系数：全部显示”会把所有跃迁强度输入框集中放到右侧导轨。密集模型默认收起
  辅助引线，悬停对应跃迁或输入框、以及聚焦输入框时才显示该项的斜向+横向导引，避免
  引线交叉遮挡；输入框提示中还会给出跃迁序号、起止格点和胞内/胞间偏移。“显示次近邻”
  是独立的物理连线图层，不会因打开全部系数而自动出现。
- 每个模型有独立撤销/重做历史，默认 10 步；自动保存、撤销上限、计算防抖、吸附间隔与
  80%–180% 全界面缩放可在“编辑 → 偏好设置”中调整。
- 模型默认保存为 `~/.hvisual/models/*.hvisual`；工作区布局与偏好分别保存在
  `~/.hvisual/workspace.json` 和 `~/.hvisual/preferences.json`。模型文件仍是安全、可分享的 JSON。

- SSH 模板使用两格点原胞与显式胞内/胞间跃迁 `t1`、`t2`。在双开边界下将 `t1` 调小、`t2`
  调大即可观察接近零能的两端局域态；半无限模式则将 `t2` 作为明确的胞间 Bloch 项显示。
- Haldane 模板在同一蜂窝斜原胞上加入相反方向的复数次近邻相位 `±φ` 与子格质量 `m`，
  可直接查看复矩阵元和开隙能带；当前版本不自动计算 Chern 数，仍保留所有格点/跃迁的精确编辑入口。

## 能力边界

当前稳定支持：单轨道标量 Hermitian 哈密顿量、半无限/OBC 边界、自定义格点与固定相位跃迁、
符号/数值/智能矩阵显示、能带、OBC 本征态、JSON 存取、PNG 导出，以及 NP/SC MATLAB 对拍。

当前不支持内部自旋/轨道矩阵、非 Hermitian 模型、方向依赖相位编辑器、二维 PBC、圆柱、
半元胞和拓扑不变量。这些属于后续产品能力，不是现有接口的隐藏功能。

## 安装与启动

推荐使用干净的 Python 3.12 环境：

```powershell
conda create -n hamivisualizer python=3.12 -y
conda activate hamivisualizer
python -m pip install -r requirements.txt
python main.py
```

也可以使用 `python -m hamivisualizer.main`。安装项目后可以运行：

```powershell
python -m pip install -e .
hamivisualizer
```

### NumPy / PySide6 兼容性

本项目当前测试栈为 PySide6 6.6.x，因此依赖锁定 `numpy>=1.26,<2`。如果终端出现
“A module that was compiled using NumPy 1.x cannot be run in NumPy 2.x”，请执行：

```powershell
python -m pip install "numpy>=1.26,<2"
```

不要忽略该警告；ABI 不兼容可能导致崩溃。入口会在导入 PySide6 前给出可操作的错误信息。

## 使用流程

1. 从“文件 → 新建模型”选择模板，或打开已有 `.hvisual` / JSON 模型。需要检查一维拓扑端点态时可选 SSH。
2. 定义 `from → to`、元胞偏移、幅度、相位模式和相位。侧栏可直接选择“胞内”或“胞间”，
   “其他关系…”可选择左右/上下胞间或打开“自定义胞间偏移…”一次填写起点、终点、任意整数
   `dx/dy` 与相位；在半无限晶格页也可直接从中心格点点到左右虚影，自动得到相应 `dx`。
   表格仍可用于批量精确检查。
3. 参数面板自动提取 `t`、`phi`、`omg` 等自由符号；`phi` 按 π 计并支持 `1/13`、`1/4` 等分数输入。
4. 半无限模式设置 NY 与 `kx/π`；OBC 设置 NX×NY。
5. 查看矩阵、晶格、能带或本征态；OBC 波函数页可按能量选择最近本征态并显示边界权重，点击矩阵元查看详情。
   编辑态拖动格点时不会把两个格点自动吸附到同一位置；需要故意重合时可关闭吸附或按住 `Alt`，再用表格精确检查。
6. 模型会自动保存到 `~/.hvisual/models/`（工作区布局与偏好在 `~/.hvisual/`）；也可另存为独立 `.hvisual` 文件或导出当前标签页 PNG。

矩阵与晶格区域支持滚轮缩放、`+/-` 缩放和左键拖拽平移（晶格按“适应窗口”基准相对缩放，不会因坐标单位过小而跳变）；矩阵单元在屏幕像素达到可读阈值后
自动显示文本，缩小视图时自动隐藏细节以保持流畅。按 `0` 可恢复适应窗口。

输入变化后旧结果会标记为“已过期”；只有成功构建后才恢复导出。较大规模的谱计算在后台执行，
连续编辑产生的旧任务结果不会覆盖新模型。

## 模型语义

`Site` 索引必须连续，坐标必须有限、唯一并位于 `[0,Lx)×[0,Ly)`。

一条 `HoppingTerm` 表示：

```text
from_site in cell c  →  to_site in cell c + (off_x, off_y)
```

用户只定义一个方向，反向 Hermitian 共轭由程序补全。负偏移和 `from_site > to_site` 合法；
程序按物理键规范化，而不根据矩阵行号丢弃跃迁。同一物理键的等价反向副本会去重。

半无限模式支持任意整数 `off_x` 跨胞偏移（远程项以对应 Bloch 谐波进入矩阵）；OBC 可使用更远偏移。
on-site 项必须为实数。
`cell` 与 `site` 只是基底排列，必须具有相同本征谱。

## 安全表达式

允许数字、参数名、`pi/E/I`、`+ - * / **`，以及 `sqrt/sin/cos/tan/exp/log/abs`。
属性访问、下标、导入、任意函数调用、超长或过深表达式会被拒绝。外部 JSON 在修改 UI 前会经过
完整 schema 与表达式验证，保存使用同目录临时文件和原子替换。

## 边界公式

半无限模式：

```text
H(kx) = H0 + H1 exp(i kx) + H1† exp(-i kx)
```

OBC 直接构造有限 Hermitian 矩阵。进入 `eigh` 前会检查非空、方阵、有限值与 Hermitian 误差。

## 性能与交互

- kx 单独变化走缓存快路径；
- 能带分块构造，避免一次分配 `nk×N×N` 张量；
- 80 阶及以上谱计算进入 Qt 线程池；
- 64 阶以上矩阵使用单张栅格图，避免 `N²` 个 Qt 图元；
- 9–64 阶矩阵在放大到可读尺寸后懒加载文本，避免初始刷新卡顿；
- 物理 y 轴统一向上，组合视图与波函数保持纵横比；
- 用户缩放和平移在结构未变化时保持；半无限周期晶格的虚影按展开后的开边界显示序号绘制，
  周期跨元胞项仍独立由 `H1 exp(±ikx)` 计算。

当前仍使用稠密矩阵。数千格点或只求少数本征态的场景应在后续引入 SciPy 稀疏后端。
为避免误输入极大 NX/NY 时直接触发危险的内存分配，当前后端在建阵前会做约 256 MiB
工作集预检；超出预算会给出可恢复提示，但不会禁止模型保存或收紧 NX/NY 的输入范围。
