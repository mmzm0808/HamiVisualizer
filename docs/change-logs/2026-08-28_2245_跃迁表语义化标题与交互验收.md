# 跃迁表语义化标题与交互验收

- 时间：2026-08-28 22:45 +08:00
- 范围：左侧跃迁表的用户可见列标题、半无限胞间编辑入口、跨缩放视觉验收

## 修改

- 将显示标题从实现字段 `name/from/to/amp/mode/phase/sign` 改为 `名称/起点/终点/幅度/相位模式/相位/符号`；`dx/dy` 保留为物理上明确的元胞偏移记号；
- 内部 `HOP_COLS`、表格列序、模型 JSON 字段、`get_hop_rows()` 返回键和 Hamiltonian 构建逻辑完全不变；
- 保留半无限新增后自动展开高级列的行为，用户可以在同一表格中直接把 `dx` 改为 `+1/-1` 完成右/左胞间连接；
- 新增界面回归，确认标题语义化但内部 schema 仍可被解析器消费。

## 视觉与跨场景验收

- 空白单格点半无限模型：新增行显示 `0→0, dx=1, dy=0`，没有非法索引或未知相位；
- 蜂窝半无限模型：新增行显示合法胞内 `0→1`，高级列可切换为胞间；
- 150% 深色窗口滚动到跃迁区后，表格边框、标题、偏移值、按钮和底部“立即计算/取消计算”均完整可见；
- 重新渲染全部 8 个内置预设的半无限最近邻+次近邻代表画面，参数表、矩阵 LaTeX 标签、晶格节点和虚影没有裁切或空白；
