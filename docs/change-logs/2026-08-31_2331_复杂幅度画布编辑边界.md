# 复杂幅度画布编辑边界

- 开始时间：2026-08-31 23:10:11 +08:00
- 完成时间：2026-08-31 23:31:39 +08:00（定向测试、全量回归与 100% 明暗证据完成）
- 变更类型：交互安全、编辑边界、回归防护
- 影响范围：控制器画布编辑上下文、复杂跃迁表达式的 UI 呈现；不改变矩阵计算、表格编辑、保存格式或公开 API

## 背景

共享跃迁身份模块已经把幅度表达式分成 `literal`、`linear(parameter)` 和 `unsupported`，但控制器此前只检查表达式是否“能求值”。因此 `t*u`、`t+t2` 或 `I*t` 虽然会被正确计算并画出物理连线，仍可能被加入画布的标量强度编辑上下文。用户点击后才发现该快捷入口无法安全写回，造成“看起来能编辑、实际被拒绝”的误导。

## 修复

在 `ViewController._push_lattice` 构建 `edit_hops` 时，先调用共享 `classify_amplitude(...).editable`：

- `literal` 和实数一次齐次式（如 `-t`、`4*t`、`sqrt(3)*t`）继续生成画布输入框，并沿用既有比例归一化与撤回/重做；
- `unsupported` 表达式不进入画布编辑层，因此没有 proxy、leader 或可激活的临时输入框；
- 物理边线和矩阵完全使用原始 `hops`，复杂表达式仍可在左侧表格中精确修改、计算和保存；
- 不支持的输入仍由表格/控制器原有错误提示负责，不会因画布刷新崩溃。

## 取舍与回滚

本轮没有隐藏或删除复杂跃迁，也没有把复杂表达式强行改写成近似数值；只收窄了“单值绝对强度快捷编辑”的适用范围。若将来提供复数/多参数编辑器，可重新使用同一共享分类结果扩展新的 editor 类型，而无需改变现有表格和矩阵语义。
