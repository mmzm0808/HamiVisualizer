# 吸附网格提示环尺寸与交互边界

- 开始时间：2026-08-31 23:34:21 +08:00
- 完成时间：2026-08-31 23:47:05 +08:00（定向测试、全量回归与明暗截图完成）
- 变更类型：视觉交互修复、编辑可用性、回归防护
- 影响范围：晶格编辑态吸附网格装饰环；不改变吸附计算、格点拖动命中区域、晶格拓扑或模型文件

## 问题证据

`LatticeView.set_data` 原先在计算当前模型的格点半径之前调用 `_draw_snap_grid`。提示环因此使用上一帧的 `self._site_radius`：小尺度蜂窝模型会出现明显偏大的第二层圆环；如果用户自定义更大的元胞间距，上一帧半径又可能使提示环缩进到格点圆内部。装饰层尺寸不应依赖刷新顺序。

## 实施修改

1. 将网格绘制移动到当前场景依据真实 NN 边长计算并写入 `self._site_radius` 之后；
2. 提示环半径改为 `max(1.16 × _site_radius, _site_radius + 0.018)`，跟随模型物理尺度，不再使用固定 `0.205/0.285` 场景单位上下限；
3. 保持环的 `Qt.NoButton`、`z=-0.8` 和格点本身的 `shape()` 不变，环只提供位置提示，不扩大或抢占鼠标命中区域；
4. 对斜元胞和大间距模型沿用同一规则，不额外引入笛卡尔网格或改变 Bravais 分数坐标吸附。
