# 全模板编辑器边界与截图清理

- **日期**：2026-08-28 14:35（+08:00）
- **范围**：晶格编辑模式中的跃迁系数输入框、内置模板回归、项目截图归档

## 1. 问题与根因

跃迁系数输入框使用 `QGraphicsProxyWidget` 固定像素渲染。输入框位置保存的是代理控件左上角，但旧的边界限制按“半宽/半高”计算：

```text
旧逻辑：bottom - 12 / zoom
实际控件：height / zoom（输入框高度约 27 px）
```

因此输入框靠近画布底部或右侧时，焦点边框和下半部分可能越出 `sceneRect`，表现为“只露出上面大半”，尤其在点击获得焦点后更明显。

## 2. 实施修改

文件：`hamivisualizer/view/lattice_view.py`

- 按 `QLineEdit` 实际宽高换算场景尺寸；
- 将锚点明确视为代理控件左上角，而非中心点；
- 分别对横、纵方向执行完整尺寸边界限制；
- 当场景小于控件尺寸时使用场景中心回退，避免上下限反转；
- 不对当前视口做强制夹紧，保留平移后重新看到对应物理键的能力。
- 新增固定像素编辑框的焦点处理：获得焦点时自动滚入可视区并临时提升
  到节点之上，失去焦点后恢复普通层级，避免附近格点覆盖焦点边框或文字。

## 3. 全模板验证

新增测试 `test_edit_strength_editors_are_not_clipped_after_fit`，覆盖全部内置模板：

`NP`、`SC`、`空白自定义`、`方格`、`一维链`、`蜂窝`、`三角`、`Kagome`，并分别覆盖半无限与双开边界，共 16 个组合。检查内容为：

- 编辑器存在时，固定像素控件四边均在视口内；
- 空白模板无跃迁时允许没有编辑器；
- 输入框在初始适配、深色主题和 150% UI 缩放下均完整显示。

全量结果：**151 passed**（加入焦点可视性回归后）。测试仅保留一个既有的 Windows `.pytest_cache` 权限警告，不影响测试结果；运行临时目录仍由 `pyproject.toml` 收口到 `.codex-artifacts/test-runs/`。
