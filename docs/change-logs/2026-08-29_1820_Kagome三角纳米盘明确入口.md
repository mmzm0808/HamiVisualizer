# Kagome 三角纳米盘明确入口

## 变更时间

2026-08-29 18:20 +08:00

## 用户反馈

上一轮“全默认预设”截图审计为了覆盖所有模板，Kagome 使用了矩形形状，因此截图本身不能作为 Kagome 三角纳米盘的证据。用户指出：三角纳米盘的边界应当是三条平直边，而不是把矩形 Kagome 或其它三角晶格截图混用。

## 根因与判断

- 模型层已经支持 Kagome 双开三角盘：`3` 格点斜原胞 `a₁=(2,0)`、`a₂=(1,√3)`，元胞掩膜为 `cₓ+cᵧ≤N−1`，可得到严格等边三角形。
- 但普通“新建模型”对话框默认选中矩形，用户必须自行选择“双开 + 三角形盘”；文件菜单也没有 Kagome 三角盘的直达入口。
- 因此，已有功能和用户实际看到的入口之间存在可发现性断层；矩形 Kagome 截图很容易被误认为“三角盘实现”。

## 实施内容

### 1. 文件菜单增加专用入口

新增“新建 Kagome 三角纳米盘”，固定创建：

- 双开边界（OBC）
- `6×6` 元胞
- `3` 格点斜原胞
- 最近邻跃迁
- 三角形掩膜

普通 Kagome 模板仍保留，用于矩形样品和半无限 ribbon；没有破坏原有接口。

### 2. 新建对话框提供物理语义提示

当用户选择 Kagome + OBC 且尚未主动选择其它盘形时，盘形自动切到“正三角形盘”。预览文字明确说明“3 格点斜原胞”和“三条平直等边”。用户之后主动切换圆盘、六边形或矩形仍会被尊重，不会强制覆盖。

### 3. 回归保护

新增 UI 回归：

- Kagome + OBC 默认进入三角盘；主动选择其它盘形后不被重置。
- 专用菜单动作创建的文档必须是 OBC、triangle、3-site oblique cell，并且面板同步显示 triangle。

README 的快速使用说明同步补充了该快捷入口及其物理约定，避免文档、菜单和实际截图使用不同名称。

## 影响与兼容性

- 对外模型格式、普通 Kagome 模板、半无限 Kagome 均保持兼容。
- 仅改变新建入口的可发现性和 Kagome+OBC 的安全默认，不改变用户主动选择的盘形。
- 没有新增依赖，也没有改变数值哈密顿量的周期/开边界语义。
