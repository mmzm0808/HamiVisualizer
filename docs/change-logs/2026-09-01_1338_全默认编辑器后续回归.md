# 全默认编辑器后续回归

- 完成时间：2026-09-01 13:38:01 +08:00（北京时间）

## 覆盖范围

本轮使用项目现有 `tools/audit_editor_scales.py`，逐个创建并展示以下 11 个场景：NP、SC、空白自定义、方格、一维链、蜂窝、三角、Kagome、SSH、Haldane，以及单独的 Kagome 三角纳米盘。每个场景都进入晶格编辑态并开启全部系数输入框，分别检查 80%、100%、150%、180% 界面倍率和浅色/深色主题，共 88 个真实 Qt 视口场景。

每个场景检查：

1. 输入框完整矩形是否落在视口安全边界内；
2. QGraphicsProxyWidget 的代理尺寸是否覆盖真实 QLineEdit 尺寸；
3. 多个输入框是否互不重叠；
4. 输入框是否避让中心格点及可见周期虚影；
5. 100% 证据截图是否仍为完整窗口，而非裁剪探针图。

## 结果

## 结论与边界

这是一次跨模型视觉/几何回归，不改变模型 JSON、矩阵计算、默认参数或 UI 对外接口。80%/150%/180% 只用于几何断言，发布证据仍统一使用 100%；后续若修改全局字体、主题或编辑器布局，应优先重跑同一脚本。
