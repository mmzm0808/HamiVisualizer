# 左侧参数分组标题栏交互打磨

- 时间：2026-08-29 17:14 +08:00
- 范围：`hamivisualizer/view/control_panel.py` 中的 `CollapsibleGroupBox`，以及本轮标题栏离屏验收截图。

## 用户问题

左侧参数控制面板的小标题原本依赖 Qt `QGroupBox` 外缘标题绘制，视觉上像“插在线上”，在滚动和高界面缩放时不够清晰；用户希望有明确标题栏、可点击的描边/背景反馈，实际操作要亲民。

## 改动

1. 保留原有分组折叠语义，但把标题绘制为卡片内部的完整横向标题栏，标题不再占用卡片外缘的边框缺口；
2. 标题栏增加独立的 `AlternateBase` 底色、圆角边框和左侧强调色竖条，和卡片内容形成明确层级；
3. 鼠标悬停、按下和键盘焦点分别使用高对比强调色；焦点状态绘制虚线内框，方便键盘用户定位当前分组；
4. 点击改为“按下进入高亮、释放且仍在标题栏内才切换”，避免拖出后误折叠；标题栏支持 `Space` / `Enter` 键展开与收起，并补充无障碍名称和操作描述；
5. 没有改变任何模型、矩阵、跃迁、撤回或对外数据接口。

## 验证

- UI 专项回归：`hamivisualizer/tests/test_ui_hardening.py` 通过；标题栏点击展开/收起测试保持通过；
- 代码编译：`python -m compileall -q hamivisualizer` 通过；
- 离屏实拍：浅色 100%、深色 100%、浅色 180%、深色 180%，标题栏均有完整边框、标题和展开箭头，未出现顶边裁切或内容越界。证据目录：[panel-header-polish-20260829](../../.codex-artifacts/screenshots/leader-decouple-all-20260830/)；
- 高缩放画面重点检查了“边界”“参数（φ 以 π 为单位）”“波函数”三个分组：标题仍完整，内容与矩阵/晶格区域没有布局跳变。

## 成功标准

- 用户可一眼识别每个参数分组的边界和名称；
- 标题栏整块可点击，鼠标悬停/按下有明确反馈；
- 滚动、80%–180%界面缩放和深浅主题下不依赖外缘标题、不被裁切；
- 既有计算和模型编辑回归不受影响。
