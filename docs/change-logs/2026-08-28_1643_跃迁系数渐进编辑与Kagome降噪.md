# 跃迁系数渐进编辑与 Kagome 降噪

- 时间：2026-08-28 16:43 +08:00
- 范围：晶格编辑态跃迁系数输入、Kagome/长程模型可读性、150% 控制栏布局、离屏验收工具

## 用户问题

Kagome 4×4 编辑态把每一个跃迁定义同时绘制成数字输入框。输入框与虚线、格点集中在首胞附近，导致用户无法辨认结构，也无法判断某个数字属于哪一条跃迁。此前虽然修复了输入框下边框裁切，但“全部永久展开”的交互模型本身仍然不适合稠密晶格。

## 设计调整

采用渐进披露：先看清模型，必要时再编辑一个对象。

| 模型复杂度 | 默认画布行为 | 仍可获得的编辑能力 |
| --- | --- | --- |
| 至多 3 条可编辑跃迁（如最近邻蜂窝） | 保留全部紧凑输入框 | 直接输入每条键的物理强度 |
| 超过 3 条可编辑跃迁（Kagome、NP、含长程项模型） | 不显示任何常驻数字框 | 点击首胞中的跃迁线，只显示该键的一个输入框 |
| 任意复杂度 | 工具栏“系数：全部显示” | 需要批量核对时显式展开全部输入框 |

精确跃迁表始终保留，作为批量编辑、偏移/相位修改与检查入口；符号比例归一化、`t` 基准参数、撤销/重做及哈密顿量构建逻辑均未改变。

## 实施改动

### 1. 交互式跃迁命中层

- 新增 `_EditableHopGuide`：它是首胞跃迁线上的宽命中区域，空闲时完全透明，悬停时以蓝色虚线反馈，点击后打开该行系数编辑器；
- 透明命中层不再留下 Kagome 低透明“扇形”线条；实际 NN/NNN 线仍是结构的唯一视觉来源；
- 被选择的键以蓝色虚线短暂高亮，编辑框通过一条短虚线引线连接到真实键中点，确保数值归属明确；
- 多条长程键在同一投影位置重叠时，最上层命中项被选中，用户可使用左侧精确表复核/切换具体行。

### 2. 渐进式系数编辑器

- `LatticeView` 新增当前跃迁行和“全部显示”状态；复杂模型进入编辑模式时先不创建代理输入框；
- 点击跃迁线仅创建一个 `QGraphicsProxyWidget` 输入框；开启“系数：全部显示”才创建所有框；
- 小模型维持原来的直接体验，蜂窝最近邻的 3 条键继续默认可见；
- 系数输入框缩小为 68–96 px 宽、26–36 px 高，继续在样式完成后同步代理尺寸，焦点边框和命中区域保持完整；
- 主工具栏新增可切换的 `系数：点击编辑` / `系数：全部显示`，同时更新状态提示说明“点击元胞跃迁线改系数”。

### 3. 高缩放数值框布局

- 元胞长度和两个矢量分量改为在各行内平均分配剩余宽度；
- 150% 下 `2.00000000`、`3.46410200` 等 8 位小数完整可读，保持无水平滚动条；
- 仍采用可收缩布局，窄窗口时不会把结果区挤出屏幕。

### 4. 可重复视觉验收

- 离屏回归脚本新增 `--select-hop-row` 和 `--show-all-hop-editors`，可稳定渲染“默认简洁态”“选中单键态”“显式全显态”；
- 删除 4 张已被新版截图替代的中间图片，避免项目截图目录堆积。

## 兼容性与风险

- 模型文件、跃迁表字段、符号表达式、数值矩阵和外部保存接口完全不变；
- 复杂模型首次进入编辑态需要点击目标跃迁线，这是有意的降噪交互；工具栏和底部状态文案明确说明，并始终提供“全部显示”回退；
- 与实际格点重叠的长程键可能存在投影命中歧义，精确表格继续作为无歧义兜底入口。
