# 窗口级取消编辑工具

- 完成时间：2026-08-28 21:33 +08:00
- 状态：完成
- 影响范围：晶格编辑工具的取消操作、主窗口快捷键、编辑态回归验证。

## 背景

“添加格点”和“添加跃迁”已经是显式工具，但只在画布收到键盘焦点时监听 Esc。用户若刚点击工具栏、侧栏表格或跃迁系数输入框，Esc 可能不会传到 `QGraphicsScene`，导致工具仍处于待操作状态，下一次画布点击产生意外修改风险。

## 实施

1. 在主窗口注册窗口级 Esc 快捷键，编辑工具无论焦点在画布、工具栏还是侧栏输入控件，都能被取消。
2. 取消逻辑集中到 `_cancel_lattice_tools()`，同时清理“添加格点”和“添加跃迁”的内部起点、按钮选中态和状态提示；未进入编辑工具时 Esc 不改变普通输入行为。
3. 保留场景级 Esc 作为低层兜底，确保嵌入式晶格视图和独立测试场景仍可单独工作。

## 验证

- 完整晶格界面回归：`67 passed in 22.13s`。
- 新增交互断言：工具栏仍拥有焦点时按 Esc，添加格点工具立即关闭；两个拓扑工具切换时不存在潜在的后台状态。
- 编译检查、差异空白检查通过。
- 深色 150% 实景截图确认编辑工具栏、元胞表格、晶格画布和状态栏均完整可见：[最终截图](../../.codex-artifacts/screenshots/escape-tool-audit-20260828/np-edit-tools-dark-150.png)。

## 兼容性

- 不改变模型数据格式、哈密顿量计算或键盘 Delete 删除逻辑。
- Esc 仅在当前确实有显式晶格拓扑工具处于激活状态时产生取消提示；普通输入框编辑和视图缩放不受影响。
