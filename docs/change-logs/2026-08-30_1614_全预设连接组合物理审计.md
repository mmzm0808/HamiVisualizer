# 全预设连接组合物理审计

- 时间：2026-08-30 16:14:25 +08:00
- 范围：10 个内置预设、半无限/双开两类边界、三种连接级别，以及双开边界下的矩形/三角/圆盘/六边形形状。

## 发现与处理

此前已有“全部预设 + 全部有限形状”的基础厄米性测试，但它只覆盖“最近邻 + 次近邻”这一条连接路径，并且没有把斜元胞的真实基矢传给非矩形边界。这样无法阻止以下回归：某个连接级别遗漏胞间项、三角盘错误退化为索引方格，或某个预设只在默认矩形下有效。

本轮新增 `test_all_presets_connectivity_and_boundary_combinations_are_hermitian`，按控制器的实际建模语义重建每一组输入：

1. 遍历 NP、SC、空白自定义、方格、一维链、蜂窝、三角、Kagome、SSH、Haldane；
2. 遍历“仅格点”“最近邻”“最近邻+次近邻”；
3. 半无限模式在 `kx=0、0.371、π` 分别检查矩阵维度、有限性和厄米性；
4. 双开模式在矩形、三角、圆盘、六边形中检查同样不变量；
5. Kagome/三角等斜元胞把 `a₁/a₂` 物理基矢传入边界掩膜，确保几何测试和实际界面一致。

## 结果

- 组合审计：66/66 通过；没有空矩阵、维度错、NaN/Inf 或非厄米结果；
- 新增回归测试：`1 passed`；
- 全量测试：`319 passed in 232.65s`；
- `compileall` 与 `git diff --check` 通过；没有破坏性 API、模型文件格式或用户设置变更。
