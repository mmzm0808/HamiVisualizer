# 非矩形盘实空间度量

时间：2026-08-29 11:28–11:36 +08:00  
范围：圆盘/六边形盘掩膜、斜元胞预设、有限矩阵与晶格显示的一致性

## 问题

正三角形盘上一轮已改为使用真实 `a1/a2` 基矢，但圆盘和六边形仍按归一化索引 `(cx, cy)` 判定。对于蜂窝斜原胞、Kagome 的 `2 × 2√3` 元胞或用户输入的非方形元胞，这会把本应由物理距离定义的形状拉伸成索引椭圆/变形六边形；有限矩阵和画面虽然共享同一组索引，但形状语义与真实空间不一致。

## 实施

- `Boundary` 新增内部正交物理框架：沿 `a1` 建立单位轴，取朝向 `a2` 的垂直轴，计算所有有限元胞原点的真实投影范围；无 `shape_vectors` 的旧调用继续走原有归一化兼容路径；
- 圆盘在该物理框架中按等距半径判定，并只增加一个与离散网格步长相关的小边界余量，避免 4×4/6×6 样本丢失边界环；
- 六边形改为单位外接半径的正六边形不等式，仍保留离散采样余量，不再使用旧的索引斜率近似；
- 模板和控制器对 OBC 的三角形、圆盘、六边形统一传入真实元胞矢量；半无限模式仍忽略盘形状，元胞与 Bloch 计算语义不变；
- 三角形继续使用精确等边轮廓和同一物理框架，保证三种非矩形盘共享一致的度量基础；
- 仅新增几何判定，没有改动跃迁 `cell_offset`、矩阵排序、模型 JSON 对外字段或波函数求解接口。

## 物理与边界检查

- 对 `a1=(2,0), a2=(0,4), NX=NY=5`，圆盘/六边形均不再错误保留物理距离为 8 的底部中心元胞（拟合半径为 4）；
- 对 Kagome `a1=(2,0), a2=(0,2√3), 6×6`，圆盘保留 16 个元胞（行宽 `2,6,6,2`），六边形保留 12 个元胞（行宽 `2,4,4,2`），正三角仍保留 `6,4,2` 三层；
- 对蜂窝斜原胞，圆盘和六边形随 `a1/a2` 的方向与长度旋转/缩放，元胞框、格点、边界截断和有限哈密顿量共享同一有效元胞集合；
- 低尺寸离散样本仍强制至少保留一个中心元胞，不会因形状判定为空而导致空矩阵。

## 影响与风险

- 这是 OBC 非矩形掩膜的内部增强，对矩形盘、半无限模式和已有模型文件保持兼容；
- 由于形状现在按真实坐标判定，某些旧版自定义模型在圆盘/六边形下的有效元胞数量可能变化，这是修正物理语义导致的预期行为；
- 变化不涉及破坏性 JSON schema 变更；未引用的旧截图已按项目清理规则处理，当前证据均留在项目目录内。
