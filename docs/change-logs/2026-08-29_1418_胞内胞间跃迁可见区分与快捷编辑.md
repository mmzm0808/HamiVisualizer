# 胞内 / 胞间跃迁可见区分与快捷编辑

- 时间：2026-08-29 14:18（+08:00）
- 范围：`hamivisualizer/view/control_panel.py`、`hamivisualizer/tests/test_ui_hardening.py`、`tools/render_ui_regression.py`。
- 目标：让半无限模型新增或检查跃迁时，不必依赖记忆或反复横向滚动表格，就能确认一行是胞内还是胞间，并能快速修改常用的元胞偏移。
- 兼容性：不改变 `HOP_COLS`、JSON 字段、`HoppingTerm`、Bloch 建阵规则或撤回历史；属于纯 UI 辅助层改进。

## 问题定位

项目本身已经支持 `cell_offset=(dx,dy)`，并且侧栏有“+ 胞间”和语义化菜单。但紧凑跃迁表的行仍主要依靠用户阅读短小的 `dx/dy` 数字；当行很多、主题较暗或用户刚从画布添加跃迁时，胞内与胞间的视觉差异不够直接。手动改两列还容易只改一列，导致暂时无效或方向理解错误。

## 实施修改

1. **行级关系提示**
   - `_update_hop_relation_tooltips()` 现在为整行写入一致的关系提示，而不只是 `dx/dy` 两格；悬停名称、端点、幅度等任意单元格，都能看到“胞内跃迁（同一元胞）”或“胞间跃迁（目标元胞偏移 dx=…, dy=…）”。
   - 每行额外写入 `Qt.UserRole` 的轻量语义标记 `intra/inter/invalid`，只供 UI/自动化检查使用，不进入模型文件。

2. **主题自适应弱高亮**
   - 胞间行使用当前 Qt 主题的高亮色与表格底色混合，浅色和深色均可辨认；非法编辑中的 `dx/dy` 使用低强度警示色；胞内行保留原有交替底色。
   - 着色强度刻意低于选中态，避免用户选中行后看不清文本；不添加新列，因此 80%–180% 界面缩放下不会扩大侧栏布局。

3. **跃迁表右键快捷操作**
   - 在当前行右键可直接选择“设为胞内（0,0）”“设为右侧胞间（+1,0）”“设为左侧胞间（−1,0）”。两个偏移字段作为一次 UI 操作同步更新并触发正常重算/撤回链路。
   - “在表格中编辑 dx / dy…”保留精确入口，长程 Bloch 谐波、上下胞间或斜向偏移仍可输入任意合法整数；没有用快捷菜单替代完整表格兜底能力。

4. **回归工具与测试**
   - 离屏工具新增 `--hop-relation-demo`，生成同一模型在 80%、100%、150%、180% 和浅色/深色主题下的 8 张证据图。
   - 新增 UI 回归断言：行语义标记、整行工具提示、主题底色差异以及快捷偏移更新均有效。

## 影响、风险与成功标准

- 收益：胞内/胞间关系在不改布局的前提下更易扫描；常见方向无需手工双列编辑；主题和高缩放仍可用。
- 风险：这是视觉提示，不替代物理建阵验证；颜色可能受用户 Qt 调色板影响，因此测试只约束语义差异而不锁死 RGB 值。右键快捷操作仅覆盖常见 ±1 x 方向，其他偏移仍走精确编辑。
- 成功标准：全量回归无新增回归；`dx/dy` 与模型读取保持一致；快捷操作后 `get_hop_rows()` 与 Bloch `H1` 仍反映对应胞间关系；8 张多缩放/主题截图无控件或文字裁切。
