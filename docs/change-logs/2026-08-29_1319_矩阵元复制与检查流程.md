# 矩阵元复制与检查流程

- 时间：2026-08-29 13:19（+08:00）
- 范围：`hamivisualizer/view/matrix_view.py`、`hamivisualizer/view/main_window.py`、`tools/render_ui_regression.py` 与 UI 回归测试。
- 目标：在现有矩阵元点击高亮和状态栏详情的基础上，提供可发现、可撤销风险低的复制入口，方便用户把当前矩阵元带到论文、笔记或外部检查工具中。

## 问题定位

矩阵元点击已经能显示逻辑行列和表达式，但信息只能暂时显示在状态栏。用户若要复用结果，需要手工抄写，既慢又容易抄错。另一个风险是矩阵重算后旧选择仍可能被 UI 动作引用，必须让复制动作与当前矩阵修订严格绑定。

## 实施修改

1. `MatrixView` 增加 `selectionChanged` 信号和只读 `selected_cell` 属性：
   - 新矩阵数据到达时发出 `None`，清空旧选中状态；
   - 选中单元格时发出当前 `(row, column)`；
   - 保持“矩阵”页与“矩阵+晶格”页共享同一选中事实源，不读取具体视图的私有状态。
2. 主窗口“编辑”菜单增加“复制选中矩阵元”，快捷键为 `Ctrl+Shift+C`：
   - 未选中矩阵元时禁用，避免用户点击后得到空内容；
   - 复制内容使用逻辑标签和当前显示表达式，例如 `H[0:0,0:1] = -t·e^{iφ}`；
   - 成功后在底部状态栏短暂提示；剪贴板不可用或选择已过期时给出非模态红色提示。
3. 复制动作在菜单构建阶段绑定，因此历史单文档模式和多模型工作区都可用；没有改动 HamiltonianBuilder、模型文件格式或计算结果。
4. 回归渲染工具增加 `--matrix-copy-demo`，除普通选中截图外额外抓取真实编辑菜单弹出层，确保入口文字、快捷键和视觉状态可见。

## 兼容性与取舍

- 复制的是当前界面显示式，而不是未经用户确认的内部 SymPy 对象；这保证“复制所见即所得”，也避免把内部实现细节泄漏到模型文件。
- 选中状态是呈现层状态，不进入撤回历史，不改变模型 dirty 状态，不触发重新计算。
- `Ctrl+C` 保留给文本/表格原生复制，使用 `Ctrl+Shift+C` 避免抢占输入框的常用快捷键。
