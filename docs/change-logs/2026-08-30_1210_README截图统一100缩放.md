## 背景

- 通过项目离屏渲染工具在 `1920×1200` 窗口、100% 界面缩放下重新生成主界面、蜂窝编辑态、Kagome 正三角纳米盘和跃迁系数编辑态；
- 逐张查看浅色/深色输出，确认菜单栏、侧栏标题、晶格节点与连线、正三角三条平直等边和右侧系数框均未裁切；
- 将 README 与相关当前日志引用改为 `02-main-dark-100.png`、`04-editor-honeycomb-dark-100.png`、`05-kagome-triangle-dark-100.png`、`10-hop-editor-dark-100.png`；
