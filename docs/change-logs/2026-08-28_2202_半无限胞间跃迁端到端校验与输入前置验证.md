# 半无限胞间跃迁端到端校验与输入前置验证

- 日期时间：2026-08-28 22:02 +08:00
- 范围：半无限（x-Bloch）模式的“添加跃迁”工作流、跃迁表达式输入、全部内置预设的模型级审计
- 状态：已实现、已截图、全量回归通过

## 用户问题

用户反馈半无限模式下无法区分或添加胞间跃迁，担心新增的键没有进入周期矩阵；同时要求继续检查所有预设和实际交互，而不能只验证“控件能被点击”。

## 审计结论

1. HoppingTerm.cell_offset、build_ribbon() 的 H0/H1 分流以及 HResult.to_semi(kx) 的 Bloch 相位链路已经正确：
   - (0, 0) 保留为胞内项；
   - (+1, 0) / (-1, 0) 归一到跨元胞项并进入 H1 及其厄米共轭；
   - off_y 仍在有限的 ribbon 方向按元胞行截断；
   - 计算索引与显示用的中心/虚影编号没有混用。
2. 现有单元测试只验证了对话框和底层 H1，没有完整覆盖“编辑工具 → 对话框 → 面板行 → 控制器重建”的用户路径；本轮补齐。
3. 所有 8 个内置模板均以半无限和双开边界运行，矩阵在代表性 kx 下保持 Hermitian；三角盘、圆盘等有限盘也完成离屏核验。

## 实施修改

### 1. 添加跃迁对话框前置校验

HoppingDialog 现在在点击“确定”前复用项目的安全表达式解析器，检查幅度和相位字段：

- 合法表达式（如 -t、1/3、phi）正常关闭对话框；
- 语法错误会留在对话框中，显示可读的红色错误提示，不再把“重算失败”误认为胞间偏移失效；
- 主控制器仍保留最终模型校验，前置校验只是改善反馈，不改变外部模型格式。

### 2. 明确半无限编辑入口

“添加跃迁”工具提示补充完整语义：先选择元胞内两个格点，再在对话框选择胞内、左/右胞间或上下胞间；左右胞间会进入 Bloch 的 H1/kx 项。原有语义下拉框和自定义偏移仍可用。

### 3. 端到端回归

将显式连线测试改为真正的半无限跨胞行（off_x=1, off_y=0），并断言：

- 控制器向对话框传入 semi=True；
- 对话框返回的偏移写入跃迁表；
- 重建后格点数量不变，编辑工具自动退出，模型仍可继续计算。

## 兼容性与遗留风险

- 模型 JSON 仍使用原有 cell_offset 字段；没有破坏性格式变更。
- 跃迁表的高级列仍是精确兜底入口；对话框语义选择不会阻止手工输入任意合法整数偏移。
- 运行时仍受矩阵规模和硬件资源限制；本轮没有把大尺寸研究误判为可无限分配。
- 复杂模型的 NNN/长程键仍可通过普通浏览态开关和编辑态“显示次近邻”查看；这属于显示层选择，不会删除或改变物理项。
