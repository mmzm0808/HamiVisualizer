# README 重写、发布资产整理与生产字体几何修复

- 日期：2026-08-30 11:30 +08:00
- 范围：发布文档、打包元数据、截图资产、编辑态输入框几何
- 兼容性：不改变模型 JSON version 1、核心计算接口或用户模型语义

## 背景

旧根 README 只有安装命令和一个指向历史文件名的链接，且安装命令、运行方式、功能边界、
截图教程和发布检查都不完整。与此同时，生产字体初始化后 `QGraphicsProxyWidget` 的几何
尺寸可能比实际输入框高度小 2px，导致高缩放编辑态的底边被裁切；原有测试没有覆盖完整的
Qt 字体初始化生命周期。

## 实现

### 文档与打包

- 将完整中文使用手册迁移到根目录 `README.md`：补齐定位、目标用户、场景、功能矩阵、安装、
  NumPy ABI 排查、分步教程、模型语义、快捷键、性能边界、测试、目录结构、版本发布和故障排查；
- 把 `README-v0.3.md` 改为兼容性入口，避免旧书签失效；
- 将 `pyproject.toml` 的 `readme` 指向正式入口 `README.md`，让构建元数据和 GitHub 页面一致；
- 按 GitHub README、PyPA packaging、Keep a Changelog 和 SemVer 的公开规范组织内容与链接；
- 将 13 张经过完整窗口复核的截图固定到 `docs/assets/screenshots/`，README 只引用这些稳定资源，
  不引用系统临时目录或裁剪图。

### 编辑器几何

- `LatticeScene._refresh_editor_sizes()` 在设置实际编辑器尺寸后，同步设置代理的最小/最大尺寸、
  resize 和 geometry，消除样式/字体更新后代理几何滞后的裁切窗口；
- UI 缩放完成后由 `MainWindow._set_ui_scale()` 延迟触发一次编辑器重排，覆盖 Qt 事件循环中
  最终字体度量才确定的情况；
- 新增生产字体初始化回归测试，验证 150% 缩放下所有跃迁系数框的代理边界不小于实际控件。

### 本地文件归属

- `HamiltonVisualizer.m` 是旧 MATLAB 原型，仅保留在本地供参考；已加入 `.gitignore`，并从当前
  Git 索引移除。此提交不会再次上传它；已有远程历史不做破坏性重写。
