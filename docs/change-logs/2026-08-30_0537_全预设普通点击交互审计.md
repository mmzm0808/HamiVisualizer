# 全预设普通点击交互审计

- 时间：2026-08-30 05:37 +08:00
- 范围：10 个默认模型、半无限边界、晶格编辑页、100%/180% 界面缩放、浅色/深色主题
- 目标：验证用户在没有启用“添加格点/添加跃迁”工具时，普通单击只选择格点，不会误拖、误建、误删或让连线消失。

## 审计方法

1. 新建 NP、SC、空白自定义、方格、一维链、蜂窝、三角、Kagome、SSH、Haldane 预设，统一使用 `NX=4、NY=3、半无限、最近邻`。
2. 进入晶格编辑页并适应视图，用真实 `QTest.mouseClick` 事件点击第一个可见编辑手柄；不直接调用场景内部选择函数。
3. 点击前后逐项比较完整模型文档，检查格点数量、跃迁数量、元胞和参数均未改变，同时确认建键起点为空、建键工具未残留。
4. 每个模型在 100%/180% 和浅色/深色各保存一张截图，记录状态栏“已选择格点 1”及最终画面。

## 结果

- 10/10 默认模型通过普通点击不变性检查；没有出现格点消失、跃迁消失、隐式新增或画布平移。
- 10/10 模型的编辑工具状态均保持可解释：普通点击不会进入添加跃迁，也不会留下半个起点。
- 180% 深色 Kagome 和 100% 浅色三角代表图中，格点、元胞边框、虚影和侧栏均完整；底部状态栏能看到选择反馈。
