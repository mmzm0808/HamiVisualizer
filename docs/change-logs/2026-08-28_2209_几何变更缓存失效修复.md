# 几何变更缓存失效修复

- 日期时间：2026-08-28 22:09 +08:00
- 范围：盘形状切换、元胞矢量/间距编辑、控制器重建快路径
- 状态：已实现、已截图、回归通过

## 发现的问题

控制器使用签名缓存来区分“只改变 kx”和“需要完整重建”的输入。原签名包含边界类型、NX/NY、格点、跃迁和参数，却遗漏了：

1. OBC 的 shape（矩形、三角、圆盘、六边形）；
2. Lx/Ly 或斜元胞 a1/a2。

因此用户切换盘形状或调整相邻元胞间距后，签名可能保持不变，程序错误地走 kx 轻量刷新路径，旧矩阵和旧晶格画面继续留在屏幕上。

## 修复方案

- 将 boundary.shape 纳入重建签名；
- 读取控制面板当前的矩形元胞尺寸或二维元胞矢量，生成稳定的 cell_signature；
- 保留 kx 快路径：只有几何、拓扑、参数均未改变时才跳过完整建阵；
- 不改变模型 JSON 格式、矩阵排序或对外接口。

## 回归覆盖

### 盘形状

Kagome 4×4 OBC 从矩形盘切换到三角盘：

- 原有效元胞数：16；
- 新有效元胞数：10；
- 矩阵、节点和元胞轮廓均重新生成；
- 断言新旧 HResult 不同，避免误走 kx 快路径。

### 元胞间距

蜂窝半无限模型将 a1 长度放大 1.2 倍：

- 新旧 HResult 不同；
- Lattice.a1 精确更新；
- 几何跃迁位移与晶格显示同步更新。

## 风险与兼容性

- 这是缓存正确性修复，无破坏性 API 变化；
- 极大 OBC 尺寸仍可能受内存/计算时间限制，这与本修复无关；
- 视图显示开关仍走轻量刷新，不会触发不必要的矩阵重建。
