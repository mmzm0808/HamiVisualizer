# 边界截断状态反馈

- 时间：2026-08-28 23:24 +08:00
- 范围：双开边界下新增胞间跃迁的可解释反馈、最小模型验收

## 问题

双开模型中，跨越样品边界的跃迁按物理定义应被省略。例如 `NX=1` 的一维链只有一个元胞，右胞间项不会进入有限矩阵。此前计算结果仍显示“刷新 OK”，用户无法区分“边界截断”与“添加失败”。

## 修改

- 控制器状态栏现在保留正常刷新信息，同时追加：
  - 半无限有限方向被截断时：`有限方向截断 N 条`；
  - 双开目标胞越界时：`边界外跳过 N 条`；
- 只增加反馈，不改变边界物理、矩阵值、模型格式或跃迁编辑入口；
- 新增一维链 `NX=1, NY=1, OBC` 回归，验证右胞间键被正确截断且状态栏明确显示数量。

## 实景验收

- 深色 150% 最小双开模型中，底部状态栏显示红色高亮的“边界外跳过 1 条”；
- 矩阵、晶格和输入控件仍完整可见，没有新增布局裁切；
- 截图：[双开边界截断状态 · 深色 150%](../../.codex-artifacts/screenshots/boundary-status-audit-20260829/one-cell-obc-boundary-dark-150-status.png)。
