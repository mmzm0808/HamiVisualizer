# 画布跃迁行代表映射

## 记录信息

- 审计开始：2026-08-31 17:14:41 +08:00
- 实现与证据复核：2026-08-31 17:23:24 +08:00
- 范围：画布编辑器与左侧跃迁表之间的行号映射、合并行临时状态同步
- 目标：表格保留完整定向行时，任何一个等价行都能可靠地打开对应画布输入框，并让画布临时值与整组保持一致。

## 问题与根因

同族重复/反向跃迁在画布上只需要一个输入框，但表格仍保留每一行以便检查。原实现把画布代理的 `row` 设为代表行；如果外部事件、插件或未来的表格联动传入合并组中的其他行，`activate_hop_editor()` 会因找不到代理行而直接返回，用户看到“点了没反应”。`update_hop_strength()` 也只更新一个零基行，可能在主题切换或重绘前留下旧值。

## 实施修改

### 1. 统一代表行解析

新增 `_editor_representative_for_row()`，先按当前几何键与参数族生成代表列表，再在每个代表的 `_editor_rows` 中查找传入表格行。它同时覆盖：

- 同方向重复行；
- 反向厄米行；
- 正/负胞间偏移已经规范化后的等价行。

### 2. 激活与状态同步使用同一映射

- `activate_hop_editor()` 接收任意等价表格行，统一激活代表代理，并在状态栏说明合并行号；
- `update_hop_strength()` 对代表的全部 `_editor_rows` 更新 view-only strength 快照，避免下一次主题/缩放重绘恢复旧数值；
- 传入不属于当前模型的行仍安全忽略，不会创建幽灵输入框。

## 兼容性与影响

- 不改变表格行号、矩阵数值、Bloch 相位、模型 JSON 或公开接口；
- 仅增强画布编辑层对“代表行/合并行”的容错和反馈；
- 表格依旧是精确兜底，用户可以继续直接修改任意具体行。
