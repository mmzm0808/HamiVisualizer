# 矩阵公式缩放与布洛赫下标审计

- 时间：2026-08-30 07:15 +08:00
- 范围：矩阵视图、符号矩阵单元格、布洛赫相位公式、100%/180% 界面缩放、4 倍视图缩放
- 结论：通过。公式文字随矩阵视图缩放同步放大，`e^{ik_x}` 的 `x` 保持为 `k` 的下标，不再掉到主基线；浅色和深色主题均完成离屏复核。

## 本轮检查内容

1. **实际矩阵画布**：使用 NP 与 Kagome 半无限模型，在最近邻连接下打开矩阵页，分别以 100% 与 180% 界面缩放、4 倍视图缩放渲染。Kagome 场景包含 `-t·e^{ik_x}`、`-t·e^{-ik_x}` 以及带常数项的组合表达式，覆盖正负指数、多个矩阵块和边缘裁切。
2. **字体与公式布局**：矩阵单元格统一使用 `MathLayout` 的数学字体回退链（Cambria Math → STIX Two Math → DejaVu Serif → Times New Roman）。上下标按父原子布局，`x` 只相对 `k` 下移，同时整个 `ik_x` 作为 `e` 的上标抬高，避免 Qt 富文本嵌套 `<sup>/<sub>` 的二次下沉。
3. **缩放一致性**：小矩阵使用可缩放的 `MathTextItem`，大矩阵的栅格化文字按视图像素倍率重新计算字号；本轮截图中 100% 与 180% 的公式均无固定字号、重叠或裁切。
4. **解析与兼容**：保留 `to_html()` 的兼容输出；矩阵显示使用 `to_math_html()`/`MathLayout` 的数学排版路径，不新增外部 LaTeX 运行时依赖，避免用户安装完整 TeX 环境才能启动软件。

## 代码与回归

- `hamivisualizer/view/math_text.py`：保留分组、`^`、`_` 的受控 TeX 子集，并以父原子为基准计算上下标偏移。
- `hamivisualizer/model/symbolic.py`：将常见 `e^{ik_x}`/`e^{ik_{x}}` 归一为数学字体可正确排版的指数串；兼容接口仍输出原有 HTML 结构。
- 已有回归覆盖：普通 HTML 结构、数学字体包装、嵌套布洛赫下标、栅格化大矩阵、视图缩放字号增长；本轮离屏截图补充了 NP/Kagome 两类模型及明暗主题。
