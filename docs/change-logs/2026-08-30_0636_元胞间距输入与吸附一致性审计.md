# 元胞间距输入与吸附一致性审计

时间：2026-08-30 06:36 +08:00

## 背景

持续审计编辑态的“间距修改 → 重建 → 格点拖动/吸附”链路。目标是让几何输入、元胞框、编辑手柄和吸附参考始终使用同一组元胞矢量，并在输入阶段阻止会让模型延迟失败的无效尺寸。

## 发现与修复

1. `Lx/Ly` 长度框此前在统一初始化循环中被设置成了 `-1000…1000`。这与长度的物理语义冲突：用户输入负值时，两个负值还可能被 `get_cell_size()` 当成“自动间距”，错误直到下一次重建才暴露。
   - 现在 `Lx/Ly` 只允许 `0…1000`；0 仅表示自动，而且必须成对出现。
   - `a₁/a₂` 的四个分量仍保留有符号范围，斜元胞方向不会受影响。
2. `_apply_cell_vectors()` 与 `set_cell_vectors()` 现在即时检查有限性、非零长度、`a₂.y` 非零及不共线条件，错误会留在当前输入面板，不再以通用重建错误打断用户。
3. `set_cell_size()` 与 `set_cell_vectors()` 在写入前完成完整校验，并把外部列表转换成不可变数值副本，避免调用方后续修改列表而绕过几何签名缓存。
4. 验证间距修改后的运行时几何：控制器签名包含矩形尺寸/斜元胞矢量；重建会同步更新 `LatticeView._cell_vectors`、中心编辑锚点、元胞框、跃迁引线以及吸附参考的场景变换。编辑会话基线仍保留局部元胞坐标，因此“恢复编辑前构型”语义不变。

## 兼容性与影响范围

- 未改变模型 JSON 字段、Hamiltonian 计算或跃迁编号；只收紧了几何输入的非法状态，并强化了已有斜元胞编辑路径。
- 合法的矩形尺寸、斜元胞分量、自动间距和恢复/撤销行为保持兼容。
