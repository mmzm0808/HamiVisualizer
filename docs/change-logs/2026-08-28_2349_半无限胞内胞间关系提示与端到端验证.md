# 半无限胞内/胞间关系提示与端到端验证

## 背景与问题

半无限（x-Bloch）模型底层已经支持 `cell_offset=(dx,dy)`，但紧凑跃迁表默认隐藏高级偏移列。用户只看到“名称、起点、终点、幅度、相位”等基础列时，很难判断一行是胞内跃迁还是胞间跃迁，也不容易确认新增的右侧胞间项是否真的进入了 Bloch 哈密顿量。

## 实施内容

- 在跃迁表上方增加常驻的关系摘要，不增加横向列宽：实时显示“胞内 N 条 · 胞间 M 条”；
- 半无限模式明确提示“左右胞间项会生成 Bloch 相位 `e^(±ikₓ)`”；双开模式提示有限边界外跃迁会按边界规则截断；
- 表格输入处于暂时非法状态时显示“正在编辑”提示，恢复合法后自动回到统计摘要；
- 新增右侧胞间端到端物理回归：从语义化菜单创建 `dx=+1` 跃迁，验证 `H1` 非零且 `H(0)=-2、H(π)=+2`；
- 保持原有 JSON 字段、`HoppingTerm` 语义和矩阵接口不变。

## 验证结果

- 半无限跃迁/UI 专项：`3 passed`；
- 全量回归：`196 passed in 174.61s`；
- 150% 深色实景截图确认关系提示位于表格上方、无需滚动即可看到，侧栏和晶格区域没有新增裁切或横向漂移；
- 仅保留既有 `.pytest_cache` 权限警告，不影响测试结果。
