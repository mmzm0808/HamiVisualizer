# 全默认模板矩阵不变量审计

## 记录信息

- 审计开始：2026-08-31 17:48:30 +08:00
- 范围：10 个内置模型、半无限（x-Bloch）与双开（OBC）两种边界、最近邻与次近邻完整连接配置
- 目标：把“默认模型可用”从少数 NP/SC 对拍扩展为全部模板的统一数值不变量检查，防止某个较少使用的预设在切换边界或连接配置后产生 NaN、非方阵或非厄米矩阵。

## 审计方法

新增 `test_builtin_template_invariants.py`，通过公开的 `template_document()`、`Lattice`、`HoppingTerm` 和 `HamiltonianBuilder` 重建模型，避免绕过真实控制器路径。每个模板均使用：

- `最近邻+次近邻` 完整连接；
- `NX=3, NY=3`；
- 半无限模式的 `kx = -2.7, -0.4, 0, 1.2, 3.1` 五个代表点；
- 双开模式的有限矩阵；
- 方阵、有限值和 `H=H†` 三项断言。

这覆盖了普通正交元胞、蜂窝斜元胞、Kagome 六格点超胞、Kagome 三格点路径的公共建阵入口，以及含复相位的 Haldane 预设。

## 结果

- 10 个模板 × 2 种边界 = `20 passed`；
- 所有矩阵均为有限方阵，半无限每个测试波矢和双开矩阵均满足厄米性；
- 定向回归实测为 `20 passed in 1.00s`；随后完整回归为 `385 passed in 202.04s`（2026-08-31 17:56:44 +08:00）；
- 当前差异检查和该新增测试文件的 Python 编译检查均通过；
- 未修改 GUI、模型文件格式、矩阵数值算法或用户界面布局，因此本轮不新增视觉截图；已有 100% 界面截图仍作为 UI 基线。
