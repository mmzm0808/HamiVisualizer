# 编辑前几何一键恢复

- 日期：2026-08-28 14:30 +08:00
- 类型：用户体验补强 + 回归测试 + 离屏视觉验收
- 影响范围：`view/main_window.py`、`tests/test_ui_hardening.py`

## 背景与问题

晶格编辑已经支持吸附、Alt 自由移动、元胞矢量编辑以及 Ctrl+Z 撤回，但用户需要连续撤回多步才能回到进入编辑前的几何状态。对蜂窝等斜原胞模型，这会让“试着拖一下再恢复”不够直接。

## 实施内容

1. 进入“编辑晶格”时保存当前模型的几何快照，只包含 `sites` 和 `cell`（包括斜原胞 `a1/a2`）。
2. 编辑工具栏新增“恢复位置”按钮，退出编辑模式时自动隐藏。
3. 点击按钮时只恢复格点位置与元胞矢量，保留用户当前的参数、跃迁项、边界条件和显示选项，避免误覆盖其他编辑内容。
4. 恢复操作重新走统一 `apply_document → rebuild → document_committed` 管线，因此矩阵、能带/波函数、晶格和撤回历史保持一致。
5. 继续沿用现有显式 Delete 删除策略，不改变单击、双击和输入框的交互语义。

## 兼容性与风险

- 无破坏性 API 变更；模型文件格式不变。
- 恢复快照仅在当前编辑会话内有效，切换模型或退出编辑后重新建立，避免跨模型误恢复。
- 如果当前模型已处于无效输入状态，恢复失败会在状态栏提示，不会静默覆盖数据。
