# 关闭后台模型保持当前状态

## 问题复现

在三个模型标签 `NP（当前）→ SC → Kagome` 中，直接关闭最右侧的后台 `Kagome`，旧逻辑会按关闭位置选择相邻标签，导致当前模型从 `NP` 跳到 `SC`。这类跳转不会报错，但会让用户误以为参数或计算结果被改变。

## 修复方案

- 关闭前保存当前 `_Session` 对象身份；
- 关闭后台标签时，按会话对象重新定位活动模型，只更新索引，不切换计算文档；
- 只有关闭当前标签时，才选择同位置的下一个标签，若已是最后一个则选择前一个；
- 关闭最后一个模型时保留一个可用的“空白自定义”标签；
- 比较面板仍会重新校验被关闭的比较模型，并自动回退到仍存在的模型。

该修改不改变模型文件格式、物理计算或撤回栈语义，只修正标签生命周期的选择行为。
