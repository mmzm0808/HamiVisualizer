# 密集晶格编辑视觉层级

- 日期时间：2026-08-28 16:52 +08:00
- 范围：Kagome、NP 及其他具有次近邻/长程跃迁的晶格编辑态
- 状态：已实现、离屏截图复核、全量回归通过

## 问题与判断

用户提供的 Kagome 编辑截图虽然已经不再被大量跃迁强度输入框遮挡，但画面仍把最近邻红实线、次近邻绿虚线、虚影和元胞轮廓以近似相同的视觉权重同时呈现。密集模型因此像一张“线网”，用户难以先辨认基元结构，再决定是否要检查较长程的跃迁。

这是信息层级问题，不是删掉物理项的问题：次近邻和跨胞项仍必须保留在渲染、点击编辑和哈密顿量计算中。

本轮采用成熟绘图编辑器常用的渐进披露原则：稳定的主结构最醒目，辅助信息默认退到背景；需要精确编辑时仍可通过点击真实键或“系数：全部显示”展开。Qt Graphics View 的项目事件与悬停机制可让视觉线和宽命中区域分离，因此不必用加粗/高亮所有键来换取可点击性。[Qt Graphics View Framework](https://doc.qt.io/qt-6/graphicsview.html)

## 实现

### 1. 编辑态的键层级

`hamivisualizer/view/lattice_view.py` 按显示场景区分透明度：

| 图层 | 浏览态 | 编辑态 | 目的 |
| --- | ---: | ---: | --- |
| 最近邻 NN 红实线 | 1.00 | 1.00 | 保持晶格骨架和主连接可读 |
| 次近邻 NNN 绿虚线 | 0.55 | 0.24 | 物理项仍可见，但不与主键竞争 |
| 虚影 NNN | 0.36 | 0.12 | 只提示延拓关系，避免跨胞线网干扰 |

最近邻虚影维持原有 0.72，方便用户识别边界连续性。所有键仍照常进入矩阵、能带、波函数和编辑操作；本次没有改变模型数据或哈密顿量。

### 2. 可验证的渲染语义

物理 NN、物理 NNN、虚影 NN、虚影 NNN 线条各自写入稳定的 `QGraphicsItem.data(0)` 类型标记。这样测试可直接验证视觉层级，而不是仅以截图作主观判断。

新增 `test_dense_edit_mode_keeps_nnn_and_ghost_bonds_visibly_secondary`：

- 用 `Kagome + 最近邻/次近邻 + OBC` 进入真实编辑态；
- 断言主 NN 层是 `1.00`，物理 NNN 层是 `0.24`；
- 退出编辑态后断言 NNN 恢复浏览态 `0.55`；
- OBC 没有虚影层时允许空集合；半无限模型的虚影 NNN 使用同一渲染路径且为 `0.12`。

已有的渐进编辑器测试继续覆盖：密集模型默认零输入框、点击键后仅一框、明确选择“全部显示”后才展开所有框。
