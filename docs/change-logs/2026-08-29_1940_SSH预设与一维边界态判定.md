# SSH 预设与一维边界态判定

时间：2026-08-29 19:40

## 动机

项目原有预设覆盖链、方格、蜂窝、三角和 Kagome，但缺少一个最小、可直接验证边界态的拓扑模型。与此同时，波函数视图的边界权重算法把“某一坐标跨度为零”的一维链也当成二维外边界，导致整条链都被标为边界，真实端点态反而显示为“体态”。

## 修改

- 新增 `SSH` 内置模型：
  - 两格点原胞 `A/B`，站点位置为 `(0,0)` 与 `(0.5,0)`；
  - `t1` 为胞内跃迁，`t2` 为明确的 `off_x=1` 胞间跃迁；
  - 参数表自动显示 `t1`、`t2`，不再把胞间键隐式塞进胞内；
  - 半无限模式沿 `kx` 形成清晰的 Bloch 胞间项，双开模式可直接观察端点态。
- 新建模型向导增加 SSH 说明：双开边界下调小 `t1`、调大 `t2` 可观察近零能端点态。
- `edge_mask_for_positions` 改为只沿实际具有物理跨度的坐标轴计算外边界；一维链不再因退化坐标把所有站点标成边界，二维模型的原有边界壳层规则保持不变。

## 数值验收

- 8 个原胞、双开边界、`t1=0.3`、`t2=1.0`：矩阵为 16×16，Hermitian 误差在数值容差内；
- 能谱包含两条 `|E|<10⁻³` 的近零端点态；
- 选择 `E=0` 后波函数摘要显示边界权重约 99.2%、均匀基线 37.5%、富集 2.65×，分类为“边界局域态”；
- 原有精确简并态边界投影测试仍通过。

## 兼容性

新增模板不会改变已有模型 JSON 格式或已有模板的矩阵语义。旧版本打开的模型仍按原字段加载；SSH 只是新增可选模板，用户仍可通过表格精确编辑每个胞内/胞间跃迁。
