# 半无限胞间跃迁语义化

- 完成时间：2026-08-28 21:46 +08:00
- 状态：完成
- 影响范围：半无限模式“添加跃迁”对话框、胞间偏移录入、跨胞矩阵验证。

## 用户问题

半无限模式原先只显示两个孤立的“元胞偏移 x/y”数字框。虽然底层模型和 `HamiltonianBuilder` 已支持 `off_x=±1` 的 Bloch 跨胞项，但界面没有把“胞内”和“胞间”区分出来，用户很容易一直保持 `(0,0)`，看起来就像无法添加胞间跃迁。

## 实施改动

1. 添加跃迁对话框新增“位置”语义选择：胞内 `(0,0)`、右侧胞间 `(+1,0)`、左侧胞间 `(-1,0)`、上方 `(0,+1)`、下方 `(0,-1)` 和“自定义偏移”。
2. 选择标准位置时，数字偏移框自动同步并锁定，避免标签和实际值不一致；选择自定义后才开放两个数字框，保留任意整数跨胞项的高级能力。
3. 半无限模式增加明确说明：左右胞间是 Bloch 方向，会在矩阵中产生跨元胞相位；上下胞间连接有限方向。对话框仍保留参数名、幅度、相位和反向共轭说明。
4. 控制器将当前边界模式传入对话框；组合框数据使用稳定字符串 token，避免不同 PySide6 版本对 Python tuple 的 QVariant 比较不一致。

## 物理语义

- `(0,0)`：同一元胞内的跃迁；
- `(+1,0)` / `(-1,0)`：半无限 x-Bloch 方向的相邻元胞，进入 `H₁ e^{ik_x}` 与其厄米共轭项；
- `(0,±1)`：有限 y 方向相邻元胞，直接进入 ribbon 的块矩阵；
- 显示层仍使用中心元胞的开边界编号，矩阵层单独应用周期偏移，不混用显示序号。
