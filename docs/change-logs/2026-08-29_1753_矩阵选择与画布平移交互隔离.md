# 矩阵选择与画布平移交互隔离

- 时间：2026-08-29 17:53 +08:00
- 范围：矩阵专用页、矩阵+晶格组合页、所有 `ZoomGraphicsView` 视图的鼠标平移与选择交互。
- 触发：矩阵元虽然能够被点击选中，但左键按下仍会先进入画布平移准备状态。用户在查看矩阵元、复制公式或轻微移动指针时，可能把矩阵视口拖离当前位置；这与“点击只选择，拖动才平移”的直觉不一致。

## 根因

`ZoomGraphicsView` 原先只在晶格编辑模式下识别交互图元。矩阵视图的小矩阵使用逐格矩形，大矩阵使用单个栅格化 `QGraphicsPixmapItem`；两种情况下都由 `MatrixView.mousePressEvent()` 负责计算单元格并发出选择信号，但视图层没有一个与绘制实现无关的矩阵区域命中接口。因此左键在矩阵元上按下时仍会设置 `_pan_press_pos`，后续超过 6 像素的微小移动就可能开始平移。

## 改动

### 1. 统一矩阵区域命中

- 在 `MatrixView` 增加 `is_interactive_position(scene_pos)`，只依据真实矩阵矩形判断，不依赖逐格图元或大矩阵栅格图像；
- 小矩阵、大矩阵、浅色/深色主题和组合页统一使用“矩阵元点击优先于平移”的语义；
- 该方法只改变鼠标手势路由，不改变矩阵数值、标签、选中状态、复制 LaTeX 或视口缩放。

### 2. 选择与平移分层

- 左键命中矩阵区域、跃迁编辑框、跃迁引导线、周期虚影端点或可移动格点时，不再设置画布平移起点，事件交给相应场景/控件处理；
- 左键点击空白画布仍保留原有“移动超过 6 px 才平移”的防误触阈值；
- 中键拖动现在作为所有图形视图的明确平移通道，即使左键当前被保留给矩阵选择，也不会损失平移能力；
- 每次交互结束或命中交互控件都会清理 `_pan_button`，避免上一次手势状态泄漏到下一次点击。

## 兼容性与成功标准

- 未引入破坏性 API 变更；`ZoomGraphicsView` 仍支持滚轮/键盘缩放、左键空白处平移和场景自定义交互；
- 矩阵元点击只产生选中反馈，不会意外改变视口；需要平移时可拖动空白区域或使用中键；
- 大矩阵栅格路径与小矩阵逐格路径行为一致，后续新增视图也可通过同名命中接口接入相同手势策略。
