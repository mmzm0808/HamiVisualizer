# 半无限胞间关系提示与高缩放编辑验收

## 本轮目标

- 确认半无限模式可以明确创建胞内、左右胞间和上下胞间跃迁；
- 避免把长程 `dx=2/3` 胞间项误标成最近邻 Bloch 相位；
- 检查所有默认晶格在高界面缩放下的跃迁强度输入框是否完整、可点击、无重叠；
- 统一大矩阵栅格文字与普通矩阵文字的数学字体。

## 修改

1. 控制面板的新增入口改名为“按关系添加”，直接表明它用于选择胞内/胞间关系；关系摘要现在按实际 `|dx|` 列出 Bloch 谐波：`dx=1` 显示 `e^(±ikₓ)`，`dx=2` 显示 `e^(±i2kₓ)`，多个距离会同时列出。这样表格中输入任意整数胞偏移后，提示与矩阵物理含义一致。
2. 大矩阵的视口文字绘制路径改用 Cambria Math（不可用时回退 STIX Two Math），与普通 `QGraphicsTextItem` 的数学字体保持一致；字号仍按当前屏幕像素和矩阵缩放动态计算。
3. 保留原有语义化“按关系添加”入口、HoppingDialog 的胞内/右侧/左侧/上方/下方选择，以及高级列 `dx/dy` 精确兜底；未改变模型 JSON/API 或 Hamiltonian 建阵接口。

## 验证

- 关系摘要与长程谐波专项：`2 passed`；
- 矩阵智能表达、LaTeX 下标、视口文字专项：`17 passed`；
- 全量回归：`197 passed in 51.67s`，仅有既存的 Windows `.pytest_cache` 权限警告；
- 代表性 NP、蜂窝、Kagome、三角模型在 180% 界面缩放下逐框测量：所有编辑框完整位于晶格视口内，未发现越界或互相重叠；
- 通过半无限空白模型实际输入 `dx=2`，关系摘要显示二阶 Bloch 谐波，高级列和底部边框均完整。
