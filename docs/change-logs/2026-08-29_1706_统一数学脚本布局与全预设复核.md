# 统一数学脚本布局与全预设复核

## 时间与范围

- 时间：2026-08-29 17:06 +08:00
- 范围：矩阵小尺寸文字、大矩阵栅格化叠加层、数学字体回退、全部默认预设的矩阵+晶格组合页、编辑态跃迁系数框。
- 触发原因：虽然此前用 `<sup>/<sub>` 的富文本兼容层暂时抬高了 `k_x`，但 Qt 的嵌套 CSS 基线不是 TeX 规则；在 `e^{ik_x}`、长指数和多个参数脚本混排时，x 仍可能视觉下沉，且小矩阵与大矩阵的渲染路径存在分叉。

## 实施内容

### 1. 独立的数学布局引擎

新增 `hamivisualizer/view/math_text.py`，使用 Qt 自带 `QFontMetricsF` 和 `QPainter` 实现软件实际所需的轻量 TeX 子集：

- 花括号分组；
- `^` 上标与 `_` 下标；
- 上下标的组合与嵌套（脚本相对父原子定位，而不是相对正文重复下沉）；
- `\phi`、`\omega`、`\pi`、`\cdot`、`\pm`、`\infty` 等模型表达式会出现的宏；
- 多行换行后的独立行度量。

每个节点先计算宽度、上升和下降，再按父原子基线绘制。`e^{ik_x}` 的几何关系是：e 的指数整体上移一次，x 仅在指数内部相对 k 下移一次，因而不会再掉到 e 的正文基线附近。

### 2. 两条矩阵路径统一

- `MatrixView` 的普通小矩阵 `MathTextItem` 与大矩阵视口叠加层现在都调用 `MathLayout`；
- 叠加层缓存由 `QTextDocument` 改为 `(MathLayout, QFont)`，缓存键保留文本、像素字号和明暗主题，最多 512 项；
- 字号仍由单元格的实际屏幕像素计算，矩阵缩放不会冻结字号；
- `to_html()` 与 `to_math_html()` 继续保留，供旧 API/外部集成和剪贴板兼容使用，但画布矩阵不再依赖 Qt HTML 的嵌套脚本排版。

### 3. 全模型与交互复核

- 8 个默认模板（NP、SC、空白自定义、方格、一维链、蜂窝、三角、Kagome）分别生成半无限和双开组合页，浅色/深色各一套，共 32 张截图；
- 统一矩阵布局单独生成小矩阵 180% 与大矩阵放大截图；
- 蜂窝、Kagome、三角编辑态在 80%/100%/150%/180% 下生成全部跃迁系数框，确认完整圆角边框、底边和文本仍在场景内；
- 浅色 80% 和深色 180% 的 Kagome 三格点正三角盘继续保持等边外轮廓、连续最近邻红线和不遮挡的左侧标题栏。

## 兼容性与风险控制

- 没有引入 matplotlib、MathJax、系统 LaTeX 或其它大型运行时；发布包仍只依赖当前 requirements.txt；
- 计算、模型 JSON、矩阵复制出的标准 LaTeX 源码、外部 `to_html()` 语义均未改变；
- 对未支持的宏，解析器保留其可见字符，不静默吞掉用户输入；异常/不完整花括号也会以可见文本形式绘制。
