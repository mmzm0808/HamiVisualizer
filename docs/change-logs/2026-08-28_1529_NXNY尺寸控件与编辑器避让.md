# NX/NY 大尺寸控件与编辑态视觉避让

- 时间：2026-08-28 15:29 +08:00
- 范围：尺寸输入、模板创建、编辑态跃迁输入框、离屏验收工具

## 背景与问题

旧版 NX/NY 控件只有一个小范围微调入口，界面层沿用了 10/12 的历史校验上限。这个上限适合早期演示，不适合能带扫描或较宽的有限宽度模型；同时，编辑态输入框在 150% 缩放和窗口尺寸变化后仍使用旧的像素换算，容易出现控件互相遮挡或底边被裁切。

## 已实施改动

1. 左侧边界面板将 NX、NY 分成独立行，每行提供滑块与精确输入框。滑块覆盖常用范围（1–64）；输入框支持更大的精确值，输入较大数值时滑块自动扩展到可见端点，避免把大尺寸误认为被限制。
2. 模板创建对话框采用同一套 NX/NY 控件和同步逻辑，保持创建模型与编辑模型的交互一致。
3. 持久化校验上限提升为 100000。它是防止异常文件耗尽资源的宽校验天花板，不是渲染承诺；有限边界矩阵的计算成本随维度近似平方增长，极大值仍受机器内存和计算时间约束。
4. 半无限边界下 NX 控件随边界语义禁用（x 方向折叠进 Bloch 波矢），NY 保持可编辑；开边界下 NX、NY 均可编辑。
5. 跃迁强度输入框改为在实际尺寸变化后下一事件循环重新布局，使用完整不透明边框并提高编辑器图层顺序；布局优先避让格点、避免输入框彼此重叠，窗口放大和 150% UI 缩放后不再沿用过期尺寸。
6. 节点半径从过大的默认比例下调，给编辑器和连线留下更清晰的视觉空间；所有 8 个内置模板均做了浅色 100%、深色 100%、深色 150% 离屏截图检查。
7. 离屏渲染退出前等待 Qt 线程池完成，避免异步能带线程在窗口销毁后向已删除信号对象发射，保证验收过程稳定。

## 兼容性与风险

- 模型文件格式和 `values()` 对外接口未改变。
- 旧模型仍按原参数加载；只放宽了尺寸合法范围。
- 输入极大的有限矩阵仍可能消耗大量内存，这是物理计算本身的资源约束。后续可增加基于内存估算的预警和可取消计算，不再恢复人为的 10/12 小上限。
