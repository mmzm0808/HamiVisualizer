# 斜向胞间关系摘要

- 日期：2026-08-29 01:17 +08:00
- 范围：控制面板“跃迁项”关系摘要
- 目的：修复混合元胞偏移的统计语义，使摘要准确区分纯水平、纯竖直和同时跨 x/y 的斜向胞间跃迁。

## 问题

摘要原先将 `off_x != 0` 计入 x 方向，将“`off_x=0` 且 `off_y != 0`”计入 y 方向。对于 `(dx,dy)=(1,1)` 这类斜向胞间项，x 计数正确但 y 计数被遗漏，用户看到的关系说明不完整，容易误判边界方向和 Bloch 作用范围。

## 修改

- y 方向统计改为所有 `off_y != 0` 的记录；
- 同时含 x/y 偏移的记录额外显示“斜向胞间 N 条”；
- x 方向仍显示实际 Bloch 谐波集合，`dx=2` 等长程项继续显示 `e^(±i2kₓ)`；
- 纯 y 偏移仍明确说明是有限方向连接；
- 不改变 `HoppingTerm`、`H0/H1/extra` 或任何矩阵计算逻辑，只修正用户可见摘要。

## 验证

- 新增回归测试构造 `(dx,dy)=(1,1)`，确认 x、y、斜向三项均显示为 1；
- 半无限空白模型深色 150% 截图确认关系摘要、高级列和矩阵/晶格视图同时可读；
- 全量测试：`218 passed in 63.61s`；
- 编译检查与 Markdown 链接检查通过。
