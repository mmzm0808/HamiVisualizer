# 跃迁对话框格点编号统一

- 时间：2026-08-31 01:50:25 +08:00（北京时间）
- 类型：交互一致性修复
- 触发问题：用户可见的格点编号约定已经统一为从 1 开始，但从晶格画布点选两个格点后弹出的“添加跃迁”对话框仍把内部零基索引直接显示为 `格点 0 → 1`，与画布标签、左侧格点表和矩阵行列标尺不一致。

## 问题定位

模型和计算层继续使用零基索引，这是 Python/NumPy 矩阵接口的内部约定；`HoppingDialog.row()` 也必须返回零基端点，控制器和哈密顿量构建器依赖这一语义。问题只出在无 `site_count` 的画布入口连接提示：构造 `QLabel` 时直接插入了 `from_site` 与 `to_site`，导致内部编号泄漏到用户界面。

## 修改内容

1. 仅在 `HoppingDialog` 的画布连接提示处将两个端点显示为 `int(index) + 1`。
2. 保持 `row()` 的返回值、矩阵索引、跃迁表写入和周期边界计算完全不变，避免任何破坏性接口变更。
3. 增加回归测试，确认画布式对话框显示“格点 1 → 2”，并继续通过胞内、胞间、分数/表达式和自定义偏移路径。
