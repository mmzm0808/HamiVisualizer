# 斜元胞网格与吸附统一

- 时间：2026-08-30 23:30:11 +08:00（北京时间）
- 范围：`hamivisualizer/view/lattice_view.py`、`hamivisualizer/view/main_window.py` 与 UI 回归测试。

## 问题

蜂窝、三角和三格点 Kagome 等斜元胞在编辑时，背景网格仍按全局 x/y 方向绘制，导致可编辑格点与网格视觉错位。更严重的是，新增格点和拖动的备用吸附仍按独立 x/y 四舍五入，用户点击一个看得见的网格节点时，模型可能写入另一处坐标。

## 修改

- 斜元胞改用 `u a₁ + v a₂` 的分数坐标网格；网格密度由原有“间距”控件换算为沿两条基矢的细分数，并限制装饰节点最多 1800 个；
- 拖动和“添加格点”共用同一个 Bravais 分数坐标取整函数，矩形元胞继续使用原有笛卡尔网格；
- 精确格点/原始位置对齐环仍保留，作为非规则基矢坐标的明确目标提示；不接收鼠标，不会抢走格点拖动或跃迁工具；
- 网格按钮提示补充“矩形沿 x/y、斜元胞沿 a₁/a₂”的可见语义。
