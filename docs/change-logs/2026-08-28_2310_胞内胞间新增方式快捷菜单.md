# 胞内胞间新增方式快捷菜单

- 时间：2026-08-28 23:10 +08:00
- 范围：半无限（x-Bloch）模式的跃迁新增入口、胞内/胞间关系可发现性、表格兜底编辑

## 问题

此前左侧 `+ 跃迁` 可以新增一行，但半无限模型的胞内与胞间区别主要隐藏在高级 `dx/dy` 列里。用户必须先展开列、理解偏移约定，再手工输入 `+1/-1`，容易误以为只能添加胞内跃迁，也不符合成熟软件“先选语义、再看参数”的交互习惯。

## 修改

- 保留原有一键 `+ 跃迁`：单格点模型自动创建右侧胞间 `(dx=1,dy=0)`，多格点模型创建合法胞内 `0→1`；
- 在其旁新增“添加方式”快捷菜单，直接提供：
  - 胞内 `(0,0)`；
  - 右侧胞间 `(+1,0)`；
  - 左侧胞间 `(-1,0)`；
  - 上方胞间 `(0,+1)`；
  - 下方胞间 `(0,-1)`；
- 任一快捷方式在半无限模式下都会自动展开高级列，新增行自动选中并滚动到可视区域；
- 端点仍使用当前模型中合法的 `0→1`（多格点）或 `0→0`（单格点），幅度默认为 `-t`、实跃迁相位为 0；
- 只增加 UI 入口，不改变 `HOP_COLS`、JSON 字段、`cell_offset` 语义、Hamiltonian 构建或历史模型格式；表格仍可精确修改任意整数 `dx/dy`。
