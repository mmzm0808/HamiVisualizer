# 跃迁悬停与点击辨识度优化

- **记录时间**：2026-09-01 12:35:50 +08:00（Asia/Shanghai）
- **范围**：晶格编辑态的跃迁悬停、跃迁引线、系数输入框、连续鼠标移动与点击切换
- **性质**：交互可用性修复；不改变 Hamiltonian 构建、矩阵数值、边界条件或模型文件格式

## 用户可见问题

在蜂窝/Kagome 等线条密集的编辑画布中，多个透明跃迁引线会同时参与 Qt 的 item-level
hover enter/leave。鼠标快速移动时，重叠命中区域会交替触发，造成未悬停的线也闪烁；密集
模式点击不同跃迁后只显示一个右侧输入框，输入框总在同一栏中心，缺少足够的“这是哪一条
跃迁”的即时线索。

## 实施内容

- 关闭 `_EditableHopGuide` 自身的 hover enter/leave 视觉副作用。`ZoomGraphicsView` 的
  每次无按钮移动现在交给 `LatticeView.handle_viewport_hover()`，把场景线段端点映射到
  实际屏幕像素后选取最近的一条引线；9 px 命中半径覆盖原有宽命中区，但不会让重叠线各自
  闪烁；当前行在等距边界上优先保留，避免快速移动时来回跳号；
- 悬停状态只由场景统一写入：当前悬停行和已点击行分别保持清晰的青色虚线，其他引线恢复
  完全透明的命中层；离开视图时清理瞬时系数徽章，避免标签滞留在画布；
- 密集模式的唯一活动输入框仍在右侧统一栏，避免引线向四面散落，但其纵坐标改为跟随所选
  键的物理中点（在视口边界内安全夹紧），所以连续点击不同键不再总落在同一位置；
- 每个当前可见的编辑框增加轻量身份标签：`#表格序号 · 起点→终点 · 内/外偏移`，同几何
  线上不同参数还会显示参数名。默认密集模式只显示被点击的这一枚，显示全部系数时关闭
  额外标签层以保证高倍率下编辑框仍不重叠；完整端点信息仍保留在输入框 tooltip 和左侧
  跃迁表中；
- 新增连续视口 hover、单一引线高亮和跨跃迁点击位置回归，覆盖实际像素命中而非只调用
  内部 slot；同步更新 SSH 及独立参数的身份标签断言。

## 兼容性与边界

- 普通点击、格点拖动、跃迁创建和画布平移的按钮语义保持不变；只有在晶格编辑态、且鼠标
  未按下时才启用像素级 hover 解析；
- 单行复杂幅度仍不会生成误导性标量输入框；表格仍是完整表达式的兜底编辑入口；
- 不改变跃迁代表行合并规则、胞内/胞间偏移计算或右侧输入框的实际写回逻辑。
