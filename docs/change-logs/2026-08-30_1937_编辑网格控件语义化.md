# 编辑网格控件语义化

时间：2026-08-30 19:37:47 +08:00（北京时间）

## 问题

编辑工具栏原本连续显示两个“网格”：一个是控制背景节点显隐的按钮，另一个是控制网格间距的数值控件。两者功能不同但文案相同，在 100% 和深色主题截图中都容易被误读为重复控件。

## 修改

- 显示开关改为“网格点”，明确它控制的是背景吸附节点的可视化；
- 间距数值前的标签改为“间距”，并在 tooltip 解释“数值越小网格越密”；
- 保留原有 0.001–10.0 的安全范围、0.05 的常用步进和实时刷新行为；
- 网格显隐与吸附逻辑继续解耦：关闭“网格点”只隐藏背景点，不改变拖动吸附；
- README 同步使用新文案，避免教程截图与实际界面不一致。

## 验证

- 新增 Qt 回归断言，确认按钮和间距标签不会重新退化为相同文案；
- 定向网格测试：`1 passed`；编译检查通过；
- 使用现有离屏工具在 1920×1200、100% 界面缩放下重新生成浅色/深色截图，并实际查看工具栏、输入框底边、网格点和侧栏，均未发现遮挡或裁切；
- 推送前完整回归基线：`327 passed in 136.64s`（2026-08-30 19:30:26 +08:00）。
