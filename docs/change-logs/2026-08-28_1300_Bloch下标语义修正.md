# Bloch 下标语义修正

## 时间

2026-08-28 13:00（UTC+08:00）

## 复核发现

首轮修复已经让部分 `k_x` 看起来像下标，但对两种常见写法的处理并不完全一致：`e^{ik_x}` 没有识别下划线，`e^{ik_{x}}` 的旧规则还会把 `k` 移到指数外。后者在视觉上容易误导，也不符合 Bloch 因子的数学结构。

## 修复

- 统一识别 `k_x` 与 `k_{x}`，同时兼容 `e^{ik_x}`、`e^{i k_{x}}`、负指数和整数谐波；
- 输出为 `e<sup>ik<sub>x</sub></sup>` 这一 Qt 富文本结构：`i k_x` 整体属于指数，`x` 明确作为 `k` 的下标；
- 不再把 `k` 错移到指数外，保持表达式的物理语义；
- 新增/更新富文本回归断言，确保后续格式化改动不会回退。

## 验证

- 33 项矩阵视图与 UI 测试通过；
- 半无限 NP 模型 NY=4、最近邻+次近邻，在浅色 100%、深色 100%、深色 150% 下离屏截图确认 `k_x` 下标可辨；
- 最终全量回归仍为 `122 passed in 22.93s`。
