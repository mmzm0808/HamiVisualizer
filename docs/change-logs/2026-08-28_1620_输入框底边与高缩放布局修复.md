# 输入框底边与高缩放布局修复

- 时间：2026-08-28 16:20 +08:00
- 范围：晶格编辑态跃迁强度输入框、左侧元胞矢量编辑区、150% 界面缩放

## 用户问题

编辑晶格时，跃迁强度输入框在聚焦后能看到上边和侧边，但下边框消失；这不是截图裁剪，而是控件代理的实际绘制范围小于子输入框。高 UI 缩放时，左侧元胞矢量区域还会出现水平滚动条，导致按钮和数值框靠边、难以操作。

## 根因

1. `QLineEdit#hopStrengthEditor` 的应用级样式在 150% 等缩放下提高了 `min-height`。编辑器创建时却用旧的 26–34 px 固定高度设置 `QGraphicsProxyWidget`，最终出现“子控件高度大于代理边界”的不一致，代理会裁掉下方边框和部分命中区域。
2. `QDoubleSpinBox` 的原生 `sizeHint()` 为 8 位小数预留了 300 px 以上宽度；即使设置了最大宽度，原有 Expanding 策略仍把这个提示宽度传递给格点组的最小宽度，150% 时触发控制栏水平滚动。

## 实施改动

### 1. 输入框尺寸与代理同步

- 跃迁输入框先执行 `ensurePolished()`，读取当前主题/缩放下真实的 `sizeHint()` 与 `minimumSizeHint()`；
- 以样式计算出的高度设置固定尺寸，使 `QGraphicsProxyWidget.boundingRect()` 与子输入框完全一致；
- 编辑器排布增加 8 px 屏幕安全边界，底边不会再贴住 `sceneRect` 或视口裁剪线；
- 保留焦点自动滚入、层级提升、输入框之间避让和原有物理强度编辑语义。

### 2. 左侧编辑栏响应式收缩

- 元胞长度标签缩短为 `a₁ 长度`、`a₂ 长度`，精确说明放入 tooltip，避免高缩放下重复占宽；
- 四个斜原胞分量框使用可收缩的 `Ignored` 水平策略，并在 UI 缩放函数中给出 78–112 px 的可读宽度区间；
- 150% 编辑态下控制栏内容宽度不超过视口，`应用元胞矢量` 和末端分量框均保持完整可点击。

## 兼容性与风险

- 没有改变模型 JSON、跃迁计算、元胞坐标或公开信号；
- 输入框仍是固定像素控件，文本过长时使用 QLineEdit 自身的水平滚动，不会改变画布缩放语义；
- 8 px 边界只影响编辑控件的视觉位置，不会改变连接线、节点坐标或矩阵结果。
