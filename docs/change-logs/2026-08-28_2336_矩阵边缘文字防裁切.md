# 矩阵边缘文字防裁切

## 问题

矩阵放大并平移后，四边冻结的行列号标尺会覆盖场景中的矩阵文字。较长的 Bloch 表达式（例如 `e^{±ik_x}`）因此可能只剩半个指数或半个符号，用户容易误读。

## 修改

- 矩阵文字图元增加行列元数据，便于按单元判断可见性；
- 在视口覆盖层绘制前计算每个文字图元的屏幕范围；
- 被任一冻结标尺覆盖的文字按“整块图元”隐藏，不再让绘制层裁切字形；
- 视口内部仍完整显示可读单元；极小矩阵若所有单元都贴近标尺，则保留文字，避免出现整张空白；
- 保持现有场景缩放、懒加载和大矩阵视口文字路径，不改变矩阵数据、排序或对外接口。
