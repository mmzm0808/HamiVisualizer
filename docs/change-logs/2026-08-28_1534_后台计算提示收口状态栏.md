# 后台计算提示收口到状态栏

- 时间：2026-08-28 15:34 +08:00

## 问题

能带或波函数异步计算时，顶部结果横幅会占用绘图区上方空间。用户已经明确希望“已输入更改，正在等待重新计算”等短时反馈只出现在底部状态栏，并以红色高亮提醒。

## 修改

- 所有“构建中”“谱数据仍在后台计算”“矩阵与晶格已更新，谱数据正在后台计算”状态均关闭顶部横幅；
- 通过现有 `flash_status` 在底部状态栏短暂高亮提示，自动恢复普通状态栏样式；
- 错误状态仍保留顶部横幅，用于持续展示需要用户处理的问题；
- 新增回归测试，确保后台进度不会重新占据绘图区。

## 验证

- 回归测试覆盖 `set_result_state(..., show_banner=False)` 与状态栏文字/样式；
- 全量测试：`158 passed in 31.15s`；仅有 Windows 项目路径编码导致的 pytest cache 警告，不影响测试结果；
- 离屏复核：[能带 NY=70 状态栏提示 · 深色 150%](../../.codex-artifacts/screenshots/dimension-controls-audit-20260828/band-ny70-statusbar-dark-150.png)。
