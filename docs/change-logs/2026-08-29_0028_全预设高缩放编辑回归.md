# 全预设高缩放编辑回归

## 背景

之前的离屏截图证明了代表性模型在 180% 界面缩放下的输入框没有越界，但回归测试只覆盖 100% 缩放。界面样式、字体或代理控件尺寸任何一次变化，都可能让底边再次被裁掉，因此这项验收需要固化到自动化测试。

## 修改

- 将 `test_edit_strength_editors_are_not_clipped_after_fit` 扩展为 100% 与 180% 两档；
- 仍覆盖全部内置预设（NP、SC、空白自定义、方格、一维链、蜂窝、三角、Kagome）以及半无限/双开边界，共 32 个组合；
- 每个组合逐个测量 `QGraphicsProxyWidget` 的真实屏幕矩形，验证四条边均在晶格视口内；
- 保留原有编辑框之间的间距、焦点滚动、拖动防误触和节点避让测试；
- “按关系添加”入口继续作为半无限胞间跃迁的显式入口，未改变模型文件或计算接口。

## 验证

- 全预设高缩放编辑回归：`32 passed in 20.93s`；
- 全量回归：`213 passed in 56.06s`，仅有 Windows 中文路径下既存的 `.pytest_cache` 权限警告；
- `compileall` 通过，文档相对链接缺失数为 0；
- 180% 实景截图仍保存在项目内，并人工查看 NP、蜂窝、Kagome、三角四类代表模型。
