# 发布入口文档校正

## 问题

根目录 `README.md` 仍保留 v0.2 草稿，包含已经失效的 PyQt5 备用说法、可选 matplotlib 说明和过时的功能状态。开源用户从 Git 仓库首页阅读该文件时，容易得到错误的安装与运行预期。

## 修改

- 将根 `README.md` 改为 HamiVisualizer 0.4 的准确快速入口；
- 明确当前 GUI 只使用 PySide6/Fusion，数值依赖为 NumPy 1.x，版本范围与 `requirements.txt`/`pyproject.toml` 一致；
- 保留 `README-v0.3.md` 作为完整使用文档和历史兼容文件名，并明确其当前内容已更新；
- 指向项目内 `.codex-artifacts/` 和 `docs/change-logs/` 的正式归档位置。

## 验证

- 文档中的安装命令可直接对应现有依赖文件；
- 未改变 Python API、模型格式或用户数据目录；
- 启动入口继续由 `main.py`、`python -m hamivisualizer.main` 和安装后的 `hamivisualizer` 提供。
