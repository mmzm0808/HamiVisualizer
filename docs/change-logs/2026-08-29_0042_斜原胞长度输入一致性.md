# 斜原胞长度输入一致性

## 发现

控制面板同时提供 `a₁/a₂` 长度和完整斜矢量分量。进入斜原胞模式后，长度输入框仍允许用户置零并显示“自动”，但内部矢量并没有被清空，模型实际几何与界面显示不一致；下一次重算还可能让用户误以为已经恢复自动间距。

## 修改

- 斜原胞模式下将 `a₁/a₂` 长度置零视为无效输入；
- 输入触发后原子恢复到上一次有效长度，保持矢量方向、跃迁端点和元胞面积不变；
- 错误提示明确说明：“自动”仅适用于矩形元胞；
- 随后输入有效正长度会清除临时错误提示；
- 没有改变真正的矩形自动推断逻辑，也没有改变模型文件字段或 Hamiltonian 接口。

## 视觉验收

在蜂窝双开模型、`NX=3, NY=3`、深色 150% 界面下输入无效长度，检查了恢复后的长度控件、错误提示、矩阵和晶格区域。提示位于底部状态/错误区域，不覆盖绘图区；蜂窝斜元胞仍保持两格点 primitive cell 和正确连线。

## 验证

- 斜原胞长度正常缩放与方向保持：`2 passed`；
- 新增零长度一致性回归：通过；
- 全量回归：`215 passed in 64.13s`，仅有 Windows 中文路径下既存的 `.pytest_cache` 权限警告；
- 测试临时文件清理完成，文档链接检查保持 0 缺失。
