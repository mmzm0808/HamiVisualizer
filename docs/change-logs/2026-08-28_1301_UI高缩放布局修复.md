# UI 高缩放布局修复

## 基本信息

- 日期：2026-08-28
- 时间：13:01（Asia/Shanghai，UTC+08:00）
- 范围：界面缩放 150%–180%、左侧参数面板、参数表格可读性
- 触发原因：180% 实景截图发现参数固定列和长组标题仍按 100% 宽度布局，出现文本截断。

## 问题证据

在界面缩放到 180% 时，字体本身可以正确加载，但参数表第一、第二列仍固定为 70/60 px；同时左侧滚动栏最小宽度被限制在约 472 px。结果是：

- `omg` 等参数名在参数表中被省略；
- “波函数（能量选择，仅波函数页生效）”等长标题靠近右边界，无法完整阅读；
- 这与界面缩放“不应出现文字超出显示范围”的验收标准不符。

## 实施修改

文件：`hamivisualizer/view/main_window.py`

1. 参数表的两列固定宽度随 UI scale 同步放大：
   - 第 1 列：`70 × scale`
   - 第 2 列：`60 × scale`
2. 左侧控制栏最小宽度改为 `max(350, 350 × scale)`，在 180% 时为 630 px；默认 100% 仍保持 350 px，不改变普通窗口的初始布局。
3. 右侧结果区使用剩余空间，矩阵、晶格仍各自保持独立缩放与滚动，不改变物理坐标或矩阵数据。

文件：`hamivisualizer/tests/test_workspace.py`

- 扩展 80%–180% UI 缩放回归：断言 180% 时固定列宽为 126/108 px、左栏最小宽度为 630 px，同时确认矩阵单元大小和用户视图变换不被 UI 缩放重置。

## 影响与风险

- 收益：高 DPI/大字号用户无需牺牲参数可读性；固定表格列与字体保持一致比例。
- 影响：180% 时左侧控制栏更宽，右侧绘图区相应变窄，但仍保留独立滚动/缩放，不改变模型计算。
- 兼容性：对外 JSON 格式、模型索引、矩阵/能带/波函数计算完全不变。
- 破坏性变更：无。
