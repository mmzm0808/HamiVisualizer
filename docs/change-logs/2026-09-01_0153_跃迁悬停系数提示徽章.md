# 跃迁悬停系数提示徽章

- 完成时间：2026-09-01 01:53:29 +08:00（北京时间）
- 范围：晶格编辑画布的跃迁悬停预览，不改变矩阵计算、跃迁表数据或对外模型格式。

## 问题与判断

跃迁线悬停时原先只显示一个没有背景的数字。画布使用深色主题、缩放或复杂背景时，数字不容易被发现，也可能与格点、网格或引导线混在一起。另一方面，悬停提示不能成为新的输入控件，否则会遮挡跃迁线并干扰“悬停查看、点击固定编辑”的交互约定。

## 实现

1. 在 `LatticeView` 中为悬停文字增加配套背景图元，背景使用主题自适应的填充色和边框，文字与背景共享固定像素大小，避免随场景缩放产生过大或过小的标签。
2. 背景设置为 `Qt.NoButton`，并保持在文字下方，保证提示只是视觉反馈，不会拦截跃迁线点击、抢焦点或启动画布拖动。
3. 文字内容变化时按实际包围盒重新计算背景尺寸并同步位置，避免不同系数长度导致文字贴边或被裁切。
4. 将背景纳入与文字相同的生命周期管理：悬停清除时先隐藏，再由场景自有单次计时器安全移除；重建场景、切换主题和关闭窗口时清空引用，避免残留图元或 Qt 原生对象访问冲突。
5. 扩展 UI 回归，验证悬停只生成一个文字徽章和一个背景徽章、内容为当前跃迁系数、点击/清除后均不遗留图元，且旧编辑器回收路径保持稳定。
