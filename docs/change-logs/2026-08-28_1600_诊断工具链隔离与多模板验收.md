# 诊断工具链隔离与多模板验收

- 日期：2026-08-28 16:00 +08:00
- 类型：验收工具修复 + 多模板拓扑/视觉复核
- 影响范围：`tools/diagnostics/*.py`

## 发现的问题

诊断脚本从文件路径直接运行时，Python 默认只把 `tools/diagnostics` 放入导入路径，无法找到项目包 `hamivisualizer`。部分脚本还启用了真实工作区，离屏关闭时可能触发保存提示或读写用户工作区，导致命令行验收挂起。

## 修复内容

1. 所有使用项目包的诊断脚本统一把 HamiVisualizer 项目根目录加入 `sys.path`，可从项目根目录或脚本绝对路径直接执行。
2. 主窗口诊断改为纯单窗口控制器，不启用真实多模型工作区，避免读写 `~/.hvisual` 和触发用户保存提示。
3. 主窗口诊断退出前清除演示 dirty 状态；普通复选框演示窗口保持普通 `close()`，不调用工作区专属接口。
4. 保持所有截图输出在 `.codex-artifacts/diagnostics/`，不产生工作区外临时文件。
