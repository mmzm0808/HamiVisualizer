# 元胞矢量编辑布局修复

- 日期：2026-08-28 14:50 +08:00
- 类型：高缩放界面布局修复 + 回归测试 + 视觉验收
- 影响范围：`view/control_panel.py`、`view/main_window.py`、`tests/test_ui_hardening.py`

## 问题

在 150% 界面缩放和晶格编辑模式下，元胞长度、a₁/a₂ 矢量输入框及“应用元胞矢量”按钮共用一行。Qt 的 `QDoubleSpinBox` 默认尺寸提示过宽，导致控制栏出现水平溢出，右侧输入框和按钮被截断。

## 修改

1. 将“应用元胞矢量”移到独立按钮行，a₁ 与 a₂ 各自只承载标签和两个分量输入框。
2. 为长度和矢量输入框设置可伸缩策略及随 UI scale 变化的最大宽度（140 × scale），避免默认样式提示把整个面板撑宽。
3. 保留 8 位小数、负数输入、斜原胞校验和原有信号/模型格式，不改变物理计算语义。
4. 增加回归测试，确认 150% 下控制栏水平滚动范围为零。

## 验证

- UI hardening：`27 passed in 5.73s`。
- 全量回归：`125 passed in 24.81s`。
- 测试运行目录：`.codex-artifacts/test-runs/full-20260828-vector-layout/`。
- 测试后已清理 `hamivisualizer/**/__pycache__`。
