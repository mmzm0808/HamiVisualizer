# 编辑网格与物理键控件去重

时间：2026-08-30 18:55:33 +08:00（北京时间）

## 背景

编辑半无限自定义晶格时，用户可以在同一条几何连线上看到两个甚至更多输入框。根因是表格通常同时保存正向项、反向厄米项和重复项，而画布编辑器此前按表格行逐条绘制，未按可见物理关系合并。另一个问题是编辑画布只有磁吸算法，没有可视化的吸附目标；用户无法判断拖动格点会落到哪里。小型自定义模型还会因“只显示最近邻”的降噪策略隐藏较长但真实存在的边。

## 修改内容

### 1. 一条物理线只显示一个画布输入框

- 新增画布层的几何关系规范化：`(from, to, dx, dy)` 与反向关系归一到同一无向关系；
- 同一几何关系的正向、反向和重复表格行合并为一个输入框；
- 输入框 tooltip 列出被合并的表格行号，左侧跃迁表仍保留逐行精确检查和修改能力；
- 不改变持久化格式、矩阵构建或表格数据，避免破坏性迁移；
- 具有不同几何关系的项仍各自显示，不会把真正不同的胞间偏移合并。

### 2. 编辑画布增加可视化吸附网格

- 编辑态在晶格和元胞框后方绘制低对比度网格节点，节点坐标与 `snap_position` 使用完全相同的锚点和间距；
- 上栏新增“网格”开关；关闭只隐藏背景点，不改变吸附规则，避免用户误以为模型被修改；
- 原“步长”控件改为“网格”数值，实时控制网格密度和吸附间隔；
- 大尺寸场景只对背景装饰进行自适应抽稀（最多约 1800 个可视节点），实际吸附精度保持用户设定值，避免拖动卡顿；
- 主题切换、进入/退出编辑和模型重建都会正确清理/重绘网格，不残留旧点。

### 3. 小型模型的连线可读性

- 对边数较少的自定义模型，在编辑态保留全部已建连线，即使某条边不属于最短距离壳层；
- 密集 Kagome、蜂窝等预设继续使用最近邻优先和“显示次近邻”开关，避免重新引入大面积交叉线网。

## 兼容性与风险

- 这是纯视图层优化；矩阵数值、Bloch 偏移、模型 JSON 结构和外部 API 保持不变；
- 当同一几何线上确实存在多个不同物理贡献时，画布只提供一个几何入口，tooltip 和左侧表格承担逐项检查，避免视觉上重复堆叠输入框；
- 网格点使用不可交互的图形项，不会抢占格点、跃迁或画布平移的鼠标命中。
