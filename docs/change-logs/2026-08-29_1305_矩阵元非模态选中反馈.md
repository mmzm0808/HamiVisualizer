# 矩阵元非模态选中反馈

- 时间：2026-08-29 13:05（+08:00）
- 范围：`hamivisualizer/view/matrix_view.py`、`hamivisualizer/view/main_window.py`、`hamivisualizer/controller.py`、矩阵交互回归测试与离屏渲染工具。
- 目标：让矩阵元点击既能明确反馈行列和数值，又不会打开阻塞式弹窗、抢走缩放/拖拽操作或在组合视图中失去选择状态。

## 问题定位

矩阵场景原本已经定义了 `cellClicked` 信号，但主窗口没有统一接收。控制器另外连接了同一个信号并打开 `QMessageBox.information`。这会造成两类不一致：

1. 点击后没有稳定的矩阵元高亮；
2. 点击会进入模态事件循环，用户只是想检查一个单元格，却被迫关闭弹窗；离屏回归在发出该信号时还会停在弹窗循环中。

## 实施修改

1. `MatrixView` 增加 presentation-only 的 `select_cell(i, j)`：
   - 以两像素 cosmetic 描边绘制选中单元格；
   - 选中框不接受鼠标，不能遮挡下一次点击，也不会改变视图变换；
   - 矩阵重绘时清理旧框，切换主题时保留选中位置；
   - 大矩阵栅格化路径同样支持选中框。
2. `MatrixView.cell_details()` 集中返回 0-based 内部索引、逻辑行列标签和当前显示表达式，避免主窗口再次复制格式化逻辑。
3. 主窗口统一处理 `cellClicked`：在矩阵专用页和“矩阵+晶格”共享场景中保持高亮，并在底部状态栏显示例如 `已选中 H[0:0,0:1]（H[0,1]） = -t·e^{iφ}` 的非模态详情，持续 6 秒。
4. 移除控制器对矩阵信号的第二个模态弹窗连接；保留 `_on_cell_clicked` 兼容入口，但它现在转发到非模态处理，不会重新引入阻塞弹窗。
5. 回归工具新增 `--matrix-selection-demo`，可在浅色/深色及不同界面缩放下生成稳定的点击选中证据。

## 兼容性与取舍

- 没有修改矩阵数据、模型 JSON、HamiltonianBuilder 或公开数据结构；只改变点击后的显示反馈。
- 这是有意的非破坏性 UX 调整：检查矩阵元不再强制用户处理模态弹窗。需要程序化调用旧控制器槽的集成仍可继续调用 `_on_cell_clicked`，但会得到同样的状态栏/高亮行为。
