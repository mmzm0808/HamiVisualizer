# 长程跨胞谐波与能带缩放验收

- 修改时间：2026-08-28 10:53:00 至 11:19:58 +08:00
- 类型：核心物理计算、符号矩阵、异步能带、模板回归、缩放布局
- 影响范围：`HamiltonianBuilder`、`HResult`、`RibbonHamiltonian`、控制器谱计算、
  一维链模板、能带场景、界面缩放、测试与离屏视觉验收工具

## 审计发现

“一维链 + 最近邻+次近邻”模板包含 `off_x=2` 的跨两个元胞跃迁，但旧的
半无限构建器只接受 `off_x=0,±1`。这造成三个不一致：

1. 模型文档能够表达二阶跨胞跃迁，半无限构建阶段却拒绝它；
2. `RibbonHamiltonian` 已有 `extra` 谐波能力，但控制器未把该数据送入矩阵、
   异步能带和符号显示；
3. 视觉验收在 150% 界面缩放下发现能带标题被裁切，并出现无意义滚动条。

## 核心计算修改

### 1. 任意整数距离的 x 周期谐波

半无限哈密顿量统一为

`H(k_x) = H0 + Σ(n>0)[Hn exp(i n k_x) + Hn† exp(-i n k_x)]`。

- `n=1` 继续由兼容字段 `H1` 表示；
- `n>=2` 存入 `HResult.extra[n]`；
- 数值与符号矩阵走同一公式；
- 不再把合法的 `|off_x|>1` 跃迁误判成不支持；
- 仍通过共轭转置自动保证厄米性。

### 2. 控制器链路贯通

- 符号矩阵调用 `HResult.to_semi(kx)`，不再只拼 `H0/H1`；
- 数值能带把 `extra` 一并传给 `RibbonHamiltonian`；
- 后台谱线程的 payload 扩展为 `(H0, H1, extra, kxs)`；
- 同步、异步、矩阵和能带使用同一份谐波数据，避免前台与后台结果分叉。

### 3. 模板与解析验证

对单轨道链 `t=1, t2=0.2`，逐点验证解析色散

`E(k_x) = -2 t cos(k_x) - 2 t2 cos(2 k_x)`。

符号验证使用指数形式直接比较，避免三角函数自动化简策略导致假阴性。
此外，8 个内置模板都分别通过半无限和双开边界控制器完整构建，矩阵维数、
厄米性和谱维数一致。

## 能带与界面缩放修复

- 将严格物理范围保存为 `_plot_rect=[-π,π]×[Emin,Emax]`；
- `sceneRect` 只作为视口裁剪区域，在四周为固定像素标题和刻度保留安全边距；
- 横坐标物理范围仍严格固定为 `[-π,π]`，不随 `t/t2` 改变；
- 标题移到绘图区上方的专用留白，不再遮挡最高能带；
- 明暗主题为标题设置显式高对比颜色；
- Ctrl +/- 改变字号和控制栏宽度后，延迟重新适配未被用户手动缩放的视图；
  用户已有的研究缩放/平移位置保持不动；
- 状态栏延迟提示在窗口销毁后安全退出，避免离屏批量验收时访问已删除对象。
